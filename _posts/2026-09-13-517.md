<p class="wp-block-paragraph">读论文最怕两件事：一是文献越攒越乱，引用时找不到原文；二是&#8221;读过像没读&#8221;，合上 PDF 啥也记不住。对研究生和科研人来说，<strong>文献管理 + 深度阅读 + 笔记沉淀</strong>是一条必须打通的生产线。</p>

<h2 class="wp-block-heading">四、翻译插件：让英文 PDF 不再劝退</h2>

<p class="wp-block-paragraph"><strong>Zotero PDF Translate</strong> 是精读流核心。配置示例：</p>

<pre><code class="language-yaml">PDF Translate 设置:
  翻译引擎: 深智/DeepL/OpenAI/本地 (按需)
  默认目标语言: 中文
  选项:
    - 选中即翻译（划词）
    - 侧边栏显示双语对照
    - 自动翻译注释
  隐私提示: 用本地模型或自建 API 时数据不出本机
</code></pre>

<p class="wp-block-paragraph">配合 Zotero 7 原生 PDF 阅读器，左边原文、右边译文，批注直接写在段落上，效率远超&#8221;复制去网页翻译&#8221;。</p>

<h2 class="wp-block-heading">五、标注 → 笔记联动</h2>

<p class="wp-block-paragraph">精读的关键不是&#8221;读&#8221;，是&#8221;提取&#8221;。推荐流程：</p>

<ol class="wp-block-list">
<li><strong>高亮</strong>关键句（Zotero 7 原生高亮，颜色区分&#8221;方法/结论/疑问&#8221;）。</li>
<li><strong>写注释</strong>：在每处高亮旁写一句自己的话（ paraphrasing 才记得住）。</li>
<li><strong>汇总到笔记</strong>：用 Better Notes 把该文献所有高亮 + 注释自动聚合成一篇笔记，模板如下：</li>
</ol>

<pre><code class="language-markdown"># 《论文标题》
- 作者 / 年份 / 期刊
- 研究问题：
- 方法：
- 主要结论：
- 我的评价 / 可复用点：
- 关联文献：[[另一篇]]
</code></pre>

<h2 class="wp-block-heading">六、与 Obsidian 第二大脑打通</h2>

<p class="wp-block-paragraph">读出来的笔记不能留在 Zotero 孤岛。用 Markdown 导出插件，把笔记存成 <code>.md</code> 同步进 <a href="https://waynetalk.com/512/">Obsidian 的 Resources 区</a>，并用 <code>[[双向链接]]</code> 关联：</p>

<pre><code class="language-text">Zotero 笔记 (Better Notes)
   ↓ Markdown 导出
Obsidian /30-Resources/科研/
   ↓ 双向链接
你的研究方向主页 / 文献综述
</code></pre>

<p class="wp-block-paragraph">这样<a href="https://waynetalk.com/540/">写综述</a>或开题时，相关文献笔记一键可查，还能图谱可视化&#8221;哪些论文在对话&#8221;。</p>

<h2 class="wp-block-heading">七、引用输出：写论文不熬夜</h2>

<p class="wp-block-paragraph">Word/LibreOffice 装 Zotero 插件后：</p>

<pre><code class="language-text">写作时：
  光标处 → Zotero 插件 → 插入引文 → 搜索文献 → 自动生成 [1]
  末尾 → 插入参考文献 → 选 GB/T 7714 样式 → 自动排版
</code></pre>

<p class="wp-block-paragraph">换期刊只需切换<strong>引用样式（CSL）</strong>，参考文献瞬间重排，告别手动调格式。</p>

<h2 class="wp-block-heading">八、平板精读 + 回传（多端闭环）</h2>

<p class="wp-block-paragraph">用 Zotfile/ZotMoov 把 PDF 发到 iPad 标注，读完后标注自动回传 Zotero：</p>

<pre><code class="language-yaml">流程:
  1. Zotero → 发送 PDF 到平板（通过指定文件夹 + 云盘）
  2. iPad 上用 GoodNotes/PDF Expert 批注
  3. 读毕移回原文件夹 → Zotfile 自动提取标注回 Zotero
</code></pre>

<h2 class="wp-block-heading">八、Better Notes 笔记模板详解</h2>

<p class="wp-block-paragraph">Better Notes 能把单篇文献的高亮自动聚合成笔记。推荐模板：</p>

<pre><code class="language-markdown"># {{title}}
> 作者：{{author}} ｜ 年份：{{date}} ｜ 期刊：{{publicationTitle}}

## 研究问题
{{highlight tag=question}}

## 方法
{{highlight tag=method}}

## 结论
{{highlight tag=conclusion}}

## 我的批注
{{annotations}}

## 关联
- 相关文献：[[{{related}}]]
</code></pre>

<p class="wp-block-paragraph">用不同颜色高亮区分&#8221;问题/方法/结论&#8221;，聚合时各归其位，写综述直接复制即用。</p>

<h2 class="wp-block-heading">九、中文文献与引用样式配置</h2>

<p class="wp-block-paragraph">国内投稿常需 <strong>GB/T 7714</strong> 样式。在 Zotero 安装对应 CSL：</p>

<pre><code class="language-yaml">步骤:
  1. 打开 zotero.org/styles 搜索 "GB/T 7714"
  2. 安装 Chinese Standard 样式
  3. 首选项 → 导出 → 默认样式 选 GB/T 7714
  4. Word 插件插入文献即按国标排版
</code></pre>

<p class="wp-block-paragraph">切换期刊时只需换 CSL，参考文献瞬间重排，免去手动调格式的深夜崩溃。</p>

<h2 class="wp-block-heading">十、批量管理与去重</h2>

<p class="wp-block-paragraph">文献攒多了必有重复。Zotero 7 自带去重：</p>

<pre><code class="language-text">工具 → 查找重复项 → 逐条合并（保留主条目 + 附件）
</code></pre>

<p class="wp-block-paragraph">配合 <strong>ZotFile</strong> 把附件统一改名（作者_年份_标题.pdf），文件夹不再是一堆&#8221;download(1).pdf&#8221;。</p>

<h2 class="wp-block-heading">十一、故障排查</h2>

<ul class="wp-block-list">
<li><strong>PDF Translate 不翻译</strong>：检查引擎 API Key 是否有效、网络是否可达；本地模型确认 <a href="https://waynetalk.com/533/">Ollama 已启动</a>。</li>
<li><strong>同步冲突</strong>：WebDAV 多设备同时写会冲突，改设置&#8221;仅一台设备自动同步附件&#8221;。</li>
<li><strong>插件不显示</strong>：确认下载的是标注 Zotero 7 兼容的版本，必要时在插件页&#8221;检查更新&#8221;。</li>
<li><strong>索引慢</strong>：首次导入大库耐心等待；可关闭不常用库的索引。</li>
</ul>

<h2 class="wp-block-heading">十二、科研人的&#8221;文献复利&#8221;</h2>

<p class="wp-block-paragraph">很多人读文献是&#8221;读一篇忘一篇&#8221;，到写综述时又从零搜。Zotero 7 的笔记联动解决的正是这个痛点：你今天为一篇论文写的批注、划的重点，未来会聚成可被检索、可被引用的&#8221;文献资产&#8221;。三年后你要写基金本子，搜一个关键词就能调出所有相关笔记与原文位置，这种复利远超临时抱佛脚。</p>

<p class="wp-block-paragraph">关键在于&#8221;读时就沉淀&#8221;——别等写论文才回头翻 PDF。每篇精读当场完成高亮+批注+笔记三联，Zotero 替你保管，Obsidian 替你关联。科研的差距，往往不在智商，而在谁把零散阅读变成了可复用的知识网。</p>

<h2 class="wp-block-heading">常见问题 FAQ</h2>

<p class="wp-block-paragraph"><strong>Q1：Zotero 7 和旧版 Zotero 6 数据能迁移吗？</strong><br />
能。Zotero 7 安装后会自动迁移本地库，首次启动请耐心等待索引重建。建议迁移前备份 <code>Zotero</code> 数据目录与 <code>storage</code> 附件文件夹。</p>

<p class="wp-block-paragraph"><strong>Q2：中文文献（知网）怎么高效入库？</strong><br />
安装 <strong>茉莉花（Jasminum）</strong> 插件，配合浏览器连接器，可在知网、豆瓣等页面一键抓取中英文元数据；学校图书馆的文献传递 PDF 也可手动拖入并让插件补全信息。</p>

<p class="wp-block-paragraph"><strong>Q3：翻译插件调用联网引擎会不会泄露我的文献？</strong><br />
敏感未发表内容建议用<strong>本地翻译模型</strong>（如 Ollama + 开源翻译模型）或自建 API，避免把原文发到第三方。公开论文用商业引擎问题不大，但仍建议留意插件的数据发送设置。</p>

<p>核心摘要（Key Takeaways）：<br />
&#8211; <strong>Obsidian 的核心价值是&#8221;纯 Markdown 本地文件+双链+插件生态&#8221;</strong>，任何替代都要先对标这三点：Logseq 最像双链党、思源笔记块编辑最强、Joplin 加密同步最自由。<br />
&#8211; <strong>免费笔记软件的坑不在软件本身，而在同步</strong>：Obsidian 官方 Sync 约 $4/月，替代方案多用&#8221;本体免费、同步自选&#8221;模式，用 WebDAV/网盘/Git 同步可以一分钱不花。<br />
&#8211; <strong>中文用户优先看思源笔记</strong>：本地功能全部免费（含商用）、块级编辑器体验最好；<strong>隐私党优先看 Joplin</strong>：端到端加密+同步后端完全自选。<br />
&#8211; 一句话建议：想要双链+大纲→Logseq；想要 Notion 式块编辑→思源笔记；想要加密+多端→Joplin；想要白板+文档混合→AFFiNE。</p>
<p>用 Obsidian 一段时间后，很多人都会冒出同样的念头：插件越装越多，移动端卡顿、同步要订阅、多人协作没有、学习成本吓退身边人。想换，但市面上的&#8221;Obsidian 替代&#8221;清单多半是把十几个名字堆在一起，完全不告诉你<strong>它们和 Obsidian 到底差在哪</strong>。</p>
<p>本文是为&#8221;正在用或准备用 Obsidian，但觉得它不够顺手&#8221;的人写的横评：7 款免费笔记软件/开源替代，全部按 2026 年 9 月的真实状态核实，表格横向对标，逐款讲清它替代的是 Obsidian 的哪一部分、以及你会失去什么。</p>

<h2>二、逐款详解</h2>
<h3>1. Logseq：离 Obsidian 双链体验最近的开源替代</h3>
<p>Logseq 是 GitHub 上 4 万+ star 的 AGPL 开源项目，隐私优先、本地优先。它的招牌是大纲式双向链接：每一条笔记都是一个节点，<code>[[双链]]</code> 自动织成知识图谱，Journal 每日笔记流深受卡片写作爱好者喜爱。<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/512/">本站此前的 Obsidian 进阶指南</a>里讲的关系图谱玩法，Logseq 开箱即有。</p>
<p><strong>价格真相</strong>：应用本体完全免费开源；官方 Sync 仍在测试阶段（此前通过赞助者计划内测），稳定方案是 Git 或第三方网盘同步。缺点是它对 Markdown 做了较多的语法扩展（大纲、TODO、块引用都会在文件里留下标记），跨工具迁移时会有摩擦。</p>
<p><strong>适合谁</strong>：大纲控、卡片笔记/卢曼式写作实践者——就是冲着 Obsidian 的双链+图谱来的人。</p>
<h3>2. 思源笔记：国产开源的块编辑器答案</h3>
<p>思源笔记是国人开发的开源项目（GitHub 4 万+ star，更新非常活跃），隐私优先、本地优先：块级编辑、块级引用、双向链接、数据库视图、关系图谱、间隔重复闪卡，还能挂载自己的 AI Key 做写作辅助。编辑器是所见即所得的块编辑器，对用惯 Notion 的人几乎零学习成本。</p>
<p><strong>价格真相</strong>：<strong>本地全部功能免费，连商用都免费</strong>，这是它最狠的地方。付费只跟同步有关：官方云同步、S3/WebDAV 同步属于会员特权（定价见<a class="wp-editor-md-post-content-link" href="https://b3log.org/siyuan/pricing.html">官网定价页</a>）。注意它用自有的 .sy 块数据格式存储，纯文本可移植性弱于 Obsidian，迁出靠导出 Markdown。</p>
<p><strong>适合谁</strong>：中文用户、学生党、想要 Notion 式块编辑但拒绝订阅制的人。</p>
<h3>3. Joplin：加密同步自由度最高的免费笔记软件</h3>
<p>Joplin 是开源笔记圈的&#8221;老兵&#8221;（GitHub 5 万+ star）：Markdown 笔记本+标签、待办提醒、浏览器剪藏插件、Evernote 一键导入，全平台覆盖甚至还有命令行客户端。最大卖点是<strong>同步后端完全由你定</strong>：Dropbox、OneDrive、WebDAV、Nextcloud、S3，或自托管 Joplin Server——且支持端到端加密。</p>
<p><strong>价格真相</strong>：应用 100% 免费开源、无功能锁；官方 Joplin Cloud 约 €2.99/月起。不想付费用自己的网盘同步即可，整套栈零成本。</p>
<p><strong>适合谁</strong>：从 Evernote 迁移、把&#8221;加密+同步后端自选&#8221;看得最重的人。双链图谱是短板，别指望它平替 Obsidian 的关系图。</p>
<h3>4. AFFiNE：文档+白板+数据库的三合一</h3>
<p>AFFiNE（官网自述 GitHub 7 万+ star）走&#8221;All in One&#8221;路线：同一块内容可以在文档模式、edgeless 无限画布白板模式、数据库模式之间切换，头脑风暴和结构化整理不用换软件。本地优先架构，离线可用；MIT 协议，社区版可自托管（Docker 一条命令）。</p>
<p><strong>价格真相</strong>：桌面与网页客户端免费，本地使用不花钱；多端同步与协作走官方云或自建服务器。注意移动端应用仍处于测试阶段，手机重度用户先观望。</p>
<p><strong>适合谁</strong>：需要白板+文档混合工作流的个人和小团队。它和 Obsidian 不是同一种生物——替代的是&#8221;Notion 那部分&#8221;，<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/notion-alternatives-free/">本站的 Notion 替代横评</a>里对它有更详细的拆解。如果你要找的是 Notion替代 而不是 Obsidian替代，优先读那篇。</p>
<h3>5. Notesnook：零知识加密的笔记仓库</h3>
<p>Notesnook 是完全开源的笔记应用，主打<strong>零知识、端到端加密</strong>：笔记在设备端加密后再同步，即使服务器被攻破内容也无法被读取。嵌套笔记本、标签、完整 Markdown 支持，界面干净，免费版即可使用（含基础同步）。</p>
<p><strong>价格真相</strong>：免费版可用，付费版解锁更多同步空间与高级功能（以官网为准）。它是&#8221;云优先&#8221;架构，不像 Obsidian 那样离线单机也能全功能运行。</p>
<p><strong>适合谁</strong>：把隐私放在第一位、但又想要&#8221;注册即用、多端自动同步&#8221;的懒人——Obsidian+自建同步嫌折腾的人会喜欢它。</p>
<h3>6. NoteGen：AI 驱动的国产开源 Markdown 笔记</h3>
<p>NoteGen 是国内开发者做的开源跨平台笔记（GitHub 1 万+ star，Tauri 构建，安装包仅 20~30MB）。核心定位很特别：<strong>用 AI 把&#8221;零散记录&#8221;变成&#8221;结构化文章&#8221;</strong>——先疯狂记录截图、文字、链接，再一键生成提纲、扩展段落。纯本地 Markdown 存储，可接硅基流动免费额度、DeepSeek 或 Ollama 本地模型，同步走 GitHub/GitLab/WebDAV。</p>
<p><strong>价格真相</strong>：完全免费、无广告、无账号、无订阅。它没有双链和知识图谱，不适合做第二大脑，但做&#8221;记录→成文&#8221;流水线是一把好手，<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/518/">和 Markdown 多平台分发流程</a>搭配使用效果更佳。</p>
<p><strong>适合谁</strong>：内容创作者、自媒体、学生——记得多、写得多，但不想手动整理的人。</p>
<h3>7. TriliumNext：层级知识库的极客之选</h3>
<p>Trilium 是老牌的层级式个人知识库（树形结构+笔记属性+脚本扩展），原项目已由作者归档，目前由社区分支 <strong>TriliumNext</strong> 继续维护。它没有双链图谱，强项是无限层级的树形组织和强大的搜索/脚本能力，适合&#8221;文件夹树&#8221;思维的技术型用户。</p>
<p><strong>价格真相</strong>：完全免费开源，单机运行，同步靠自建服务器或文件同步工具。界面朴素，学习曲线偏极客向。</p>
<p><strong>适合谁</strong>：喜欢树形层级、不信任图谱、想要一个&#8221;本地 Wiki&#8221;的技术型用户。</p>
<h2>三、按需求抄作业：三类人三种换法</h2>
<h3>🕸️ 双链党：Logseq 或思源笔记</h3>
<p>你就是冲着 Obsidian 的双向链接+关系图谱来的，换工具不能丢这个。<strong>Logseq</strong> 是最接近的开源替代，大纲式双链+每日笔记流一气呵成；<strong>思源笔记</strong>的块级引用和反链面板更强，还附带数据库视图。两者都免费，中文用户建议先试思源笔记。</p>
<h3>🔒 隐私党：Joplin 或 Notesnook</h3>
<p>你的排序是&#8221;数据主权 > 花哨功能&#8221;。<strong>Joplin</strong> 给你最大的自由度：同步后端任选、端到端加密、纯 Markdown 文件，想怎么折腾怎么折腾；<strong>Notesnook</strong> 则是&#8221;开箱即用的加密版&#8221;，注册就有 E2EE 同步，不用自己搭任何东西。</p>
<h3>🔄 多端同步党：Notesnook 或 AFFiNE</h3>
<p>你受够了 Obsidian 同步要么付费要么折腾。<strong>Notesnook</strong> 的官方云同步免费版就可用且全程加密；<strong>AFFiNE</strong> 本地优先+可选自托管，文档白板数据库三合一，一台 VPS 解决全家同步。如果笔记以阅读输入为主，也可以看看<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/513/">本站的阅读输入流水线方案</a>。</p>
<h2>四、从 Obsidian 迁移指南：四步无痛搬家</h2>
<p>换笔记软件最怕的不是学新功能，而是<strong>旧笔记烂在旧软件里</strong>。按这四步走：</p>
<ol>
<li><strong>先导出，再决定</strong>：Obsidian 的 vault 本身就是一堆 Markdown 文件，直接复制整个文件夹就是完整备份，这是它最大的优点。先做一次全量复制，再谈迁移。</li>
<li><strong>按&#8221;存储格式亲和度&#8221;选目标</strong>：Logseq、Joplin、NoteGen 对纯 Markdown 亲和度最高，基本可以直接打开 Obsidian 的 vault 文件夹；思源笔记、AFFiNE 需要走&#8221;导入 Markdown&#8221;流程，会有一次格式转换。</li>
<li><strong>双链语法做一次替换</strong>：Obsidian 的 <code>[[链接]]</code> 在 Logseq/思源笔记里基本通用；块引用 <code>^blockid</code> 这种高级语法没有通用方案，迁移前先在 Obsidian 里把核心块引用展开成普通文本。</li>
<li><strong>附件和图片单独处理</strong>：确认 vault 里附件文件夹的导入逻辑。Joplin 有 Markdown 导入器，思源笔记支持批量导入，AFFiNE 的导入相对弱一些，大附件建议先精简。</li>
</ol>
<p>迁移后保留旧 vault 三个月，确认新工具里检索、链接都正常再删。数据只有一份的时候，它就是最脆弱的时候。</p>
<h2>五、FAQ</h2>
<h3>Obsidian 替代品里，哪个和 Obsidian 最像？</h3>
<p>Logseq。同样本地优先、同样双向链接+知识图谱、同样 Markdown 底座，而且是 AGPL 开源。代价是它的 Markdown 语法扩展较多，跨工具迁移摩擦比 Obsidian 大。</p>
<h3>有完全免费、不用订阅的 Obsidian 替代吗？</h3>
<p>有。思源笔记本地功能全免费（含商用），Logseq、Joplin、AFFiNE、NoteGen、TriliumNext 本体全部免费开源。需要花钱的永远是&#8221;官方云同步&#8221;这类服务，用网盘/WebDAV/Git 自建同步即可零成本。</p>
<h3>中文用户选哪个 Obsidian 替代最好？</h3>
<p>思源笔记是国人开发，中文分词搜索、中文社区、中文文档都是原生支持，块编辑器对新手也最友好。如果你在意纯文本可移植性，Logseq 或 Joplin 更合适。</p>
<h3>Obsidian 的插件生态有替代能对打吗？</h3>
<p>目前没有。Obsidian 的 4000+ 社区插件是它最深的护城河，任何替代在这方面都是降级。思源笔记有插件集市但规模小一个量级，Logseq 也有插件系统但活跃度不如从前。接受&#8221;功能少但够用&#8221;，是换工具的前提心态。</p>
<h3>这些免费笔记软件，数据安全吗？</h3>
<p>分两层看：本地数据——Obsidian、Logseq、Joplin、思源笔记、NoteGen 都是本地优先，数据在你硬盘上，最安全；云同步——Notesnook 和 Joplin（开启 E2EE 后）是端到端加密，连服务商都看不到内容。做学术或科研笔记需要文献管理联动的，可以参考<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/517/">本站的 Zotero+笔记联动方案</a>。</p>
<h3>Notion 用户想换本地笔记，选哪个？</h3>
<p>这正是本文的姊妹篇要解决的问题：<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/notion-alternatives-free/">Notion 免费替代横评</a>从块编辑器+数据库的角度对比了 AppFlowy、AFFiNE 等 6 款。如果你要的是&#8221;本地版 Notion&#8221;，看那篇；如果你要的是&#8221;开源版 Obsidian&#8221;，就是本篇。</p>
<h3>迁移后发现不合适，还能换回来吗？</h3>
<p>能。只要你的笔记是 Markdown 纯文本（Obsidian/Logseq/Joplin/NoteGen 之间），互相打开对方的文件夹就行，迁移成本极低。这也是&#8221;纯文本优先&#8221;选型策略的最大好处：永远有退路。</p>
<h2>六、总结</h2>
<p>没有一款软件能在所有维度上&#8221;平替&#8221;Obsidian，因为 Obsidian 的护城河是三样东西的组合：<strong>纯 Markdown 文件、双向链接图谱、4000+ 插件生态</strong>。替代方案都是&#8221;三选二&#8221;：</p>
<ul>
<li>要双链+开源 → <strong>Logseq</strong></li>
<li>要块编辑+中文+免费 → <strong>思源笔记</strong></li>
<li>要加密+同步自由 → <strong>Joplin</strong></li>
<li>要白板+文档+数据库 → <strong>AFFiNE</strong></li>
<li>要开箱即用+加密同步 → <strong>Notesnook</strong></li>
<li>要 AI 整理+纯本地 → <strong>NoteGen</strong></li>

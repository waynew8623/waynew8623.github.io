<p>核心摘要（Key Takeaways）：<br />
&#8211; <strong>Tailscale 是最适合普通人的异地组网方案</strong>：基于 WireGuard 的虚拟局域网，无需公网 IP、无需端口转发、无需域名，免费版足够家庭和个人使用。<br />
&#8211; <strong>飞牛 NAS 安装只需 3 步</strong>：开启飞牛 SSH → 运行官方一键安装脚本 → <code>sudo tailscale up</code> 登录同一账号，拿到 <code>100.x.x.x</code> 虚拟 IP 后，外网直接访问 <code>http://100.x.x.x:8000</code> 即可。<br />
&#8211; <strong>进阶玩法</strong>：子网路由（访问全家局域网）、出口节点（外网走家里网络）、Tailscale Serve / Funnel（对外共享某个服务），覆盖绝大多数家庭需求。<br />
&#8211; 完整对比 Tailscale / ZeroTier / frp / Cloudflare Tunnel / 端口转发，帮助你按场景选对方案。</p>
<p>家里一台飞牛 NAS 存着照片和资料，出门在外想看一眼——你会发现这事比想象中麻烦：宽带没有公网 IP，路由器设置端口转发像天书，DDNS 经常掉线，买域名还得备案。这篇教程解决的，就是这件事。</p>
<p>Tailscale 用一句话讲：<strong>让分散在各地的设备像接在同一台路由器上一样互联，基于 WireGuard 加密，直连打通，打不通自动走加密中继。</strong> 免费，注册登录就能用。</p>
<blockquote><p>
  ⚠️ 免费政策变动较快：Tailscale Personal 个人版长期免费，多用户、多设备、无带宽限制，但免费额度 2026 年官方有过调整（多家资料说法不一），动手前请以官网 tailscale.com/pricing 为准。
</p></blockquote>
<h2>一、准备工作：5 分钟就能就绪</h2>
<p>在开始之前，准备好这些：</p>
<ol>
<li><strong>飞牛 NAS 一台</strong>（飞牛 fnOS 基于 Linux 内核，支持 SSH 与 Docker）</li>
<li><strong>要远程访问的设备</strong>：手机、笔记本电脑任选其一</li>
<li><strong>一个可用于注册的邮箱/Google/Microsoft 账号</strong>（Tailscale 支持第三方登录）</li>
</ol>
<blockquote><p>
  如果你还没搭 NAS 或正在折腾，可以参考本站的<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/519/">NAS 私有云生产力构建</a>（Synology/TrueNAS 跨设备备份）和<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/551/">NAS / VPS 媒体库搭建</a>（Docker 一键部署 Emby/Jellyfin），看完再回来看组网会更顺。
</p></blockquote>
<h2>二、第一步：注册 Tailscale 账号</h2>
<ol>
<li>打开 <code>tailscale.com</code>，点击 <strong>Get started</strong> / <strong>Sign up</strong>。</li>
<li>选择登录方式：Google、Microsoft、GitHub 或邮箱皆可。个人用户直接用 Google 或 GitHub 登录最省事。</li>
<li>登录后会进入 Tailscale 的管理后台（Admin Console），保持这个页面，稍后安装完设备会在这里出现。</li>
</ol>
<h2>三、第二步：在飞牛 NAS 上安装 Tailscale</h2>
<p>飞牛 fnOS 是基于 Linux 内核的系统，安装流程和 Linux 服务器完全一致，官方一键脚本即可完成。</p>
<h3>1. 开启飞牛 NAS 的 SSH</h3>
<ol>
<li>在飞牛 NAS 网页管理后台进入<strong>设置</strong>，找到 <strong>SSH</strong> 开关并启用（默认端口 22）。</li>
<li>在电脑上打开终端（Windows 用 PowerShell / CMD），连接 NAS：</li>
</ol>
<pre><code class="language-bash line-numbers">ssh admin@192.168.x.x   # 换成你飞牛 NAS 的局域网 IP
</code></pre>
<h3>2. 运行官方安装脚本</h3>
<p>连接成功后，执行：</p>
<pre><code class="language-bash line-numbers">sudo -i
curl -fsSL https://tailscale.com/install.sh | sh
</code></pre>
<p>脚本会自动识别系统、添加官方软件源并安装 <code>tailscale</code> 客户端和 <code>tailscaled</code> 守护进程，安装完自动设为开机自启动。</p>
<h3>3. 登录并加入你的虚拟网络</h3>
<pre><code class="language-bash line-numbers">tailscale up
</code></pre>
<p>终端会打印出一个授权链接，形如 <code>https://login.tailscale.com/a/xxxxxxxx</code>。用<strong>任意设备</strong>的浏览器打开它，用刚才注册的同一个 Tailscale 账号登录确认，回到终端稍等片刻，出现 <code>Success.</code> 即成功。</p>
<p>NAS 的 Tailscale 客户端也支持 Docker 部署，官方 <code>tailscale/tailscale</code> 镜像跑一个 sidecar 容器即可，适合不想动系统环境的用户。</p>
<h3>4. 记下 NAS 的虚拟 IP</h3>
<pre><code class="language-bash line-numbers">tailscale ip -4    # 输出类似 100.64.0.5
</code></pre>
<p>这个 <code>100.x.x.x</code> 就是 NAS 在你的虚拟局域网里的<strong>固定地址</strong>，记下来——后面远程访问全靠它。Tailscale 还附带 MagicDNS，设备名 <code>.tailnet名.ts.net</code> 的域名可自动解析，输 IP 或域名都行。</p>
<h2>四、第三步：在手机/电脑上安装 Tailscale</h2>
<ol>
<li><strong>Windows / macOS</strong>：官网下载客户端，安装后登录<strong>同一个账号</strong>。</li>
<li><strong>iOS / Android</strong>：在 App Store / 应用商店搜索 &#8220;Tailscale&#8221;，登录同一账号并开启连接。</li>
<li>同一账号下的所有设备自动组成一张虚拟局域网（tailnet），无需任何手动配置。</li>
</ol>
<h2>五、第四步：外网直接访问飞牛 NAS</h2>
<p>只要手机和 NAS 都在线且登录了同一账号，现在打开浏览器访问：</p>
<pre><code class="line-numbers">http://100.x.x.x:8000
</code></pre>
<p>（<code>100.x.x.x</code> 换成你 NAS 的虚拟 IP，<code>:8000</code> 换成飞牛 NAS 管理页的实际端口）</p>
<p>能打开飞牛 NAS 的登录页，说明组网成功。同样的方式，飞牛上用 Docker 部署的任何服务（Emby、Jellyfin、Alist 等）都可以通过 <code>100.x.x.x:对应端口</code> 直接访问。</p>
<blockquote><p>
  无需公网 IP、无需改路由器、无需 DDNS 的外网访问就这么完成了。如果你还想看其他无公网 IP 的思路，可以读本站的<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/547/">无公网 IP 方案：Cloudflare Tunnel、Tailscale 与 ZeroTier 实现远程访问</a>，里面还对比了几种内网穿透方案。
</p></blockquote>
<h2>六、进阶玩法：子网路由与出口节点</h2>
<h3>1. 子网路由：让外网设备访问全家局域网</h3>
<p>组网默认只打通&#8221;装了客户端的设备&#8221;。想从外网访问家里没装 Tailscale 的设备（比如路由器管理页、打印机、智能家居网关）？在飞牛 NAS 上开启<strong>子网路由</strong>：</p>
<pre><code class="language-bash line-numbers">tailscale up --advertise-routes=192.168.x.0/24   # 换成你家局域网网段
</code></pre>
<p>然后去管理后台 → Machines → 找到飞牛 NAS → 勾选 <strong>Enable subnet routes</strong>。之后从外网设备直接访问 <code>192.168.x.x</code> 即可，像身在局域网一样。</p>
<h3>2. 出口节点：外网流量走家里网络</h3>
<p>想在外地访问只限家庭宽带的服务（如 IPTV 盒子、运营商内网页面），可以把飞牛 NAS 设为<strong>出口节点</strong>：</p>
<pre><code class="language-bash line-numbers">tailscale up --advertise-exit-node
</code></pre>
<p>在管理后台给飞牛 NAS 开启 <strong>Exit node</strong> 权限后，手机端 Tailscale 切换到这个出口节点，上网流量就会经由家中 NAS 转出。</p>
<h3>3. Tailscale Serve / Funnel：对外共享单个服务</h3>
<ul>
<li><strong>tailscale serve</strong>：把 NAS 上的某个本地服务（如照片管理页）映射到 tailnet 域名，仅组网内成员可见，自动配 HTTPS。</li>
<li><strong>tailscale funnel</strong>：把服务暴露到<strong>公网</strong>，不装客户端也能访问。但要注意这是把服务公开到互联网，<strong>不确定就永远别开</strong>，开了一定要配好鉴权。</li>
</ul>

<h2>八、FAQ</h2>
<p><strong>Q1：Tailscale 免费版真的够用吗？会被收费吗？</strong><br />
A：个人家庭场景完全够用：免费 Personal 版多用户、多设备，访问控制（ACL）、子网路由、出口节点、MagicDNS 这些核心功能都开放，且无带宽/流量限制。只需确认你在官网注册时选的是免费 Personal 套餐；用企业域名邮箱注册可能进入付费试用，个人用 Gmail / GitHub 登录一般默认免费版。</p>
<p><strong>Q2：没有公网 IP 也能用 Tailscale 吗？</strong><br />
A：能，这正是它的核心优势。设备间通过 NAT 打洞直连（WireGuard 的 UDP 41641 端口最好能出站）；打不通时自动回退到 Tailscale 的加密中继服务器（DERP），不需要你做任何配置。</p>
<p><strong>Q3：Tailscale 和 VPN 有什么区别？</strong><br />
A：传统 VPN 是&#8221;拨到一个中心服务器再出去&#8221;；Tailscale 是 mesh 网状结构，设备之间尽量直连，延迟更低、单点故障更少，且不需要维护服务器。它更像是一个帮你自动配好 WireGuard 的&#8221;虚拟交换机&#8221;。</p>
<p><strong>Q4：飞牛 NAS 重启后 Tailscale 还在吗？</strong><br />
A：在。官方安装脚本会把 <code>tailscaled</code> 注册为系统服务并设为开机自启。重启后它会自动上线，你可以通过管理后台的 Machines 列表确认设备状态。</p>
<p><strong>Q5：手机和电脑必须开着 Tailscale 客户端吗？</strong><br />
A：是的。Tailscale 是客户端组网模式，访问 NAS 的设备也需要运行客户端并登录同一账号。不过手机端可以设置按需连接（on-demand），不占常驻资源。</p>
<p><strong>Q6：速度快吗？看 NAS 里的高清电影会不会卡？</strong><br />
A：大部分家庭宽带环境下设备能直连（P2P），速度取决于你的上传带宽；局域网直连则跑满内网带宽。如果两端都是严格 NAT 打不通，会走境外中继中转，延迟和带宽会下降。看 4K 建议走直连或先确认上传带宽。</p>
<p><strong>Q7：Tailscale 能访问没装客户端的智能家居设备吗？</strong><br />
A：能，用第六节的子网路由：把飞牛 NAS 设为子网路由网关并在后台启用路由，外网设备就能访问家里 <code>192.168.x.x</code> 网段的全部设备。</p>
<p><strong>Q8：担心隐私，数据会经过 Tailscale 服务器吗？</strong><br />
A：Tailscale 的控制面只负责分发密钥和协调打洞，流量本身端到端 WireGuard 加密直传；只有直连失败时才经 DERP 中继转发密文，Tailscale 无法解密内容。</p>
<h2>总结</h2>
<p>Tailscale 组网教程的核心其实就三行命令：<code>tailscale up</code> 让 NAS 上网，<code>tailscale ip -4</code> 拿到虚拟 IP，<code>http://100.x.x.x:端口</code> 开始远程访问。对飞牛 NAS 用户来说，它比任何内网穿透工具都简单：不用折腾公网 IP、不用买域名、不用调路由器。</p>
<p>进阶的子网路由和出口节点则把&#8221;远程访问一台 NAS&#8221;升级成了&#8221;随身携带整个家庭局域网&#8221;——这正是异地组网方案的真正价值。</p>

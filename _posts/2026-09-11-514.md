<p class="wp-block-paragraph">&#8220;这个月钱都花哪了？&#8221;——每到月底，这个问题总让人心虚。你试过记账 App，坚持三天就放弃了；你导出过微信、支付宝账单，却在<a href="https://waynetalk.com/974/">几十列杂乱的 Excel</a> 里迷失。记账本身不难，<strong>难的是持续</strong>，而持续的关键，是让&#8221;记录&#8221;这件事自动化。</p>

<p class="wp-block-paragraph">本文给你两条落地路径：一条走<strong>程序员友好的 Beancount 复式记账</strong>（纯文本、可版本管理、报表强大），一条走<strong>普通人友好的 Excel/Power BI 数据面板</strong>。无论哪条，核心都是——把微信、支付宝账单自动化导入，而不是手动敲。</p>

<blockquote class="is-layout-flow wp-block-quote-is-layout-flow">
<p>⚠️ <strong>隐私与安全前置提醒（务必读完）</strong><br />
账单包含你的消费习惯、住址、人际关系等高度敏感信息。请遵守以下原则：<br />
1. 账单文件<strong>不要</strong>上传到任何不明第三方网站或发给他人。<br />
2. 自动化脚本在<strong>本地</strong>运行，凭证（Cookie、API Key）存于本地环境变量，绝不明文写进仓库。<br />
3. 用 Git 管理 Beancount 账本时，务必把含敏感信息的文件加入 <code>.gitignore</code>，或使用私有仓库。<br />
4. 关闭账单导出后的文件分享权限，处理完及时从临时目录删除原始 CSV。</p>
</blockquote>

<h2 class="wp-block-heading">一、整体流水线设计</h2>

<pre><code class="language-text">[微信/支付宝 App]
   ↓ 官方账单导出（CSV/Excel）
[原始账单文件]
   ↓ 清洗脚本（统一字段、分类）
[标准化交易记录]
   ↓ 路由
   ├─→ Beancount (.beancount 纯文本账本) → fava 网页报表
   └─→ Excel / Power BI → 透视表数据面板
</code></pre>

<p class="wp-block-paragraph">关键在中间的&#8221;清洗脚本&#8221;：微信和支付宝的导出格式不一样，需要归一化。</p>

<h2 class="wp-block-heading">二、第一步：导出原始账单</h2>

<h3 class="wp-block-heading">2.1 微信账单导出</h3>

<p class="wp-block-paragraph">路径：<code>微信 → 我 → 服务 → 钱包 → 账单 → 常见问题 → 下载账单 → 用于个人对账</code>。<br />
选择时间范围后，账单会<a href="https://waynetalk.com/529/">发送到你的微信绑定邮箱</a>，解压需输入微信提供的<strong>解压码</strong>（注意解压码仅通过微信会话发送，请妥善保管）。导出为 Excel。</p>

<h3 class="wp-block-heading">2.2 支付宝账单导出</h3>

<p class="wp-block-paragraph">路径：<code>支付宝 → 我的 → 账单 → 右上角 … → 开具交易流水证明 → 用于个人对账</code>。<br />
同样发送到邮箱，获得 Excel/CSV。</p>

<blockquote class="is-layout-flow wp-block-quote-is-layout-flow">
<p>两家导出的列名、编码、时间格式都不同，这正是需要脚本清洗的原因。<strong>不要</strong>尝试用&#8221;账单截图 OCR&#8221;的第三方小程序，存在泄露风险。</p>
</blockquote>

<h2 class="wp-block-heading">三、路径 A：Beancount 复式记账（推荐进阶用户）</h2>

<p class="wp-block-paragraph">Beancount 是纯文本复式记账工具，每一笔交易都&#8221;有借必有贷&#8221;，自动保证账目平衡，并能生成净资产、收支、分类统计等报表。</p>

<h3 class="wp-block-heading">3.1 安装</h3>

<pre><code class="language-bash">pip install beancount fava
# fava 是网页端查看器
</code></pre>

<h3 class="wp-block-heading">3.2 账本主文件结构</h3>

<pre><code class="language-beancount">; main.beancount
option "title" "我的个人账本"
option "operating_currency" "CNY"

2026-01-01 open Assets:WeChat     CNY
2026-01-01 open Assets:Alipay     CNY
2026-01-01 open Expenses:Food     CNY
2026-01-01 open Expenses:Transport CNY
2026-01-01 open Income:Salary     CNY

; 一笔示例交易
2026-09-01 * "午餐 麦当劳"
  Assets:Alipay        -38.00 CNY
  Expenses:Food         38.00 CNY
</code></pre>

<h3 class="wp-block-heading">3.3 用脚本把 CSV 转成 Beancount 条目</h3>

<p class="wp-block-paragraph">社区有现成工具 <code>beanprice</code>、以及针对不同平台的导入器。一个简化思路（Python 伪代码）：</p>

<pre><code class="language-python">import csv, re

CATEGORY_MAP = {
    "餐饮": "Expenses:Food",
    "交通": "Expenses:Transport",
    "工资": "Income:Salary",
}

def to_beancount(row):
    date = row["交易时间"][:10]
    desc = row["商品名称"]
    amount = float(row["金额"])
    cat = CATEGORY_MAP.get(row["交易分类"], "Expenses:Other")
    source = "Assets:WeChat" if "微信" in row["收/支"] else "Assets:Alipay"
    return f'{date} * "{desc}"\n  {source}  {-amount:.2f} CNY\n  {cat}  {amount:.2f} CNY\n'

# 读取清洗后的 CSV → 追加到 main.beancount
</code></pre>

<h3 class="wp-block-heading">3.4 查看报表</h3>

<pre><code class="language-bash">bean-check main.beancount   # 校验账目平衡
fava main.beancount         # 启动网页 http://localhost:5000
</code></pre>

<p class="wp-block-paragraph">fava 提供按账户、按时间、按标签的丰富图表，比任何记账 App 都自由。</p>

<h2 class="wp-block-heading">四、路径 B：Excel / Power BI 数据面板（推荐普通用户）</h2>

<p class="wp-block-paragraph">如果你不想碰命令行，Excel 也能做出漂亮面板。</p>

<h3 class="wp-block-heading">4.1 用 Power Query 清洗</h3>

<ol class="wp-block-list">
<li>把微信、支付宝 CSV 放进同一文件夹。</li>
<li>Excel → 数据 → 从文件夹 → 合并。</li>
<li>在 Power Query 里统一列名、把&#8221;交易时间&#8221;转为日期、按关键词匹配分类。</li>
<li>加载为数据模型，插入<strong>数据透视表</strong> + <strong>切片器</strong>（按月份、分类筛选）。</li>
</ol>

<h3 class="wp-block-heading">4.2 自动刷新</h3>

<p class="wp-block-paragraph">把清洗逻辑存成 Power Query 步骤，下次只需把新 CSV 丢进文件夹，点&#8221;全部刷新&#8221;即可。再进阶可用 Power BI 做可视化看板，手机端也能看。</p>

<h2 class="wp-block-heading">五、进阶：半自动持续同步</h2>

<p class="wp-block-paragraph">完全实时同步需要平台开放账单 API，目前个人用户并不开放。务实做法是<strong>月度批处理</strong>：</p>

<pre><code class="language-yaml">每月 1 号 定时任务:
  - 手动导出上月微信/支付宝账单到 ~/finance/inbox/
  - 运行清洗脚本 → 生成标准化 CSV
  - 脚本自动追加到 Beancount 或刷新 Excel
  - 发送一条摘要到你的笔记（如 Flomo/Notion）
</code></pre>

<p class="wp-block-paragraph">可用 macOS 快捷指令、Windows 任务计划程序或 cron 触发提醒，真正做到&#8221;人只导出，机器记账&#8221;。</p>

<h2 class="wp-block-heading">九、常见报错与排查</h2>

<ul class="wp-block-list">
<li><strong>编码乱码</strong>：微信/支付宝导出多为 GBK，用 <code>iconv -f GBK -t UTF-8</code> 或 Excel&#8221;从文本导入&#8221;选对编码。</li>
<li><strong>金额符号混用</strong>：支付宝支出带 <code>-</code>，微信可能相反，清洗脚本要统一方向。</li>
<li><strong>Beancount 不平衡</strong>：每笔交易借贷必须相等，报错会指出哪行，检查是否漏写对手账户。</li>
<li><strong>日期格式</strong>：统一成 <code>YYYY-MM-DD</code>，避免 <code>9月5日</code> 这类无法排序的格式。</li>
</ul>

<h2 class="wp-block-heading">十、隐私自检清单</h2>

<p class="wp-block-paragraph">部署前逐项确认：</p>

<pre><code class="language-yaml">隐私自检:
  - [ ] 账单原始文件未上传任何第三方网站
  - [ ] 脚本在本地运行，无外部网络调用
  - [ ] 凭证/解压码存于本地，未写进代码或仓库
  - [ ] Git 仓库为私有，敏感文件已 gitignore
  - [ ] 处理完删除临时目录的原始 CSV
  - [ ] 云备份开启加密
</code></pre>

<h2 class="wp-block-heading">十一、记账的终极目标不是数字，是觉察</h2>

<p class="wp-block-paragraph">自动化把记账成本降到极低后，真正的价值才浮现：当你每月打开报表，看到&#8221;外卖占比 30%&#8221;&#8221;订阅服务悄悄涨到 200 元&#8221;，改变的契机就来了。记账不是自我审视的刑具，而是财务觉察的起点。建议每月拨 10 分钟看趋势图，问自己两个问题：钱花得和我的价值观一致吗？有哪些可优化？答案比数字本身更有用。</p>

<h2 class="wp-block-heading">总结</h2>

<p class="wp-block-paragraph">记账自动化的本质，是把&#8221;每月一次的痛苦手工活&#8221;变成&#8221;导出一个文件、跑一段脚本&#8221;。无论你选 Beancount 的极客之路，还是 Excel 的平民方案，核心都是<strong>减少人为操作、<a href="https://waynetalk.com/902/">保护个人隐私</a></strong>。从下个月账单开始，试着让机器替你记第一笔账。</p>

<h2 class="wp-block-heading">常见问题 FAQ</h2>

<p class="wp-block-paragraph"><strong>Q1：微信/支付宝有没有官方自动同步 API？</strong><br />
截至目前，个人用户无法获取实时账单 API，只能走&#8221;手动导出 + 脚本清洗&#8221;的批处理模式。任何宣称&#8221;免导出实时同步&#8221;的第三方服务都需谨慎，可能涉及账号风险与隐私泄露。</p>

<p class="wp-block-paragraph"><strong>Q2：Beancount 和市面记账 App 比有什么优势？</strong><br />
数据是纯文本，永不属于任何公司；复式记账保证账目自洽；报表完全自定义且可版本管理。缺点是上手门槛高，需要一点命令行基础。</p>

<p class="wp-block-paragraph"><strong>Q3：我的账单信息会不会在自动化过程中泄露？</strong><br />
只要脚本在本地运行、不调用不明云服务、凭证不入库，风险极低。本文所有方案均可在离线环境完成。敏感文件处理完务必删除原始导出，并避免加入公开 Git 仓库。</p>

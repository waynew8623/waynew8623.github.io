<h2>三、快速上手：四段代码跑通免费TTS API 与文生图</h2>
<h3>1. Edge TTS：三行命令生成中文语音</h3>
<pre><code class="language-bash line-numbers">pip install edge-tts
edge-tts --voice zh-CN-XiaoxiaoNeural --text "你好，这是免费文字转语音测试" --write-file test.mp3
</code></pre>
<p>Python 批量处理（自动分段，适合长文本）：</p>
<pre><code class="language-python line-numbers">import asyncio, edge_tts

async def tts(text, out="out.mp3", voice="zh-CN-YunxiNeural"):
    comm = edge_tts.Communicate(text, voice, rate="+5%")
    await comm.save(out)

asyncio.run(tts("第一段文本……"))  # 长文本建议按段落切分后逐段合成再拼接
</code></pre>
<p>常用中文音色：<code>zh-CN-XiaoxiaoNeural</code>（女声）、<code>zh-CN-YunxiNeural</code>（男声）、<code>zh-CN-YunjianNeural</code>。更多音色可用 <code>edge-tts --list-voices</code> 查看。</p>
<h3>2. Pollinations：一条 URL 出图，一条 curl 出语音</h3>
<p>文生图（直接 GET，返回图片）：</p>
<pre><code class="language-bash line-numbers">curl "https://gen.pollinations.ai/image/a%20cozy%20pixel%20art%20robot%20in%20a%20digital%20garden?width=1024&height=1024" -o robot.jpg
</code></pre>
<p>支持 <code>width/height/model/seed</code> 参数，<code>model</code> 可选 FLUX 系列等（以官方文档为准）。</p>
<p>TTS（OpenAI 兼容接口，需 Key）：</p>
<pre><code class="language-bash line-numbers">curl 'https://gen.pollinations.ai/v1/audio/speech' \
  -H 'Content-Type: application/json' \
  -H "Authorization: Bearer <redacted>" \
  -d '{"model": "tts-1", "input": "你好，欢迎来到江狐说", "voice": "nova"}' \
  -o speech.mp3
</code></pre>
<p>Key 在 <a class="wp-editor-md-post-content-link" href="https://enter.pollinations.ai">enter.pollinations.ai</a> 免费注册获取。</p>
<h3>3. Cloudflare Workers AI：REST 调用 FLUX 文生图</h3>
<pre><code class="language-bash line-numbers">curl -X POST "https://api.cloudflare.com/client/v4/accounts/你的ACCOUNT_ID/ai/run/@cf/black-forest-labs/flux-1-schnell" \
  -H "Authorization: Bearer <redacted>" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "flat minimalist tech illustration, sound waves and paintbrush, blue gradient", "steps": 4}' \
  | python3 -c "import sys,json,base64; open('cf_flux.jpg','wb').write(base64.b64decode(json.load(sys.stdin)['result']['image']))"
</code></pre>
<p>返回的是 base64 编码的 JPEG，直接解码保存即可。注意 <code>steps</code> 越小越省 neurons，schnell 模型 4 步即可出图。</p>
<h3>4. 硅基流动：OpenAI 兼容，一套代码两用</h3>
<p>硅基流动兼容 OpenAI 接口风格，TTS 与文生图都可以用熟悉的 SDK 调：</p>
<pre><code class="language-python line-numbers">from openai import OpenAI

client = OpenAI(base_url="https://api.siliconflow.cn/v1", api_key="你的KEY")

# TTS（CosyVoice 系列，具体模型名以控制台为准）
resp = client.audio.speech.create(model="FunAudioLLM/CosyVoice2-0.5B",
                                  input="注册赠送的额度足够跑完验证",
                                  voice="alex")
resp.stream_to_file("sf_tts.mp3")
</code></pre>
<p>模型名与参数以硅基流动官方文档为准，变动较频繁。</p>

<h2>五、商用注意事项</h2>
<ol>
<li><strong>授权条款先看</strong>：Edge TTS、Pollinations 匿名接口本质是&#8221;社区/客户端级&#8221;服务，条款可能限制商业用途；正式商用优先选有明确 SLA 的官方免费档（Azure、Google Cloud、Cloudflare）。</li>
<li><strong>免费档无 SLA</strong>：限速、排队、临时下线都可能发生，生产环境务必做降级（多家 fallback + 本地缓存）。</li>
<li><strong>数据条款</strong>：部分免费档可能将输入用于模型改进，敏感文案、未公开产品信息不要上传。</li>
<li><strong>额度监控</strong>：免费档多为&#8221;超额即停&#8221;，但绑定过支付方式的账号要设预算告警，避免试用转付费后意外扣费。</li>
<li><strong>遵守合理使用</strong>：不要用脚本恶意刷量，匿名接口被滥用会导致全网限速收紧。</li>
</ol>
<h2>六、FAQ</h2>
<p><strong>Q1：有完全免费、不需要注册的 TTS API 吗？</strong><br />
A：有，微软 Edge TTS。无需 Key、无需注册，约 400 个神经网络音色直接调用。缺点是单次请求约 3000–5000 字符上限，长文本需自行分段，且非官方公开 API，商用前请确认授权。</p>
<p><strong>Q2：文字转语音免费方案里，中文效果最好的是哪个？</strong><br />
A：中文自然度口碑较好的：Azure 中文神经网络音色（中英混读强）、MiniMax speech 系列、阿里 CosyVoice 系列（硅基流动可低价调用）。Edge TTS 的晓晓/云希日常使用完全够用。</p>
<p><strong>Q3：免费图片生成API 有数量限制吗？</strong><br />
A：都有。Pollinations 匿名档限速较严（高频会被 429）；Cloudflare Workers AI 每天约 10000 neurons（约 150–200 张 FLUX 图）；Hugging Face 按模型限速。个人博客配图、Bot 日常出图通常够用，批量生产建议叠加多家。</p>
<p><strong>Q4：Pollinations 需要 API Key 吗？</strong><br />
A：基础调用不需要，匿名即可用；但匿名档限速严。2026 年新版接口建议到官网免费注册 Key，限额更宽松，且文本/图像/音频统一走 <code>gen.pollinations.ai</code>。</p>
<p><strong>Q5：国内不用翻墙，有哪些文字转语音免费/低价方案？</strong><br />
A：硅基流动（注册送约 14–16 元代金券，CosyVoice 模型约 ¥1.5/万字符）、MiniMax（官网有免费试用额度）、Azure Speech（国内可直连，每月约 50 万字符免费）。</p>
<p><strong>Q6：免费 TTS/文生图 API 能商用吗？</strong><br />
A：看条款。Azure、Google Cloud、Cloudflare 的官方免费档通常允许轻量商用；Edge TTS、Pollinations 匿名接口建议仅作学习测试。正式商用前逐一核对各家服务条款，并切到有 SLA 的付费档。</p>
<p><strong>Q7：Edge TTS 突然连不上/被限速怎么办？</strong><br />
A：三板斧：降低并发并加退避重试；长文本分段后串行请求；准备 Azure Speech 或 Pollinations 做 fallback。也可以把常用文案的音频缓存到本地/对象存储，避免重复合成。</p>

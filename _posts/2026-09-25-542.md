<h2 class="wp-block-heading">二、注册避坑：为什么总被拒</h2>

<p class="wp-block-paragraph">Oracle 注册拒人不是新鲜事。常见被拒原因：</p>

<ul class="wp-block-list">
<li><strong>信用卡验证失败</strong>：部分地区发行的卡、预付费卡、与账单地址不匹配的卡容易失败。请用本人实名、账单地址真实的卡片。</li>
<li><strong>手机号收不到验证码</strong>：换网络环境、换浏览器、关闭代理重试。</li>
<li><strong>区域选择</strong>：首页区域（Home Region）注册后<strong>不可更改</strong>，建议选离你近且资源充足的区域，例如日本、韩国、新加坡、美国东部（但美东 A1 容量常紧张）。</li>
<li><strong>一人多号</strong>：同一人反复注册极易被风控。不要尝试批量薅。</li>
</ul>

<p class="wp-block-paragraph">合规提醒：请使用<strong>真实身份与真实支付方式</strong>注册，不要借用、盗用他人信用卡或伪造信息。账号被封不仅损失实例，还可能涉及支付欺诈风险。</p>

<h2 class="wp-block-heading">三、创建 ARM 实例 step-by-step</h2>

<ol class="wp-block-list">
<li>登录 OCI 控制台，进入「计算 → 实例 → 创建实例」。</li>
<li>名称随意；<strong>映像（Image）</strong>推荐 Ubuntu 22.04/24.04 或 Oracle Linux 9。</li>
<li><strong>形状（Shape）</strong>选择 <code>VM.Standard.A1.Flex</code>，设置：<br />
   &#8211; OCPU：2<br />
   &#8211; 内存：12 GB（在 A1 上 2 OCPU 对应上限即 12GB）</li>
<li>启动卷（Boot Volume）大小：建议 47–100GB（总 200GB 额度内可自行分配）。</li>
<li>网络：新建或选择已有 VCN，分配公有 IPv4 子网。</li>
<li>添加 SSH 密钥（务必用密钥登录，禁用密码）。</li>
<li>点击「创建」，等待分配<a href="https://waynetalk.com/frp-ssl-ddns-raspberry-guide/">公网 IP</a>。若出现 <code>Out of host capacity</code>，换可用域（AD）或稍后重试。</li>
</ol>

<pre><code class="language-bash"># 本地生成密钥对（如尚未有）
ssh-keygen -t ed25519 -C "oracle-oci"

# 登录
ssh -i ~/.ssh/id_ed25519 opc@<你的公网IP>
</code></pre>

<blockquote class="is-layout-flow wp-block-quote-is-layout-flow">
<p>若你已有超配实例，请在控制台「更多操作 → 编辑」把 OCPU 改到 2、内存改到 12GB，并<strong>备份后</strong>操作；只停止（Stop）不会释放额度，必须改形状或终止。</p>
</blockquote>

<h2 class="wp-block-heading">四、保活策略：别让实例被回收</h2>

<p class="wp-block-paragraph">Oracle 会对<strong>空闲实例回收</strong>：在 7 天周期内，若 CPU 第 95 百分位利用率 < 20%、网络利用率 < 20%、A1 实例内存利用率 < 20%，就可能被回收。保活的核心是"让它看起来在干活"：</p>

<ul class="wp-block-list">
<li>跑一个轻量常驻服务，如 <code>nginx</code> + 监控探活、或 <code>cron</code> 定时任务。</li>
<li>用脚本周期性产生低负载活动（不要搞高 CPU 的&#8221;挖矿式&#8221;保活，违反条款且伤机器）。</li>
<li>示例：每 5 分钟写一条日志并访问本地端口。</li>
</ul>

<pre><code class="language-bash"># /etc/cron.d/keepalive
*/5 * * * * opc curl -s -o /dev/null http://127.0.0.1:80/ || true
</code></pre>

<ul class="wp-block-list">
<li>真正长期稳定：在上面跑你的真实服务（博客、API、网盘、CI Runner），自然就不会被判空闲。</li>
</ul>

<h2 class="wp-block-heading">五、网络调优：把 10TB 流量用出价值</h2>

<p class="wp-block-paragraph">Oracle 默认只给 IPv4 公网地址（且免费实例 IPv4 资源日益紧张，部分地区新建实例默认无 IPv4）。几个调优点：</p>

<ol class="wp-block-list">
<li><strong>IPv6</strong>：在 VCN 中启用 IPv6 前缀，给实例分配 IPv6 地址，可绕过 IPv4 紧张问题，且很多场景仅用 IPv6 即可。</li>
<li><strong>安全列表（Security List）/ 防火墙</strong>：只开放必要端口（22、80、443），其余默认拒绝。</li>
<li><strong>BBR 加速</strong>：开启 TCP BBR 拥塞控制，提升跨境带宽利用率。</li>
</ol>

<pre><code class="language-bash"># 开启 BBR（需 root）
echo 'net.core.default_qdisc=fq' >> /etc/sysctl.conf
echo 'net.ipv4.tcp_congestion_control=bbr' >> /etc/sysctl.conf
sysctl -p
sysctl net.ipv4.tcp_congestion_control  # 应输出 bbr
</code></pre>

<ol class="wp-block-list" start="4">
<li><strong>结合 Cloudflare</strong>：把域名 CNAME 到 Oracle 公网 IP，启用 Cloudflare 代理（橙色云），既能隐藏源站 IP，又能借 Cloudflare 边缘缓存进一步省出站流量。</li>
</ol>

<h2 class="wp-block-heading">七、FAQ</h2>

<p class="wp-block-paragraph"><strong>Q1：Oracle 免费机真的永久免费吗？</strong><br />
A：Always Free 资源在账号存续期间、且不超出额度上限时是免费的。但 Oracle 保留调整免费额度的权利（2026 年 8 月已实际缩减 ARM 额度），请以官网最新条款为准。</p>

<p class="wp-block-paragraph"><strong>Q2：注册一直被拒怎么办？</strong><br />
A：优先检查信用卡真实性与账单地址一致性、手机号能否收码、网络环境是否干净。不要反复用同一身份猛撞，容易被风控。实在注册不上，可考虑本文其他免费方案（如 Cloudflare Pages 静态托管）替代。</p>

<p class="wp-block-paragraph"><strong>Q3：实例被回收了能恢复吗？</strong><br />
A：因空闲被回收的实例通常进入&#8221;终止中/已回收&#8221;状态，数据盘若独立创建可保留，但实例本身一般需重建。预防优于补救——按第四节的保活策略来。</p>

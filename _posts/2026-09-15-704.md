<h2>1. 旁路网关（旁路由）拓扑架构设计</h2>
<p>很多用户初玩软路由，会把软路由直接作为主路由拨号。但在实际家庭网络中，一旦软路由重启或插件崩溃，全家断网，家庭矛盾频发。</p>
<p><strong>旁路由架构（Bypass Gateway）</strong> 是当前公认容灾性最强、最优雅的拓扑方案：</p>
<pre><code class="language-">       [电信/联通/移动 光猫]
                 │ (PPPoE 拨号)
                 ▼
       [硬主路由器 (主网关)] ─── IP: 192.168.1.1 (负责 DHCP、Wi-Fi 覆盖与交换)
                 │
        ┌────────┴───────────────────────────┐
        ▼                                    ▼
[OpenWrt 旁路由 (透明代理)]        [常规家庭终端: 智能家居/老人手机]
IP: 192.168.1.2                     (网关: 192.168.1.1, 直通主路，永不故障)
        │
        ▼
[需要科学上网的终端: Apple TV / 电脑 / PS5]
(网关手工/自动指定为: 192.168.1.2)
</code></pre>
<h3>核心优势：</h3>
<ul>
<li><strong>完全解耦</strong>：即便旁路由关机升级，主路由依然保障全屋基础宽带畅通无阻；</li>
<li><strong>定向接管</strong>：可只让需要翻墙的设备指定旁路由为网关，普通智能家居依旧直连主路由。</li>
</ul>

<h2>2. OpenWrt 旁路由网络参数极简配置</h2>
<p>在进入 OpenClash 前，<a href="https://waynetalk.com/vless-setup-openwrt-guide/">必须先确保 OpenWrt 系统的网络底层配置正确</a>，避免网络回环或丢包。</p>
<h3>2.1 物理接口配置（LAN 口）</h3>
<p>登录 OpenWrt Web 界面，进入 <strong>网络 -> 接口 -> LAN -> 修改</strong>：<br />
1. <strong>IPv4 地址</strong>：设置为与主路由同网段的静态 IP（例如主路由为 <code>192.168.1.1</code>，则旁路由填 <code>192.168.1.2</code>）；<br />
2. <strong>IPv4 子网掩码</strong>：<code>255.255.255.0</code>；<br />
3. <strong>IPv4 网关</strong>：必须填写<strong>主路由 IP</strong>（<code>192.168.1.1</code>）；<br />
4. <strong>自定义 DNS 服务器</strong>：填写主路由 IP（<code>192.168.1.1</code>）或公共 DNS（<code>223.5.5.5</code>）；<br />
5. <strong>IPv6 设置</strong>：建议在旁路由上<strong>禁用 IPv6</strong>（除非有特殊需求，IPv6 极易导致 DNS 泄漏和绕过代理策略）；<br />
6. <strong>DHCP 服务器</strong>：勾选 <strong>“忽略此接口”</strong>（关闭旁路由自带的 DHCP，由主路由统一分配）。</p>
<h3>2.2 解决旁路由不转发流量的关键防火墙规则</h3>
<p>在某些 Linux 内核版本上，旁路由必须关闭 SYN-flood 防御并开启 IP 动态伪装（NAT）：<br />
进入 <strong>网络 -> 防火墙 -> 自定义规则</strong>，在末尾添加：</p>
<pre><code class="language-bash"># 解决旁路由单网口无法转发流量的问题
iptables -t nat -I POSTROUTING -o eth0 -j MASQUERADE
</code></pre>
<p><em>(注：如果你的网卡名称是 <code>br-lan</code>，请将 <code>eth0</code> 替换为 <code>br-lan</code>)</em>。</p>

<h3>3.2 彻底根治 DNS 污染与泄漏的核心配置</h3>
<p>DNS 泄漏是用户访问海外隐私网站时真实身份暴露的最主要原因。</p>
<p>在 <strong>OpenClash -> 覆写设置 -> DNS 设置</strong> 中：<br />1. <strong>启用自定义本地 DNS 覆写</strong>：勾选；<br />2. <strong>Fake-IP 缓存</strong>：启用持久化缓存；<br />3. <strong>NameServer (国内直连 DNS)</strong> 填写：</p>
<ul>
<li><code>https://dns.alidns.com/dns-query</code></li>
<li><code>223.5.5.5</code></li>
</ul>
<p>4. <strong>Fallback (境外加密代理 DNS)</strong> 填写：</p>
<ul>
<li><code>https://1.1.1.1/dns-query</code></li>
<li><code>https://8.8.8.8/dns-query</code></li>
</ul>
<p>5. <strong>禁止 Dnsmasq 缓存</strong>：勾选（避免路由器级双重缓存引起冲突）。</p>

<h2>4. 终端设备接入方式：手动指定 vs 全局无感接管</h2>
<h3>方案 A：针对特定设备定向分流（推荐）</h3>
<p>在 Apple TV、PS5、日常使用的主力 PC/手机上，打开 Wi-Fi 设置，将 IP 获取从“自动 (DHCP)”改为“手动”：</p>
<ul>
<li><strong>IP 地址</strong>：<code>192.168.1.150</code>（保持原 IP）</li>
<li><strong>子网掩码</strong>：<code>255.255.255.0</code></li>
<li><strong>默认网关</strong>：<code>192.168.1.2</code>（<strong>指向旁路由</strong>）</li>
<li><strong>首选 DNS</strong>：<code>192.168.1.2</code>（<strong>指向旁路由</strong>）</li>
</ul>
<h3>方案 B：全屋自动无感接管（主路由 DHCP 下发旁路由网关）</h3>
<p>如果想让所有连入家庭 Wi-Fi 的设备默认全部走旁路由：</p>
<ul>
<li>登录<strong>主路由器</strong>管理页面，进入 DHCP 选项；</li>
<li>将 <strong>“默认网关 (Gateway)”</strong> 修改为旁路由 IP（<code>192.168.1.2</code>）；</li>
<li>将 <strong>“主 DNS 服务器”</strong> 修改为旁路由 IP（<code>192.168.1.2</code>）；</li>
<li>保存重启主路由 DHCP，即可实现全屋设备无感接入。</li>
</ul>

<h2>6. 常见故障排查（FAQ）</h2>
<h3>Q1: 某些国内 App（如微信图片加载慢、淘宝图片裂开）怎么办？</h3>
<ul>
<li><strong>原因</strong>：国内部分 CDN 节点使用了基于客户端 IP 的智能调度。如果使用了远程 DNS 解析国内域名，CDN 会将请求调度至境外节点，导致访问极慢。</li>
<li><strong>解决办法</strong>：在 OpenClash 策略中确保 <code>GEOSITE:cn</code> 走 <code>DIRECT</code>，且国内 DNS（NameServer）必须填写大陆本地运营商或阿里的直连 DNS。</li>
</ul>
<h3>Q2: 旁路由发热大，测速跑不满千兆宽带怎么回事？</h3>
<ul>
<li><strong>解答</strong>：检查软路由 CPU 是否支持 AES-NI 硬件加速指令集；同时在 OpenWrt 系统设置中开启 <strong>“软件流量分载 (Software Flow Offloading)”</strong> 和 <strong>“硬件流量分载”</strong>，可大幅降低软路由 CPU 占用，轻松跑满千兆。</li>
</ul>

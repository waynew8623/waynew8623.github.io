<p class="wp-block-paragraph">每天要在十几个科技站点之间来回刷，生怕漏掉竞品动态或 AI 新发布？与其靠人肉盯，不如让 <strong><a href="https://waynetalk.com/522/">n8n 自动化工作流</a></strong> 当你的「<a href="https://waynetalk.com/262/">资讯雷达</a>」：定时轮询 RSS、用翻译模型做中英互译、去重后通过 <strong>Webhook</strong> 推到 <strong>飞书</strong> 群与多维表格。本文给出可落地的完整做法。</p>

<h2 class="wp-block-heading">第一步：配置 RSS 源</h2>

<p class="wp-block-paragraph">用 <strong>RSS Read</strong> 节点，填入你关注的源（科技类举例）：</p>

<ul class="wp-block-list">
<li><code>https://hnrss.org/frontpage</code>（Hacker News）</li>
<li><code>https://www.theverge.com/rss/index.xml</code></li>
<li><code>https://openai.com/blog/rss.xml</code></li>
<li><code>https://github.blog/feed/</code></li>
</ul>

<p class="wp-block-paragraph">可放多个源，节点支持逗号分隔或并行多个 RSS Read 后再 <strong>Merge</strong>。</p>

<h2 class="wp-block-heading">第二步：去重，避免反复推送同一条</h2>

<p class="wp-block-paragraph">新建 <strong>Code</strong> 节点，用一组已见过的 <code>link</code> 集合过滤：</p>

<pre><code class="language-javascript">// 使用 n8n 静态数据做轻量去重（重启后清空，生产建议用 DB/Redis）
const seen = <span class="katex math inline">getWorkflowStaticData('global').seen || {};
const out = [];
for (const item of</span>input.all()) {
  const link = item.json.link || item.json.guid;
  if (!link || seen[link]) continue;
  seen[link] = Date.now();
  out.push(item);
}
$getWorkflowStaticData('global').seen = seen;
return out;
</code></pre>

<blockquote class="is-layout-flow wp-block-quote-is-layout-flow">
<p>提示：<code>seen</code> 会无限增长，生产环境应改为写入飞书多维表格或 Redis，并定期清理。</p>
</blockquote>

<h2 class="wp-block-heading">第三步：调用翻译模型做中英互译</h2>

<p class="wp-block-paragraph">很多英文源需要中文摘要。用 <strong>HTTP Request</strong> 节点调用翻译模型（以<a href="https://waynetalk.com/544/">兼容 OpenAI 协议的接口</a>为例）：</p>

<pre><code>Method: POST
URL: https://your-translation-endpoint/v1/chat/completions
Headers: Authorization: Bearer {{ <span class="katex math inline">env.TRANSLATE_TOKEN }}
Body:
{
  "model": "translate-pro",
  "messages": [
    { "role": "system", "content": "你是将英文科技新闻翻译为流畅中文的助手，保留专有名词。" },
    { "role": "user", "content": "请翻译标题并给出一句摘要：{{</span>json.title }}\n{{ $json.contentSnippet }}" }
  ],
  "temperature": 0.3
}
</code></pre>

<p class="wp-block-paragraph">用表达式把返回内容解析到字段 <code>zh</code>。如果你用 n8n 1.x 及以上版本，也可直接用内置 <strong>LangChain</strong> 节点（如 <code>LangChain OpenAI Chat Model</code> + <code>AI Chain</code>），更省拼接代码。</p>

<h2 class="wp-block-heading">第四步：推送到飞书群机器人</h2>

<p class="wp-block-paragraph">飞书自定义群组机器人 Webhook 形如 <code>https://open.feishu.cn/open-apis/bot/v2/hook/XXXX</code>。用 <strong>HTTP Request</strong> 节点：</p>

<pre><code>Method: POST
URL: https://open.feishu.cn/open-apis/bot/v2/hook/{{ <span class="katex math inline">env.FEISHU_BOT_KEY }}
Headers: Content-Type: application/json
Body:
{
  "msg_type": "interactive",
  "card": {
    "header": { "title": { "tag": "plain_text", "content": "{{</span>json.zh_title }}" } },
    "elements": [
      { "tag": "div", "text": { "tag": "lark_md", "content": "{{ <span class="katex math inline">json.zh_summary }}" } },
      { "tag": "action", "actions": [
        { "tag": "button", "text": { "tag": "plain_text", "content": "查看原文" }, "url": "{{</span>json.link }}" }
      ]}
    ]
  }
}
</code></pre>

<p class="wp-block-paragraph">消息卡片比纯文本更友好，支持按钮跳转原文。</p>

<h2 class="wp-block-heading">第五步：沉淀到飞书多维表格</h2>

<p class="wp-block-paragraph">除了群推送，把每条资讯写入 <strong>飞书多维表格（Bitable）</strong>，方便后续检索与选题。多维表格新增记录接口：</p>

<pre><code>POST https://open.feishu.cn/open-apis/bitable/v1/apps/{{ APP_TOKEN }}/tables/{{ TABLE_ID }}/records
Body:
{
  "fields": {
    "标题": "{{ <span class="katex math inline">json.zh_title }}",
    "原文链接": "{{</span>json.link }}",
    "来源": "{{ <span class="katex math inline">json.creator }}",
    "发布时间": "{{</span>json.isoDate }}",
    "摘要": "{{ $json.zh_summary }}",
    "标签": ["RSS", "科技"]
  }
}
</code></pre>

<blockquote class="is-layout-flow wp-block-quote-is-layout-flow">
<p>多维表格接口需 <code>tenant_access_token</code>，建议用 <strong>飞书凭证</strong> 节点或定时刷新 Token 后存到 n8n 环境变量。</p>
</blockquote>

<h2 class="wp-block-heading">第六步：关键词过滤，只推关心的</h2>

<p class="wp-block-paragraph">在翻译前加一个 <strong>Filter</strong> 节点，只保留命中关键词的条目（如 <code>AI</code>、<code>GPU</code>、<code>n8n</code>、<code>kubernetes</code>），避免噪声：</p>

<pre><code>Filter 条件：
  $json.title 包含任意 ["AI","大模型","k8s","n8n","RPA"]
</code></pre>

<h2 class="wp-block-heading">排错与优化</h2>

<ul class="wp-block-list">
<li><strong>RSS 抓取失败</strong>：部分源限频，给 Schedule 设 30 分钟以上间隔；用 <code>Retry On Fail</code> 自动重试。</li>
<li><strong>翻译超长</strong>：对 <code>contentSnippet</code> 截断到 1500 字符再送模型。</li>
<li><strong>飞书限流</strong>：群机器人单群约 100 条/分钟，多维表格写入建议批量（一次最多 500 条）。</li>
</ul>

<h2 class="wp-block-heading">总结</h2>

<p class="wp-block-paragraph">这套 n8n RSS 聚合流把「人找信息」变成「信息找人」，每天自动把精选科技资讯翻译成中文并推到飞书，省下的时间足以回本。还能横向扩展：加 Slack、加邮件摘要、加每周聚合报告。</p>

<h2 class="wp-block-heading">FAQ</h2>

<p class="wp-block-paragraph"><strong>Q1：RSS Read 节点支持需要鉴权的私有源吗？</strong><br />
支持。在节点高级设置里配置 Basic Auth 或自定义 Header 即可拉取私有 Feed。</p>

<p class="wp-block-paragraph"><strong>Q2：去重存在内存里够用吗？</strong><br />
单机演示够用，但 n8n 重启或重部署会清空静态数据，导致重复推送。生产建议写入数据库或飞书多维表格做持久去重。</p>

<p class="wp-block-paragraph"><strong>Q3：翻译模型必须用付费 API 吗？</strong><br />
不一定。你可以用本地部署的开源翻译模型（如兼容 OpenAI 协议的服务）通过 HTTP Request 调用，完全离线，数据不出内网。</p>

<h2>四、逐款详解：录屏篇</h2>
<h3>1. OBS Studio：免费录屏软件的天花板</h3>
<p>OBS Studio 是直播和录屏领域事实上的标准工具，<strong>完全免费、开源（GPLv2），无水印、无时长限制、无账号要求</strong>，跨 Windows、macOS、Linux 三平台。2026 年主线版本已进入 32 系列，支持 4K 60fps 录制，N 卡 NVENC、Intel QuickSync、AMD AMF 硬件编码一应俱全，CPU 占用可控。</p>
<p>它的核心是&#8221;场景&#8221;系统：屏幕、窗口、摄像头、浏览器页、麦克风、系统声音都可以作为独立图层自由组合，还带逐路音量调节的音频混音器。录完存本地，MP4/MKV/FLV/MOV 任选。新手第一次上手建议走&#8221;工具 → 自动配置向导&#8221;，让它按你的硬件自动选最优设置；缺点是菜单层级深，第一次用需要半小时学习成本，但一劳永逸。</p>
<p>录下来的长视频如果想剪辑、修复画质或做后期，可以参考本站的<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/893/">《高效数字资产管理：视频画质修复与批量智能挑图工具深度指南》</a>，把录制和后期串成一条线。</p>
<h3>2. ShareX：Windows 上的截图+录屏效率流</h3>
<p>ShareX 是 Windows 平台的老牌免费开源捕捉工具，自 2007 年持续维护至今。它不止能录屏：13+ 种截图模式（区域、窗口、滚动长截图）、<strong>屏幕录制导出 MP4 或 GIF</strong>、OCR 识别、取色器、二维码生成，还内置视频转换和裁剪小工具。</p>
<p>它的杀手锏是&#8221;工作流&#8221;：截图/录屏后可以自动执行一串动作——保存、加水印、上传到 80+ 个图床/网盘、把链接复制到剪贴板，一键完成。缺点是界面为可配置性而生，选项密集，新手容易晕。建议先只配一个截图快捷键 + 两个&#8221;截图后动作&#8221;，熟了再叠加。</p>
<p>如果你还想深入玩转屏幕捕捉，可以看看本站的<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/859/">《专业级截图工具实战指南：形状捕捉与无损长图录制深度解析》</a>，里面有更多捕捉技巧。</p>
<h3>3. Xbox Game Bar：Windows 自带，按 Win+G 就录</h3>
<p>很多 Windows 用户不知道：系统自带就有录屏。按下 <strong>Win+G</strong> 呼出 Xbox Game Bar，不用装任何软件就能开始录制当前窗口，适合&#8221;临时录一段发给同事看&#8221;这种高频小需求。Win10 和 Win11 都带，零学习成本，录完直接存到&#8221;视频/捕获&#8221;文件夹。</p>
<h3>4. macOS 截屏工具栏：Mac 用户不用装任何东西</h3>
<p>Mac 用户按 <strong>Shift + Command + 5</strong> 呼出截屏工具栏，可选全屏录制、区域录制、定时开始，还能选保存位置和麦克风，输出默认 .mov。优点是系统级集成、手感最好；注意它默认只录麦克风，<strong>想内录系统声音需要加装虚拟声卡</strong>（如 BlackHole），这是 macOS 系统的限制，不是工具的问题。</p>
<h3>5. Captura Web Recorder：免安装的浏览器录屏</h3>
<p>这里要先澄清一个常见误区：桌面版 Captura（MathewSachin/Captura）<strong>已于 2019 年左右停止维护</strong>，GitHub 仓库已注明不再更新，老版本在新系统上可能有兼容问题，不建议再装。</p>
<p>作者推出了精神续作 <strong>Captura Web Recorder</strong>：纯浏览器录屏，Chrome/Edge/Firefox 桌面版打开即用，能同时录屏幕、摄像头小窗和麦克风，输出 WebM 或 MP4，<strong>全程本地运行、不上传任何数据</strong>。适合借用别人电脑、或不想装软件时的临时录制。限制是：浏览器拿不到系统级键盘钩子，做不了按键显示；手机浏览器不支持录屏。</p>
<h2>五、逐款详解：下载篇</h2>
<h3>6. N_m3u8DL-RE：m3u8/DASH 流媒体下载专精</h3>
<p>很多网页视频用的是 HLS（m3u8）或 DASH 分片传输，右键另存为只能拿到一个几 KB 的播放列表文件。<strong>N_m3u8DL-RE</strong>（GitHub: nilaoda/N_m3u8DL-RE）就是专治这个的开源命令行工具，跨平台，支持点播和直播录制，能自动并行下载分片、自动解密 AES-128 加密流、调用 ffmpeg 合并成 MP4/MKV。</p>
<p>基本用法就一行：</p>
<pre><code class="language-bash line-numbers">N_m3u8DL-RE "https://example.com/stream/master.m3u8" --save-name "课程视频"
</code></pre>
<p>2026 年 6 月已发布 v0.6.0-beta，依然活跃。它比直接用 ffmpeg 抓 m3u8 更聪明：能处理防盗链头、跳转和不规范播放列表，很多 ffmpeg 抓失败的站它都能拿下。<strong>提醒：只下载你有授权的内容</strong>（比如自己买的课程、公开课）。</p>
<h3>7. yt-dlp：1800+ 网站的视频下载瑞士军刀</h3>
<p>yt-dlp 是 youtube-dl 停滞后社区接手的活跃分支，<strong>免费开源、无广告、无账号</strong>，截至 2026 年 8 月稳定版为 2026.08.19，几乎每天都在跟进各网站的接口变化。支持 YouTube、Vimeo、TikTok、Instagram 等 1800+ 站点，能下播放列表、整个频道、字幕，还能只抽音频转 MP3，甚至集成 SponsorBlock 跳过赞助片段。</p>
<p>常用命令：</p>
<pre><code class="language-bash line-numbers"># 装好后直接下
yt-dlp "视频链接"
# 只要最高画质 MP4 + 只下音频版
yt-dlp -f "bestvideo+bestaudio/best" --merge-output-format mp4 "视频链接"
yt-dlp -x --audio-format mp3 "视频链接"
</code></pre>
<p>命令行是它的门槛也是它的上限：写进脚本就能定时批量归档。怕命令行的可以搜开源 GUI 前端，但建议优先认准基于 yt-dlp 的开源项目，别装来历不明的&#8221;免费下载器&#8221;。</p>
<h3>8. Motrix Next（已更名 Rayburst）：多协议下载加速器</h3>
<p>Motrix 是很多人的 IDM 平替记忆，但原版已于 2023 年停滞。现在的正统续作是 <strong>Motrix Next</strong>：用 Tauri 2 + Rust 重写，安装包仅约 20MB，MIT 开源，支持 HTTP/HTTPS/FTP、BT、磁力链、ED2K，多线程加速、断点续传、批量任务、限速调度，浏览器插件还能一键接管网页下载。</p>
<p><strong>注意一个 2026 年 9 月底的最新变动</strong>：Motrix Next 已正式更名为 <strong>Rayburst</strong>，新版本还原生支持了 HLS/DASH 下载。老用户请从官方渠道认准新名字下载，不要搜到山寨站。旧任务和配置不会自动迁移，切换前先完成手头的下载。</p>
<h3>9. qBittorrent：无广告的 BT/磁力下载器</h3>
<p>提到 BT 下载，qBittorrent 是经久不衰的免费开源选择：无广告、无捆绑，支持磁力链、种子、RSS 订阅自动追更、做种管理、远程 WebUI，功能对标付费 BT 客户端。配合 Motrix Next，一个管常规文件、一个管 BT，桌面下载基本全覆盖。</p>

<h2>八、FAQ</h2>
<p><strong>Q1：免费录屏软件真的没有水印吗？</strong><br />
A：本文 5 款录屏工具都没有水印、没有时长限制。注意区分：Loom、Cap 等国外工具的&#8221;免费版&#8221;通常限制 5 分钟或加水印，它们不在本文推荐之列。</p>
<p><strong>Q2：OBS 太复杂，有没有 1 分钟上手的？</strong><br />
A：有。Windows 直接 Win+G，Mac 直接 Shift+Command+5，浏览器打开 Captura Web Recorder 也行。等你需要多图层、混音、高画质时再回头学 OBS。</p>
<p><strong>Q3：桌面版 Captura 还能用吗？</strong><br />
A：不建议。原项目 2019 年左右停更，无安全更新，在新版 Windows 上可能有兼容问题。作者官方推荐的替代是浏览器版 Captura Web Recorder，免安装、持续维护。</p>
<p><strong>Q4：m3u8 下载下来一堆 ts 碎片，怎么变成正常视频？</strong><br />
A：用 N_m3u8DL-RE 会自动合并成 MP4/MKV，直接双击就能播（推荐 VLC 或 PotPlayer）。如果已经下了一堆 ts 碎片，用 <code>ffmpeg -i "concat:1.ts|2.ts" -c copy out.mp4</code> 手动合并。</p>
<p><strong>Q5：yt-dlp 突然下不了某个网站了怎么办？</strong><br />
A：第一步永远是升级到最新版：<code>yt-dlp -U</code>（或去 GitHub Releases 下新版）。网站接口天天变，旧版本失效是常态，不是工具坏了。</p>
<p><strong>Q6：Motrix 和 Motrix Next（Rayburst）是什么关系？</strong><br />
A：Motrix Next 是原 Motrix 停滞后的社区/官方续作，重写了技术栈；2026 年 9 月底它更名为 Rayburst。认准新名字从官方渠道下载，别下到山寨版。</p>
<p><strong>Q7：免费下载器能破解网盘限速吗？</strong><br />

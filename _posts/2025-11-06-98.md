<h2 id="kuai-su-ru-men-gou-jian-nin-de-di-yi-ge-shuang-jun-xian-ce-lue" tabindex="-1">快速入门：构建您的第一个双均线策略</h2>
<p>理论不如实践。下面，我们将通过一个经典的<strong>双均线交叉策略</strong>，演示在 QuantDigger 中实现一个完整的回测是多么简单直观。</p>
<h3 id="1.-ce-lue-luo-ji-ding-yi" tabindex="-1">1. 策略逻辑定义</h3>
<ul>
<li><strong>买入信号 (金叉)</strong>：当短期移动平均线（例如 5 日均线）从下方上穿长期移动平均线（例如 20 日均线）时，全仓买入。</li>
<li><strong>卖出信号 (死叉)</strong>：当短期移动平均线下穿长期移动平均线时，清空所有头寸。</li>
</ul>
<h3 id="2.-wan-zheng-ce-lue-dai-ma-shi-li" tabindex="-1">2. 完整策略代码示例</h3>
<p>QuantDigger 采用事件驱动的结构。<code>on_init</code> 用于策略初始化，<code>on_bar</code> 会在每个新的 K 线数据点上被调用。</p>
<pre><code class="language-python hljs"><span class="hljs-keyword">from</span> quantdigger <span class="hljs-keyword">import</span> Strategy, MA, set_symbols, add_strategy, run

<span class="hljs-keyword">class</span> <span class="hljs-title class_">DemoStrategy</span>(<span class="hljs-title class_ inherited__">Strategy</span>):
    <span class="hljs-string">"""一个简单的双均线交叉策略"""</span>

    <span class="hljs-keyword">def</span> <span class="hljs-title function_">on_init</span>(<span class="hljs-params">self, ctx</span>):
        <span class="hljs-string">"""策略初始化：在这里定义技术指标"""</span>
        <span class="hljs-comment"># 计算5日收盘价移动平均线，并在图表上绘制</span>
        ctx.short_ma = MA(ctx.close, <span class="hljs-number">5</span>, <span class="hljs-string">'short_ma'</span>, plot=<span class="hljs-literal">True</span>)
        <span class="hljs-comment"># 计算20日收盘价移动平均线，并在图表上绘制</span>
        ctx.long_ma = MA(ctx.close, <span class="hljs-number">20</span>, <span class="hljs-string">'long_ma'</span>, plot=<span class="hljs-literal">True</span>)

    <span class="hljs-keyword">def</span> <span class="hljs-title function_">on_bar</span>(<span class="hljs-params">self, ctx</span>):
        <span class="hljs-string">"""K线更新回调：在这里编写交易逻辑"""</span>
        <span class="hljs-comment"># 金叉信号：短期均线上穿长期均线</span>
        <span class="hljs-keyword">if</span> ctx.short_ma > ctx.long_ma:
            ctx.buy(<span class="hljs-number">1</span>) <span class="hljs-comment"># 买入1个单位（对于股票，可理解为全仓）</span>
        <span class="hljs-comment"># 死叉信号：短期均线下穿长期均线</span>
        <span class="hljs-keyword">elif</span> ctx.short_ma < ctx.long_ma:
            ctx.sell(<span class="hljs-number">1</span>) <span class="hljs-comment"># 卖出1个单位（清仓）</span>

<span class="hljs-comment"># --- 回测设置 ---</span>
<span class="hljs-comment"># 1. 设置回测标的：平安银行(000001.SZ)，日线(D1)数据</span>
set_symbols([<span class="hljs-string">'000001.SZ'</span>], timeframe=<span class="hljs-string">'D1'</span>)

<span class="hljs-comment"># 2. 添加要运行的策略</span>
add_strategy([DemoStrategy(name=<span class="hljs-string">'均线策略'</span>)])

<span class="hljs-comment"># 3. 启动回测引擎</span>
run()
</code></pre>
<h3 id="3.-jie-du-hui-ce-jie-guo" tabindex="-1">3. 解读回测结果</h3>
<p>执行上述代码后，QuantDigger 将自动启动并渲染一个包含完整回测信息的交互式图表。您可以清晰地看到<strong>K 线上的买卖点标记、策略资金曲线、收益率统计</strong>等关键绩效指标，从而对策略的有效性做出专业评估。</p>

<h2 id="jin-jie-ying-yong-zu-he-ce-lue-yu-shen-du-ke-shi-hua" tabindex="-1">进阶应用：组合策略与深度可视化</h2>
<p>QuantDigger 的强大之处不止于单个策略的回测，它还支持更复杂的应用。</p>
<h3 id="1.-gou-jian-yu-hui-ce-tou-zi-zu-he" tabindex="-1">1. 构建与回测投资组合</h3>
<p>在真实投资中，我们通常会运行多个弱相关的策略来分散风险。QuantDigger 支持将多个策略组合成一个投资组合进行整体回测。</p>
<pre><code class="language-python hljs"><span class="hljs-comment"># 同时运行均线策略和另一个动量策略</span>
add_strategy([
    DemoStrategy(name=<span class="hljs-string">'均线策略'</span>), 
    MomentumStrategy(name=<span class="hljs-string">'动量策略'</span>)
])
</code></pre>

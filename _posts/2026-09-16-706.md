<h2>1. 为什么必须放弃第三方公共订阅转换？</h2>
<p>许多科学上网新手为了<a href="https://waynetalk.com/vpn-airport-buying-guide/">将机场订阅转为 Clash 或 Sing-box 格式</a>，习惯使用公共网页转换工具（如各类免费 <code>subconverter</code> 在线站）。</p>
<p>这存在严重的<strong>安全与隐私隐患</strong>：<br />1. <strong>订阅链接与凭证泄露</strong>：你的机场 Token、甚至带有密码的自建节点直接被第三方转换服务器记录并被黑客扫库；<br />2. <strong>中间人劫持与插桩注入</strong>：恶意转换服务器可以在下发的规则中注入重定向规则或恶意分流，盗取账号密码或挂马；<br />3. <strong>服务不稳定与频繁宕机</strong>：公共转换站经常被滥用封禁，导致客户端无法更新节点。</p>
<p><strong>Sub-Store</strong>（由 Peng-YM 团队开发）是目前业界公认最先进、功能最强大的私有<a href="https://waynetalk.com/clash-tutorial-beginners/">订阅管理</a>工具，原生支持全协议、提供现代化的 Web 交互界面与完备的 JavaScript 插件生态。</p>
<hr />

<h2>3. 核心功能实战：订阅聚合与节点自动化清洗</h2>
<p>在 Sub-Store 中，整个工作流程遵循：<code>节点源 (Subscriptions) -&gt; 集合 (Collections) -&gt; 产出订阅 (Target Profile)</code>。</p>
<h3>3.1 添加节点源与自动去重</h3>
<ol>
<li>点击左侧 <strong>“Subscriptions (订阅)”</strong>，点击右上角 <code>+</code> 号；</li>
<li>填入名称（如 <code>机场A</code>、<code>自建节点</code>），粘贴订阅链接；</li>
<li>勾选 <strong>“自动去重”</strong>，系统会自动剔除 IP、端口或 UUID 完全重复的冗余节点。</li>
</ol>
<h3>3.2 高阶玩法：使用正则表达式清洗节点垃圾名称</h3>
<p>很多机场节点名类似：</p>
<ul>
<li><code>【官网:xxx.com】香港 01 | 0.5x | 专线</code></li>
<li><code>加入TG群防失联-美国 02</code></li>
</ul>
<p>我们希望将它们统一规整为规范的：<code>🇭🇰 香港 01 [0.5x]</code> 和 <code>🇺🇸 美国 02</code>。</p>
<p>在 Sub-Store 订阅的 <strong>“节点操作 (Processors)”</strong> 中添加 <strong>正则替换 (Regex)</strong>：</p>
<h4>正则规则样例 1：清除网址、广告与群推广字符</h4>
<ul>
<li><strong>查找正则</strong>：<code>(?i)(官网|网址|防失联|TG|群|频道|http|www)[^ -]<em></code></li>
<li><strong>替换为</strong>：</em>(留空)<em></li>
</ul>
<h4>正则规则样例 2：国家/地区标准化与 Emoji 自动追加</h4>
<p>Sub-Store 内置了强大的国家地区识别插件。添加 Processor 选 <strong>“脚本操作 (Script)”</strong>，引用官方维护的地区规范化脚本：</p>
<pre><code class="language-">https://raw.githubusercontent.com/xream/scripts/main/sub-store/flag.js
</code></pre>
<p>该脚本会自动检测节点名称中的关键词（如“HK”、“东京”、“SG”、“Los Angeles”），自动在开头追加国旗 Emoji，并输出规整的名字。</p>

<h2>4. 自动化节点组合：<a href="https://waynetalk.com/703/">链式代理</a>（Proxy Chain / Relay）配置</h2>
<p>有些业务场景下，我们希望实现：</p>
<ul>
<li>前置节点为优质低延迟的<strong>香港中继</strong>；</li>
<li>后置落地节点为原生纯净的<strong>美国自建节点</strong>（用于解锁当地受限服务）。</li>
</ul>
<p>在 Sub-Store 的 <strong>“组合节点 (Relay)”</strong> 功能中：<br />1. 新建一个 Relay 节点组；<br />2. 选择前置节点池（例如选择筛选出延迟低于 100ms 的香港节点）；<br />3. 选择落地节点池（选择美国落地节点）；<br />4. Sub-Store 会自动为你编译出符合 Clash/Sing-box 规范的链式代理配置：</p>
<pre><code>   # 自动生成的 Clash Relay 策略<br /><ul><li>name: "🔗 链式中继: 香港 -&gt; 美国"</li></ul><br />     type: relay<br />     proxies:<br /><ul><li>"🇭🇰 香港 01"</li><li>"🇺🇸 美国 落地01"</li></ul><br />   </code></pre>

<h2>6. 常见故障排查（FAQ）</h2>
<h3>Q1: 订阅更新后客户端报证书错误或无法下载？</h3>
<ul>
<li><strong>解答</strong>：若在公网 VPS 部署 Sub-Store，强烈建议使用 Nginx/Caddy 配置反向代理并启用 HTTPS 证书；客户端如果使用 HTTP 链接直接拉取，某些平台（如 iOS）的安全策略会直接阻断未加密的配置更新。</li>
</ul>
<h3>Q2: 自建 Sub-Store 如何实现每日定时自动同步更新？</h3>
<ul>
<li><strong>解答</strong>：Sub-Store 容器内置了 Cron 定时任务，在“设置”中可以开启 <strong>“Sync Cron”</strong>，设置为 <code>0 4 </em> <em> </em></code>（每天凌晨 4 点自动抓取最新节点并清理失效节点），保证客户端随时拉取到的都是最新最优的节点池。</li>
</ul>

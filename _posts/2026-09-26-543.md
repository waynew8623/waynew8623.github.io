<p class="wp-block-paragraph">想拥有一个属于自己的<a href="https://waynetalk.com/free-website-guide-2026/">独立博客</a>，但一看到云服务器、域名、SSL 证书、CDN 的年费就打退堂鼓？好消息是：<strong>2026 年你完全可以用 0 元搭一个全球可访问、带HTTPS、还能绑自己域名的个人博客</strong>。核心组合就是 <a href="https://waynetalk.com/cloudflare-pages-blog-guide/">Cloudflare Pages</a>（免费静态托管）+ Hugo 或 Hexo（静态生成器）+ 免费域名/子域名绑定。</p>

<p class="wp-block-paragraph">本文适合开发者、折腾党，也适合只想安静写字的普通用户。读完你将拥有一套可长期白嫖、几乎零运维的博客系统。</p>

<h2 class="wp-block-heading">一、为什么选 Cloudflare Pages</h2>

<p class="wp-block-paragraph">Cloudflare Pages 是 Cloudflare 推出的前端托管平台，对静态站极其友好：</p>

<ul class="wp-block-list">
<li><strong>免费额度大方</strong>：无限请求数、无限站点、自动 HTTPS、全球 CDN 边缘缓存、自动 CI（连接 Git 仓库后推送即部署）。</li>
<li><strong>零运维</strong>：不用管服务器、不用配 Nginx、不用买证书。</li>
<li><strong>生态强</strong>：与 Cloudflare 的 <a href="https://waynetalk.com/546/">DNS、WAF、R2、Workers 无缝衔接</a>，本博客其他文章会用到。</li>
<li><strong>合规稳定</strong>：正规大厂服务，不像某些小众免费托管随时跑路。</li>
</ul>

<blockquote class="is-layout-flow wp-block-quote-is-layout-flow">
<p>注意区分：Cloudflare Pages 与 Cloudflare Workers 是不同的产品；本文用 Pages 托管静态站。免费层与付费 Pro 的差异以官网最新为准，个人博客通常永远用不满免费额度。</p>
</blockquote>

<h2 class="wp-block-heading">三、Hugo 建站流程</h2>

<pre><code class="language-bash"># 安装 Hugo（macOS 示例，其他平台见官网）
brew install hugo
# 或 Windows：winget install Hugo.Hugo.Extended

# 新建站点
hugo new site myblog
cd myblog

# 添加主题（以 PaperMod 为例）
git init
git submodule add https://github.com/adityatelange/hugo-PaperMod.git themes/PaperMod

# 配置 config.yaml 启用主题
echo 'theme: PaperMod' >> hugo.yaml

# 新建一篇文章
hugo new posts/hello.md

# 本地预览
hugo server -D
</code></pre>

<p class="wp-block-paragraph">构建产物在 <code>public/</code> 目录，Cloudflare Pages 只需这个目录。</p>

<pre><code class="language-yaml"># hugo.yaml 最小示例
baseURL: "https://你的域名/"
languageCode: "zh-cn"
title: "我的博客"
theme: PaperMod
</code></pre>

<h2 class="wp-block-heading">四、Hexo 建站流程</h2>

<pre><code class="language-bash">npm install -g hexo-cli
hexo init myblog
cd myblog
npm install
hexo new "hello"
hexo server      # 本地预览
hexo generate    # 生成 public/ 静态文件
</code></pre>

<h2 class="wp-block-heading">五、部署到 Cloudflare Pages</h2>

<p class="wp-block-paragraph">两种部署方式：Git 联动（推荐）与直接上传。</p>

<p class="wp-block-paragraph"><strong>方式一：连接 Git 自动部署</strong></p>

<ol class="wp-block-list">
<li><a href="https://waynetalk.com/545/">把博客推到 GitHub</a>/GitLab。</li>
<li>登录 Cloudflare 控制台 → Pages → 创建项目 → 连接仓库。</li>
<li>构建设置（以 Hugo 为例）：<br />
   &#8211; 构建命令：<code>hugo</code><br />
   &#8211; 构建输出目录：<code>public</code><br />
   &#8211; 环境变量：<code>HUGO_VERSION = 0.128.0</code>（按你的版本填）</li>
<li>点击部署，几分钟后获得 <code>xxx.pages.dev</code> 子域名。</li>
</ol>

<p class="wp-block-paragraph"><strong>Hexo 构建设置</strong>：<br />
&#8211; 构建命令：<code>hexo generate</code><br />
&#8211; 输出目录：<code>public</code></p>

<blockquote class="is-layout-flow wp-block-quote-is-layout-flow">
<p>提示：Hexo 依赖 Node，Pages 默认会用较新 Node；若失败，在环境变量设置 <code>NODE_VERSION</code>。</p>
</blockquote>

<h2 class="wp-block-heading">六、免费域名绑定方案</h2>

<p class="wp-block-paragraph">Cloudflare Pages 自带 <code>*.pages.dev</code> 免费子域名，已经能直接访问。但想要&#8221;独立域名&#8221;的体面，有三种 0 元或近 0 元方案：</p>

<ol class="wp-block-list">
<li><strong><code>.pages.dev</code> 子域</strong>：完全免费，无需任何域名。最简单。</li>
<li><strong><a href="https://waynetalk.com/221/">免费二级域名</strong>：部分服务商</a>（如 <code>eu.org</code>、<code>pp.ua</code> 等，具体以各注册局政策为准）提供免费二级域名，注册后把 DNS 托管到 Cloudflare 即可。</li>
<li><strong>低价顶级域名 + Cloudflare</strong>：<code>.top</code>、<code>.xyz</code> 等常年在促销价（注意续费价可能上涨，请以注册商最新价格为准）。</li>
</ol>

<p class="wp-block-paragraph">绑定步骤：</p>

<ol class="wp-block-list">
<li>在 Cloudflare 添加你的域名，按提示把 NS 改为 Cloudflare 的 DNS。</li>
<li>在 Pages 项目 → 自定义域 → 输入域名 → 按提示添加 CNAME 记录。</li>
<li>Cloudflare 自动签发 SSL 证书，全程免费 HTTPS。</li>
</ol>

<pre><code class="language-dns"># DNS 记录示例（在 Cloudflare 添加）
CNAME  @      <你的项目>.pages.dev
CNAME  www    <你的项目>.pages.dev
</code></pre>

<h2 class="wp-block-heading">八、FAQ</h2>

<p class="wp-block-paragraph"><strong>Q1：Cloudflare Pages 免费版有流量上限吗？</strong><br />
A：Pages 对静态站几乎不限请求数，但单文件与构建有约束（例如单个站点构建产物体积、构建时长），个人博客完全够用。具体限制以官网最新文档为准。</p>

<p class="wp-block-paragraph"><strong>Q2：不想写代码能搭吗？</strong><br />
A：可以。用 Hugo/Hexo 写 Markdown 即可，发布只是 <code>git push</code>。若连 Git 都不想碰，也有 StackEdit + 自动化发布的方案，但门槛略高。</p>

<p class="wp-block-paragraph"><strong>Q3：免费域名靠谱吗？会不会被收回？</strong><br />
A：<code>.pages.dev</code> 由 Cloudflare 提供，最稳。第三方免费二级域名受各自政策约束，存在政策变动风险，建议重要内容做好备份。</p>

<h2 class="wp-block-heading">总结</h2>

<p class="wp-block-paragraph">用 Cloudflare Pages + Hugo/Hexo，你能在 0 元预算下拥有一个全球加速、自动 HTTPS、可绑独立域名的个人独立博客。它几乎零运维、不会跑路、还能无缝衔接 R2 图床与 Workers。对想认真写字、沉淀知识的你来说，这是 2026 年性价比最高的建站方案，没有之一。</p>

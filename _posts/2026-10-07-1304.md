<h2>二、逐平台点评</h2>
<h3>1. Gemini（Google AI Studio）：免费额度天花板，新手首选</h3>
<p>Google AI Studio 的免费档是开发者社区公认的&#8221;最良心&#8221;之一：<strong>免信用卡、注册即调</strong>，免费额度按模型独立计算。Flash 系的轻量模型每天可调用约数百到上千次（参考值，Pro 系推理模型则严格得多，每天只有约几十次）。</p>
<p>优点：<br />
&#8211; 免费额度在几个大厂里属于第一梯队，个人项目、学习练手基本够用；<br />
&#8211; 模型能力覆盖全：从轻量 Flash 到强推理 Pro，还有 Gemma 开源系；<br />
&#8211; 长上下文（百万 token 级）免费档也能用，做文档问答、代码仓库分析很占便宜。</p>
<p>缺点：<br />
&#8211; <strong>免费档可能有数据用于模型改进的条款</strong>，敏感数据不要上传；可在账号设置里查看 opt-out 选项；<br />
&#8211; 国内访问需要境外网络，且免费额度按模型分开计算，超限会返回 429；<br />
&#8211; 模型版本迭代快，额度规则经常调整，要以控制台实时显示为准。</p>
<p>一句话：<strong>能接受境外网络的话，Gemini 是免费 API 的&#8221;基本盘&#8221;</strong>。</p>
<h3>2. Groq：速度之王，实时场景专用</h3>
<p>Groq 靠自研 LPU（语言处理单元）芯片跑开源模型，推理速度是全场第一梯队：输出 token 的速度肉眼可见地快。免费档同样<strong>免信用卡</strong>，按模型限速，典型约为每分钟 30 次请求、每天约 1.4 万次请求（分模型，token 维度另有限制）。</p>
<p>优点：<br />
&#8211; 速度极快，适合实时对话、语音转写、代码补全等对延迟敏感的场景；<br />
&#8211; OpenAI 兼容接口，<code>base_url</code> 换成 <code>https://api.groq.com/openai/v1</code> 即可迁移，切换成本极低；<br />
&#8211; 模型阵容是 Llama、Qwen、gpt-oss 等热门开源模型，更新及时。</p>
<p>缺点：<br />
&#8211; <strong>TPM（每分钟 token）限制是实际瓶颈</strong>：速度太快，一个请求就可能吃掉大量 token 配额，不适合长文档批量处理；<br />
&#8211; 同样需要境外网络；<br />
&#8211; 免费档的模型版本可能随官方 deprecation 计划下线，生产用要注意跟进。</p>
<p>一句话：<strong>要极致速度选 Groq，但别拿它跑大批量长文本任务</strong>。</p>
<h3>3. DeepSeek：官方超低价+注册送额度，国内直连</h3>
<p>DeepSeek 官 API（platform.deepseek.com）走 OpenAI 兼容接口，<strong>邮箱注册即可</strong>，新用户可领取约 500 万 token 的免费额度（约 30 天有效期，参考值）。用完后官方定价也是全场最低一档，适合把原型直接过渡到生产。</p>
<p>优点：<br />
&#8211; 国内直连，延迟稳定，不用折腾网络；<br />
&#8211; DeepSeek V 系列综合能力强，R 系列推理能力突出，代码和数学场景口碑好；<br />
&#8211; 免费额度 + 超低价续费，长期用成本可控。</p>
<p>缺点：<br />
&#8211; 免费额度是&#8221;送额度&#8221;形态，约 30 天过期，用完就没了，不是永久免费；<br />
&#8211; 高峰期偶有排队和降速；<br />
&#8211; 模型阵容只有自家模型，想玩 Llama、Qwen 得去别家。</p>
<p>一句话：<strong>国内用户的主力 API，免费额度先拿，长期用也便宜</strong>。本站<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/544/">《2026免费AI API汇总》</a>里也有 DeepSeek 额度领取的详细说明。</p>
<h3>4. 硅基流动：一个 Key 调几十个模型，国内聚合首选</h3>
<p>硅基流动（cloud.siliconflow.cn）是国内模型聚合平台：Qwen、DeepSeek、GLM 等几十个模型一个接口全调通。<strong>注册送约 16 元代金券</strong>，部分小模型还有长期免费档，<strong>免信用卡</strong>，国内直连。</p>
<p>优点：<br />
&#8211; 一个 API Key 调几十个模型，做模型横评、降级路由非常方便；<br />
&#8211; 国内直连 + 支付宝/微信支付，付费续费无门槛；<br />
&#8211; 部分免费模型限流宽裕，适合做 Embedding、向量检索等配套调用。</p>
<p>缺点：<br />
&#8211; 免费额度以代金券为主，用完即止，大模型烧券速度不慢；<br />
&#8211; 部分免费模型需要完成实名认证才能解锁全部；<br />
&#8211; 免费政策调整较频繁，曾有免费模型转付费的情况，关键链路不要只押一家。</p>
<p>一句话：<strong>国内想&#8221;一个接口玩遍所有模型&#8221;，选硅基流动</strong>。如果想先了解各家模型能力差异，可以看看本站的<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/532/">《主流大模型横评：OpenAI、Claude、Gemini 与开源模型各擅长什么？》</a>。</p>
<h2>三、按场景推荐：三类人三种起手式</h2>
<h3>场景一：纯新手，从零学 API 调用</h3>
<p><strong>起手式：Gemini + Groq 双持。</strong></p>
<p>先去 Google AI Studio 拿 Key 跑通第一个请求（官方 SDK 文档最友好），再注册 Groq 体验 OpenAI 兼容接口的写法。两个都是永久限速免费，学透&#8221;限速-重试-降级&#8221;这一套，之后换任何平台都不慌。</p>
<pre><code class="language-python line-numbers">from openai import OpenAI

client = OpenAI(
    base_url="https://api.groq.com/openai/v1",
    api_key="YOUR_GROQ_KEY",  # 建议用环境变量，不要硬编码
)
r = client.chat.completions.create(
    model="llama-3.3-70b-versatile",
    messages=[{"role": "user", "content": "免费大模型API哪家强？"}],
)
print(r.choices[0].message.content)
</code></pre>

<h3>场景二：独立开发者，做 side project / 小工具</h3>

<p>写一个统一的 <code>call_llm(provider, model, prompt)</code> 适配器，捕获 429（Too Many Requests）后退避重试或切换备用 Key。实战里常见的组合还包括：把 AI 能力接到<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/528/">用 n8n 搭建的 Telegram 客服 Bot</a>、或者接到 <a class="wp-editor-md-post-content-link" href="https://waynetalk.com/534/">Cursor 这类 AI 编程工具</a>的工作流里，免费额度足够把 MVP 跑起来。</p>
<h3>场景三：国内用户，不想折腾网络</h3>
<p><strong>起手式：DeepSeek 官 API + 硅基流动。</strong></p>
<p>DeepSeek 负责主力对话和推理，硅基流动负责模型聚合和 Embedding 等配套调用。两个都国内直连，注册都不需要信用卡，额度叠加后个人项目基本够用。隐私要求高的场景，还可以考虑<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/533/">本地部署 Ollama</a>，零调用成本。</p>
<h2>四、常见问题 FAQ</h2>
<p><strong>Q1：这四家真的都不需要信用卡吗？</strong><br />
是的。Gemini、Groq 免信用卡是长期政策；DeepSeek、硅基流动用国内支付体系，也不需要绑卡。注册即可拿到 API Key 开始调用。</p>
<p><strong>Q2：免费额度用完会怎样？会自动扣费吗？</strong><br />
不会。四家的免费档都是&#8221;用完即停&#8221;：返回 429 或额度耗尽错误，不会自动扣费（因为你根本没绑支付方式）。想继续用，要么等额度重置，要么手动充值。</p>
<p><strong>Q3：国内直连的只有 DeepSeek 和硅基流动吗？</strong><br />
在本文横评的四家里是的。Gemini 和 Groq 需要稳定的境外网络才能调用。如果你在国内且不想折腾网络，优先 DeepSeek + 硅基流动。</p>
<p><strong>Q4：免费 API 能用于商业项目吗？</strong><br />
要看各家条款：Groq 免费档明确面向个人和非商业项目；Gemini 免费档有数据使用方面的附加条款。<strong>正式商用前务必阅读各平台最新的服务条款</strong>，小流量 MVP 可以先跑，起量后建议切付费档。</p>
<p><strong>Q5：429 报错（Too Many Requests）怎么办？</strong><br />
这是触发限速的标志。正确姿势：指数退避重试（等几秒再试）、降低并发、把请求分散到多个平台（比如 Gemini 429 了就切 Groq）。不要写死循环猛刷，可能被临时封禁。</p>
<p><strong>Q6：哪个平台的模型中文效果最好？</strong><br />
综合来看：DeepSeek 中文代码和推理口碑最好；硅基流动聚合的 Qwen、GLM 系中文表现强；Gemini 中文能力也不弱。建议用你的实际 prompt 在几家都跑一遍，效果差异比榜单排名更真实。</p>
<p><strong>Q7：免费额度政策变得快，怎么跟进？</strong><br />
认准各平台官方文档和控制台的实时额度显示，不要依赖任何第三方文章里的具体数字（包括本文）。本站的<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/544/">免费 AI API 汇总</a>会定期刷新，也可以订阅各平台的更新日志。</p>
<p><strong>Q8：除了这四家，还有值得关注的免费 API 吗？</strong><br />
有。Mistral 的 Experiment 计划、Cerebras 的每日免费 token、OpenRouter 的免费模型、智谱 GLM 的免费档都值得一看，完整清单见<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/544/">《2026免费AI API汇总：18个平台额度实测》</a>。</p>

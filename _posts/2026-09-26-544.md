<h2>一、先搞清楚&#8221;免费&#8221;的三种形态</h2>
<p>混用这些概念最容易踩坑，先对齐术语：</p>
<ul>
<li><strong>永久限速免费</strong>：不收钱、不限期，但限制每分钟/每天请求数。适合开发、演示、低流量场景。</li>
<li><strong>注册送额度</strong>：给一笔虚拟额度，用完或过期即止。本质是试用金，不是永久容量。</li>
<li><strong><a href="https://waynetalk.com/533/">开源自部署</strong>：模型权重免费</a>，但服务器和算力成本自己担。</li>
</ul>
<p>工程建议：原型阶段用&#8221;永久限速免费&#8221;；上线前评估付费档；<strong>不要把试用金当成生产容量</strong>。</p>

<h2>三、按场景选：四类人四种起手式</h2>
<h3>1. 纯新手：Google AI Studio（Gemini）起步</h3>
<p>最慷慨的免费档之一，<strong>无需信用卡</strong>，拿到 API Key 即用，文档友好，OpenAI 兼容风格便于日后切换。</p>
<pre><code class="language-bash">pip install google-generativeai
export GEMINI_API_KEY=<redacted>
</code></pre>
<pre><code class="language-python">import google.generativeai as genai
genai.configure(api_key="YOUR_KEY")
model = genai.GenerativeModel("gemini-2.5-flash")
print(model.generate_content("用一句话介绍免费API").text)
</code></pre>
<p>注意：免费档可能有&#8221;数据用于改进模型&#8221;条款，敏感数据请勿上传；可在账号设置中查看 opt-out 选项（以官网为准）。</p>
<h3>2. 国内直连、不用翻墙：硅基流动 + 火山方舟 + 智谱</h3>
<p>这是本次升级新增的重点。<strong>硅基流动</strong>注册送约 14–16 元代金券，部分小模型长期免费，国内直连速度最稳；<strong>火山方舟</strong>每模型约 50 万 token，学生认证额度更高；<strong>智谱</strong>的 GLM-4-Flash 有永久免费档。三个都注册一遍，额度叠加非常可观。</p>
<h3>3. 要极速：Groq / Cerebras</h3>

<pre><code class="language-bash">pip install openai

<h2>五、把多个免费额度&#8221;叠&#8221;起来用</h2>
<p>个人项目常见架构：<strong>Gemini 做主模型，Groq 做低延迟兜底，DeepSeek 做代码专项，硅基流动做国内备用，OpenRouter 做降级路由</strong>。关键点：</p>
<ul>
<li><strong>统一封装</strong>：写一个 <code>call_llm(provider, model, prompt)</code> 适配器，按可用性切换。</li>
<li><strong>限速兜底</strong>：捕获 429（Too Many Requests），退避重试或换备用 Key。</li>
<li><strong>缓存</strong>：对相同 prompt 做结果缓存（SQLite/Redis），显著省额度。</li>
</ul>
<pre><code class="language-python">import time

PROVIDERS = ["gemini", "groq", "deepseek", "siliconflow"]  # 按优先级排序

def call_with_fallback(prompt):
    for p in PROVIDERS:
        try:
            return do_call(p, prompt)
        except RateLimitError:
            time.sleep(1)  # 简单退避，生产环境建议指数退避
            continue
    raise RuntimeError("所有免费额度均被限速")
</code></pre>
<h2>六、合规与风险提醒</h2>
<ul>
<li><strong>不要盗刷额度</strong>：用脚本恶意刷量违反条款，会被封号且可能追责。</li>
<li><strong>敏感数据</strong>：免费档可能允许厂商用于训练，合同/用户隐私数据请勿上传。</li>
<li><strong>生产稳定性</strong>：免费档无 SLA，别把它当核心生产依赖。</li>
<li><strong>计费意外</strong>：绑定过信用卡的试用可能超额自动扣费，务必设置预算告警。</li>
</ul>
<h2>七、FAQ</h2>
<p><strong>Q1：哪个免费 AI API 最适合新手？</strong><br />
A：Google AI Studio（Gemini）无需信用卡、文档友好、模型强，是首选；想要极速对话体验再叠一个 Groq。</p>
<p><strong>Q2：不用信用卡、不用翻墙，有哪些可选？</strong><br />
A：硅基流动、ModelScope 魔搭、DeepSeek（邮箱注册即用）；智谱、火山方舟、阿里云百炼需实名但无需信用卡。</p>
<p><strong>Q3：免费额度够跑一个线上小应用吗？</strong><br />
A：低流量（每天几百次调用）通常够。一旦增长，建议升级付费档或做缓存+兜底路由，避免 429 影响体验。</p>
<p><strong>Q4：有免费的 AI 绘画 / TTS API 吗？</strong><br />
A：有。绘画用 Pollinations（免 Key）或 Cloudflare Workers AI 的 FLUX；TTS 用 Edge TTS 或 Pollinations 语音接口。</p>
<p><strong>Q5：免费 API 能用于商业项目吗？</strong><br />
A：看具体条款，多数免费档允许轻量商业用途，但<strong>无 SLA、无技术支持</strong>，正式商用建议切付费档。</p>
<p><strong>Q6：遇到 429 限速怎么办？</strong><br />
A：三板斧：指数退避重试、多 Key 轮换、多平台 fallback。代码示例见第五节。</p>
<p><strong>Q7：模型版本怎么选？</strong><br />
A：以各平台控制台当前可用模型为准。免费档常覆盖 Flash/小参数/开源模型，旗舰模型多放在付费档。</p>
<p><strong>Q8：额度政策多久会变？本文多久更新？</strong><br />
A：免费政策调整非常频繁，本文按月复核更新，文末有更新日志。动手前务必再去官网核对一次。</p>

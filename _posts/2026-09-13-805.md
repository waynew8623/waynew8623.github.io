<h2>一、 部署准备与架构概述</h2>
<p>cfblog 是一套现代化的无服务器（Serverless）博客系统，深度整合了 GitHub 自动化流水线与 Cloudflare 的全球边缘计算及分布式存储能力。</p>
<p><img decoding="async" alt="cfblog 系统架构与效果概览" src="https://waynetalk.com/wp-content/uploads/2026/09/cfblog-guide_01.jpg" /></p>
<p>在正式开始配置前，请确保您已准备好以下环境与权限：</p>
<ul>
<li>拥有一个有效的 GitHub 账号。</li>
<li>拥有一个已注册并完成基础配置的 Cloudflare 账号。</li>
</ul>
<hr />
<h2>二、 核心部署步骤与实操指南</h2>
<p>整个部署流程主要分为代码仓库初始化、Cloudflare 凭证配置、存储绑定以及自动化部署四个核心阶段。</p>
<p><img decoding="async" alt="cfblog搭建步骤全景" src="https://waynetalk.com/wp-content/uploads/2026/09/cfblog-guide_02.jpg" /></p>
<h3>步骤 1：获取并克隆开源项目仓库</h3>
<p>首先，在 GitHub 上访问 cfblog 官方开源项目页面。</p>
<p><img decoding="async" alt="在 GitHub 查找开源项目" src="https://waynetalk.com/wp-content/uploads/2026/09/cfblog-guide_03.jpg" /></p>
<p>点击页面右上角的 <strong>Fork</strong> 按钮，将该项目完整复制到您自己的 GitHub 账号仓库中。</p>
<p><img decoding="async" alt="点击 Fork 按钮复制项目" src="https://waynetalk.com/wp-content/uploads/2026/09/cfblog-guide_04.jpg" /></p>
<h3>步骤 2：获取 Cloudflare 凭证与鉴权配置</h3>

</ol>
<p><img decoding="async" alt="配置 Workers 与 D1 权限" src="https://waynetalk.com/wp-content/uploads/2026/09/cfblog-guide_06.jpg" /></p>
<ol>
<li>记录生成的 API Token 字符串。</li>

<p><img decoding="async" alt="生成 JWT_SECRET 加密密钥" src="https://waynetalk.com/wp-content/uploads/2026/09/cfblog-guide_08.jpg" /></p>
<h3>步骤 3：配置 GitHub Repository Secrets</h3>
<p>进入您 Fork 后的 GitHub 仓库，依次点击 <code>Settings</code> -> <code>Secrets and variables</code> -> <code>Actions</code>。<br />
新建以下三个仓库密钥（Repository secrets）：</p>
<ul>
<li><code>CLOUDFLARE_ACCOUNT_ID</code></li>
<li><code>CLOUDFLARE_API_TOKEN</code></li>
<li><code>JWT_SECRET</code></li>
</ul>
<p>将上一步获取的对应值粘贴并保存。</p>
<p><img decoding="async" alt="新建三个 Repository secrets" src="https://waynetalk.com/wp-content/uploads/2026/09/cfblog-guide_09.jpg" /></p>

<h2>三、 常见误区与避坑建议</h2>
<blockquote><p>
<strong>避坑提示</strong>：</p>
<ul>
<li><strong>权限配置遗漏</strong>：在创建 Cloudflare API Token 时，必须同时勾选 Workers 边缘脚本编辑与 D1 数据库管理权限，否则 GitHub Actions 在执行数据库迁移或脚本发布时会报鉴权失败错误。</li>
<li><strong>密钥匹配校验</strong>：请核对 GitHub Secrets 中的变量名是否与代码库及工作流文件中的大小写完全一致。</li>
</ul>
</blockquote>

<h2>常见问题解答（FAQ）</h2>
<h3>Q1: 部署 cfblog 需要购买云服务器（VPS）吗？</h3>
<p>A: 完全不需要。cfblog 基于 Cloudflare Workers 无服务器架构运行，并借助 GitHub Actions 实现自动化部署，无需维护任何传统服务器，零服务器成本即可运行。</p>
<h3>Q2: 博客文章和静态资源保存在哪里？</h3>
<p>A: 博客文章的元数据和结构化内容存储在 Cloudflare D1 关系型数据库中，而上传的图片等媒体附件则通过 Cloudflare R2 对象存储进行托管，具备极高的可靠性与全球分发速度。</p>
<h3>Q3: 部署完成后如何绑定自己的独立域名？</h3>
<p>A: 登录 Cloudflare 控制台，进入刚刚生成的 Worker 应用设置页面，选择“自定义域名（Custom Domains）”选项卡，按照提示输入您的域名并完成 DNS 绑定即可直接访问。</p>

<h2 class="wp-block-heading">架构</h2>

<pre><code>网站表单（Webflow/WordPress/自建）提交
   │ Webhook
   ▼
n8n：校验 → 富化（邮箱/域名→公司画像）→ 打分 → 写入 Airtable → 通知销售
</code></pre>

<h2 class="wp-block-heading">第一步：表单提交触发 Webhook</h2>

<p class="wp-block-paragraph">表单提交后 POST 到 n8n：</p>

<pre><code>POST https://n8n.example.com/webhook/lead-in
Content-Type: application/json
{
  "email": "jane@acme.com",
  "name": "Jane Doe",
  "message": "想了解企业版报价",
  "plan": "enterprise"
}
</code></pre>

<p class="wp-block-paragraph">n8n <strong>Webhook</strong> 节点 <code>Response Mode</code> 设 <code>Respond Immediately</code> 返回成功，富化异步进行。</p>

<h2 class="wp-block-heading">第二步：数据校验与去重</h2>

<p class="wp-block-paragraph">用 <strong>Filter</strong> 节点拦截无效邮箱（正则）：</p>

<pre><code class="language-regex">^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$
</code></pre>

<p class="wp-block-paragraph">提取公司域名：从 <code>email</code> 取 <code>@</code> 之后部分。</p>

<pre><code class="language-javascript">const email = <span class="katex math inline">json.email;
const domain = email.split('@')[1]?.toLowerCase();
const isFree = ['gmail.com','qq.com','163.com','outlook.com'].includes(domain);
return [{ json: { ...</span>json, domain, isFreeMail: isFree } }];
</code></pre>

<p class="wp-block-paragraph">去重：用 Airtable <code>Find</code> 查是否已存在该邮箱，存在则走「更新」分支而非新建。</p>

<h2 class="wp-block-heading">第三步：富化公司画像（核心）</h2>

<p class="wp-block-paragraph">用域名调用富化 API（如 Clearbit、Apollo 或自建数据源），以 HTTP Request 为例：</p>

<pre><code>GET https://person.clearbit.com/v2/combined/find?email={{ <span class="katex math inline">json.email }}
Headers: Authorization: Bearer {{</span>env.CLEARBIT_KEY }}
</code></pre>

<p class="wp-block-paragraph">把返回映射到字段：</p>

<ul class="wp-block-list">
<li><code>company_name</code> ← <code>company.name</code></li>
<li><code>company_domain</code> ← <code>company.domain</code></li>
<li><code>industry</code> ← <code>company.category.industry</code></li>
<li><code>employees</code> ← <code>company.metrics.employees</code></li>
<li><code>country</code> ← <code>company.geo.country</code></li>
<li><code>linkedin</code> ← <code>company.linkedin.handle</code></li>
</ul>

<blockquote class="is-layout-flow wp-block-quote-is-layout-flow">
<p>若不用第三方，也可以用搜索引擎 + <a href="https://waynetalk.com/530/">网页抓取</a>自建轻量富化，注意遵守对方 robots 与隐私政策，仅用于已授权线索。</p>
</blockquote>

<h2 class="wp-block-heading">第四步：意向评分（Lead Scoring）</h2>

<p class="wp-block-paragraph">用 <strong>Code</strong> 节点按规则打分，方便销售排序：</p>

<pre><code class="language-javascript">let score = 0;
const j = $json;
if (!j.isFreeMail) score += 20;          // 企业邮箱加分
if (j.employees > 200) score += 20;       // 中大型企业
if (j.plan === 'enterprise') score += 30; // 明确企业版意向
if (/报价|采购|预算|POC/i.test(j.message || '')) score += 20; // 采购信号词
if (j.country === 'CN' || j.country === 'US') score += 10;
let level = score >= 70 ? 'A' : score >= 40 ? 'B' : 'C';
return [{ json: { ...j, score, level } }];
</code></pre>

<h2 class="wp-block-heading">第五步：写入 Airtable</h2>

<p class="wp-block-paragraph">Airtable 节点（或用 HTTP Request 调 REST API）：</p>

<pre><code>POST https://api.airtable.com/v0/{{ BASE_ID }}/Leads
Headers: Authorization: Bearer {{ <span class="katex math inline">env.AIRTABLE_TOKEN }}
Body:
{
  "fields": {
    "姓名": "{{</span>json.name }}",
    "邮箱": "{{ <span class="katex math inline">json.email }}",
    "公司": "{{</span>json.company_name }}",
    "行业": "{{ <span class="katex math inline">json.industry }}",
    "规模": "{{</span>json.employees }}",
    "国家": "{{ <span class="katex math inline">json.country }}",
    "意向等级": "{{</span>json.level }}",
    "评分": "{{ <span class="katex math inline">json.score }}",
    "来源": "独立站表单",
    "留言": "{{</span>json.message }}",
    "创建时间": "{{ $now.toISO() }}"
  }
}
</code></pre>

<p class="wp-block-paragraph">若去重命中，改用 <code>PATCH</code> 更新对应记录。</p>

<h2 class="wp-block-heading">第七步：防止垃圾询盘</h2>

<ul class="wp-block-list">
<li>** honeypot 字段**：表单藏一个隐藏输入框，机器人填了就丢弃。</li>
<li><strong>限流</strong>：同一 IP/域名 1 分钟内多次提交直接忽略。</li>
<li><strong>验证码</strong>：前端加 Turnstile/hCaptcha，n8n 侧校验 token。</li>
</ul>

<p class="wp-block-paragraph">表单只是入口，富化与评分才是转化引擎。这条 n8n 线索流让每条询盘在秒级内变成「带公司背景 + 意向等级」的可跟进记录，销售从「找信息」变成「直接谈」。</p>

<h2 class="wp-block-heading">FAQ</h2>

<p class="wp-block-paragraph"><strong>Q1：富化 API 一定要付费吗？</strong><br />
不一定。免费邮箱可跳过公司富化，仅做基础打分；轻度使用可选有免费额度的服务，或用公开数据自建轻量富化。注意数据合规。</p>

<p class="wp-block-paragraph"><strong>Q2：Airtable 免费版够用吗？</strong><br />
免费版单基 1000 条记录、限 5 个编辑者。线索量小可接受；量大建议付费版或迁移到 Postgres/飞书多维表格。</p>

<p class="wp-block-paragraph"><strong>Q3：如何避免重复线索刷分？</strong><br />
在第二步用 Airtable <code>Find</code> 查重，命中走「更新 + 累加互动分」分支，不新建记录，保证同一客户唯一。</p>

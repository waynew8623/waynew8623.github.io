<p>核心摘要：<br />
&#8211; <strong>全程 0 元</strong>：免费域名申请 + Hugo 静态博客生成 + Cloudflare Pages 托管 + 免费 HTTPS，一个下午即可上线个人博客。<br />
&#8211; <strong>免费域名现状</strong>：Freenom 已停止新注册，当前靠谱渠道是免费二级域名——EU.org（永久免费、审核慢）、deSEC 的 dedyn.io（注册即用、支持隐私）、Gname 的 eu.cc（秒托管 Cloudflare）。<br />
&#8211; <strong>Hugo 博客搭建教程核心就三步</strong>：<code>hugo new site</code> 建站 → 套一个主题 → <code>hugo new posts</code> 写 Markdown 文章，本地 <code>hugo server</code> 实时预览。<br />
&#8211; <strong>Cloudflare Pages 部署零运维</strong>：连 GitHub 仓库，构建命令 <code>hugo --gc --minify</code>，push 即自动上线；绑定自定义域名后 SSL 证书自动签发。</p>
<p>想做个人博客、作品集或技术笔记站，最大的心理障碍往往不是&#8221;不会写代码&#8221;，而是觉得建站很贵、很麻烦：买域名、租服务器、配环境、续费续SSL……其实在 2026 年，这套流程已经可以完全免费跑通。</p>
<p>原理很简单：<strong>静态网站不需要服务器</strong>。Hugo 把你写的 Markdown 文章在本地编译成纯 HTML，Cloudflare Pages 负责把这些文件免费托管到全球 CDN，域名则用免费二级域名代替。全程不掏一分钱，而且速度比很多付费虚拟主机还快。</p>
<blockquote><p>
  重要提醒：免费二级域名的所有权在服务商手里，适合个人博客、作品集、学习实验；如果要做长期经营的项目，建议后续换成几十元一年的付费顶级域名。
</p></blockquote>
<h2>一、全流程总览：四步上站</h2>
<p>整个流程按顺序只有四步，耗时约 1–2 小时（不含域名审核等待）：</p>
<ol>
<li><strong>申请免费域名</strong>：选一个免费二级域名渠道（如 eu.cc / eu.org / dedyn.io）。</li>
<li><strong>本地用 Hugo 生成博客</strong>：安装 Hugo → 创建站点 → 安装主题 → 写第一篇文章。</li>
<li><strong>推到 GitHub，Cloudflare Pages 自动部署</strong>：连仓库、填构建参数，push 即上线。</li>
<li><strong>绑定域名 + 开启 HTTPS</strong>：在 Pages 里添加自定义域名，Cloudflare 自动完成 DNS 与 SSL。</li>
</ol>
<p>如果你之前按本站的 <a class="wp-editor-md-post-content-link" href="https://waynetalk.com/543/">0 元搭建个人独立博客：Cloudflare Pages + Hugo/Hexo + 免费域名绑定</a> 跑过类似流程，会发现思路完全相通——本文是面向 2026 年的完整重写版，渠道和细节都按现状刷新。</p>

<h3>渠道 1：EU.org（稳妥派首选）</h3>
<p>访问 <code>nic.eu.org</code> 注册账号 → 提交域名申请（如 <code>myblog.eu.org</code>）→ 等待人工审核。审核周期一般 1–4 周，通过后把域名的 NS 记录改成 Cloudflare 分配的即可托管。适合不着急、追求长期稳定的博客。</p>
<h3>渠道 2：Gname eu.cc（最快上手）</h3>
<p>注册账号后即可免费注册 eu.cc 二级域名（一般每人限 3 个左右，以官网为准），DNS 可直接托管到 Cloudflare，之后 Pages 绑定、SSL 全流程无缝。本站之前详细介绍过：<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/221/">GNAME 推出免费二级域名 eu.cc：秒托管 CF，永久免费续费教程</a>。</p>
<h3>渠道 3：deSEC dedyn.io（隐私派）</h3>
<p>deSEC 是欧洲的免费 DNS 服务商，注册账号后可直接添加 <code>dedyn.io</code> 下的二级域名，支持 A/AAAA/CNAME/TXT 全类型解析，一个免费账号可添加约 15 个域名。同样可以把 NS 或解析指向 Cloudflare 使用。</p>
<blockquote><p>
  免费域名的三个坑：①所有权不在你手里，服务商可随时收回；②部分后缀曾被滥用，搜索引擎权重一般；③不要在上面放重要数据。记住&#8221;备份内容，域名可换&#8221;即可。
</p></blockquote>
<h2>三、Hugo 博客搭建教程：本地三步走</h2>
<p><a class="wp-editor-md-post-content-link" href="https://gohugo.io">Hugo</a> 是用 Go 写的静态站点生成器，最大优点是<strong>快</strong>：一个二进制文件、无需装运行时，几千篇文章几秒钟编译完。它也是个人博客搭建里生态最成熟的方案之一（主题数千款）。</p>
<h3>第 1 步：安装 Hugo</h3>
<ul>
<li><strong>Windows</strong>：<code>winget install Hugo.Hugo.Extended</code>（或去官网下载 extended 版解压）</li>
<li><strong>macOS</strong>：<code>brew install hugo</code></li>
<li><strong>Linux</strong>：<code>sudo apt install hugo</code>（建议用官网最新版，仓库版可能偏旧）</li>
</ul>
<p>验证：<code>hugo version</code> 能输出版本号即成功。注意 Cloudflare Pages 构建时最好用 <strong>Extended 版</strong>对应版本，后文会讲如何锁定。</p>
<h3>第 2 步：创建站点并安装主题</h3>
<pre><code class="language-bash line-numbers">hugo new site myblog
cd myblog
git init
# 以 PaperMod（最受欢迎的博客主题之一）为例
git submodule add --depth=1 https://github.com/adityatelange/hugo-PaperMod.git themes/PaperMod
echo "theme = 'PaperMod'" >> hugo.toml
</code></pre>
<p>然后按主题文档配置 <code>hugo.toml</code>（站点标题、菜单、作者信息等），每个主题的配置项略有不同，照着主题的 README 抄一遍即可。</p>
<h3>第 3 步：写第一篇文章并本地预览</h3>
<pre><code class="language-bash line-numbers">hugo new posts/hello-world.md
</code></pre>
<p>用编辑器打开 <code>content/posts/hello-world.md</code>，Front Matter 之后就是正文，直接写 Markdown：</p>
<pre><code class="language-markdown line-numbers">---
title: "你好，世界"
date: 2026-09-30T10:00:00+08:00
draft: false
---

这是我的第一篇博客文章，用 Markdown 写作，真香。
</code></pre>
<p>启动本地预览：</p>
<pre><code class="language-bash line-numbers">hugo server
</code></pre>
<p>浏览器打开 <code>http://localhost:1313</code>，改文章保存后页面自动刷新。确认样式没问题后，把站点推到 GitHub：</p>
<pre><code class="language-bash line-numbers">git add -A
git commit -m "init: my hugo blog"
git branch -M main
git remote add origin git@github.com:你的用户名/myblog.git
git push -u origin main
</code></pre>
<p>之后写博客的日常流程就是：新建 md 文件 → 本地预览 → <code>git push</code>，剩下的交给 Cloudflare。</p>
<h2>四、Cloudflare Pages 部署：push 即上线</h2>
<p>Cloudflare Pages 是 Cloudflare 的静态托管服务，免费版对个人博客完全够用：不限站点数、不限流量，构建次数每月也有充足额度。操作步骤：</p>
<ol>
<li>注册/登录 <a class="wp-editor-md-post-content-link" href="https://dash.cloudflare.com">Cloudflare</a>，进入 <strong>Workers &#038; Pages</strong>。</li>
<li>点击 <strong>创建应用程序 → Pages → 连接到 Git</strong>，授权 GitHub 并选择你的博客仓库。</li>
<li>构建设置：</li>

<li><strong>锁定 Hugo 版本</strong>（关键一步）：Cloudflare 默认的 Hugo 版本可能比你本地旧，导致构建失败。去项目 <strong>设置 → 环境变量</strong> 添加 <code>HUGO_VERSION</code>，值填你本地 <code>hugo version</code> 的版本号（例如 <code>0.1xx.x</code>，Extended 版不用加后缀）。</li>
<li>点击 <strong>保存并部署</strong>。首次构建约 1–2 分钟，成功后你会得到一个 <code>你的项目.pages.dev</code> 的临时域名，博客已经全球可访问。</li>
</ol>
<p>从此以后，每次 <code>git push</code> 到 main 分支，Cloudflare Pages 都会自动重新构建并发布——这就是&#8221;无运维&#8221;博客的日常。</p>

<h2>五、绑定免费域名 + 全站 HTTPS</h2>
<p>有了 <code>xxx.pages.dev</code> 还不够，绑上自己的域名才像个真正的博客：</p>
<ol>
<li>在 Pages 项目中进入 <strong>自定义域 → 设置自定义域</strong>，输入你的免费域名（如 <code>myblog.eu.cc</code>）。</li>
<li>如果域名 DNS 已经托管在 Cloudflare，系统会自动创建 CNAME 记录，几秒钟生效；如果 DNS 还在服务商处，按提示手动添加一条 CNAME 指向 <code>你的项目.pages.dev</code>。</li>
<li><strong>HTTPS 全自动</strong>：Cloudflare 会为自定义域自动签发 SSL 证书，无需任何操作。建议在 Cloudflare 的 SSL/TLS 设置里把加密模式设为&#8221;完全（严格）&#8221;。</li>
</ol>
<p>至此，一个拥有独立域名、全球 CDN 加速、自动 HTTPS 的个人博客正式上线，总花费：<strong>0 元</strong>。</p>
<p>顺带一提，Cloudflare 还提供免费的域名邮箱转发（Email Routing），<code>admin@你的域名</code> 可以转发到你的 Gmail/QQ 邮箱，博客的联系邮箱也有了着落。</p>
<h2>六、常见问题与避坑</h2>
<ul>
<li><strong>构建失败 90% 是 Hugo 版本问题</strong>：本地和云端版本不一致最常见，务必设置 <code>HUGO_VERSION</code> 环境变量并与本地保持一致。</li>
<li><strong><code>pages.dev</code> 域名被墙？</strong>：Cloudflare 的 <code>pages.dev</code> 后缀在国内访问偶有不稳定，这正是要绑定自定义域名的原因之一；自定义域名经 Cloudflare CDN 后访问质量通常更好。</li>
<li><strong>主题更新</strong>：用 git submodule 安装的主题，执行 <code>git submodule update --remote</code> 即可升级，升级前先在本地预览确认无样式错乱。</li>
<li><strong>文章图片怎么放</strong>：把图片放进 <code>static/images/</code> 目录，Markdown 里用 <code>/images/xxx.png</code> 引用；想用对象存储做图床，可以看本站的 <a class="wp-editor-md-post-content-link" href="https://waynetalk.com/546/">Cloudflare R2 + PicGo 免费图床方案</a>。</li>
<li><strong>换电脑写博客</strong>：仓库 clone 下来，装好 Hugo 就能继续写——这也是&#8221;博客即代码&#8221;工作流的优势。</li>
</ul>

<h2>七、FAQ</h2>
<p><strong>Q1：免费建站真的完全不用花钱吗？</strong><br />
A：是的。本文方案中域名（免费二级域名）、托管（Cloudflare Pages 免费版）、SSL 证书、CDN 全部免费。唯一的&#8221;成本&#8221;是你的时间，以及一个 GitHub 账号和一个邮箱。</p>
<p><strong>Q2：免费域名申请会被拒绝吗？</strong><br />
A：有可能。EU.org 是人工审核，名字太短、含义不明或疑似抢注的可能被拒，建议用&#8221;名字+blog&#8221;这类有明确个人用途的组合。Gname eu.cc 和 deSEC dedyn.io 是注册即用，被拒概率低。</p>
<p><strong>Q3：Hugo 和 Hexo/WordPress 怎么选？</strong><br />
A：追求速度和零运维选 Hugo（单文件、编译极快）；熟悉 Node.js 生态选 Hexo；需要后台管理、可视化编辑和插件生态选 WordPress（但需要服务器或托管费用）。纯个人博客场景，Hugo + Cloudflare Pages 是性价比最高的组合。</p>
<p><strong>Q4：博客内容会被搜索引擎收录吗？</strong><br />
A：会。Cloudflare Pages 默认允许爬虫，Hugo 主题一般自带 sitemap 和 RSS。免费二级域名的收录权重不如付费顶级域名，但正常提交 Search Console 后收录没问题。做 SEO 长期经营的话，建议日后升级付费域名并做 301 跳转。</p>
<p><strong>Q5：不懂 Git 和命令行能建站吗？</strong><br />
A：Hugo 方案需要最基础的命令行操作（复制粘贴命令即可）。如果完全不想碰终端，可以考虑 Cloudflare Pages 的&#8221;直接上传&#8221;模式（把本地 <code>public</code> 文件夹拖进去部署），但会失去自动部署的便利。</p>
<p><strong>Q6：以后想换付费域名麻烦吗？</strong><br />
A：不麻烦。在 Pages 的自定义域里添加新域名、把 Hugo 配置里的 <code>baseURL</code> 改掉、旧域名做 301 跳转到新域名即可，文章内容零改动。</p>
<h2>八、总结</h2>
<p>零成本建站的公式就是：<strong>免费二级域名（eu.cc/eu.org/dedyn.io）+ Hugo 本地生成 + Cloudflare Pages 免费托管 + 自动 HTTPS</strong>。没有服务器续费压力，没有环境配置地狱，写博客回归到&#8221;写 Markdown、git push&#8221;这两件事。</p>
<p>建议的行动顺序：今天先花 20 分钟把 Hugo 本地跑起来、看到第一篇文章在浏览器里渲染出来；域名可以同步去申请（EU.org 审核慢，先用 <code>pages.dev</code> 临时域名不耽误写作）。等域名下来再绑定，全程无缝。</p>
<p>建站只是起点，持续输出才是博客的生命线。先让网站上线，再慢慢打磨——祝你的博客早日开张。</p>

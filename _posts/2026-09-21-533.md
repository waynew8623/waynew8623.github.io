<h2 class="wp-block-heading">引言：你的聊天记录，凭什么上传到别人的服务器？</h2>

<p class="wp-block-paragraph">用云端大模型很方便，但代价是：你输入的每一段文字、每一份合同、每一行代码，都可能经过第三方服务器。对开发者、律师、医生和<a href="https://waynetalk.com/902/">重视隐私</a>的个人来说，这是不可接受的风险。</p>

<p class="wp-block-paragraph">好消息是，2026 年的本地推理已经足够成熟。借助 <strong>Ollama</strong>（模型运行底座）和 <strong>Open WebUI</strong>（类 ChatGPT 的聊天界面），你可以用一条命令拉起一个&#8221;完全离线、数据不出域&#8221;的私有 ChatGPT。本教程从零讲清楚：装什么、怎么装、<a href="https://waynetalk.com/532/">选哪个模型</a>、如何对外提供 API。</p>

<h2 class="wp-block-heading">一、方案全景：Ollama 与 Open WebUI 各自负责什么？</h2>

<ul class="wp-block-list">
<li><strong>Ollama</strong>：本地大模型运行引擎，负责拉取、加载、量化推理。支持 Qwen3、Llama 4、DeepSeek、Gemma、Phi 等数百种开放权重模型，自动处理量化和硬件加速。</li>
<li><strong>Open WebUI</strong>：基于 Web 的聊天前端，提供对话界面、<a href="https://waynetalk.com/535/">多模型切换、知识库（RAG）</a>、用户管理、工具调用等，体验接近 ChatGPT，但数据全在本地。</li>
<li><strong>组合价值</strong>：Ollama 管&#8221;模型怎么跑&#8221;，Open WebUI 管&#8221;人怎么用&#8221;。两者通过本地端口通信，全程无需联网（首次下载模型除外）。</li>
</ul>

<h2 class="wp-block-heading">三、Step 1：安装并启动 Ollama</h2>

<h3 class="wp-block-heading">方式 A：原生安装（最简单）</h3>

<p class="wp-block-paragraph">Windows / macOS 访问 <a href="https://ollama.com">ollama.com</a> 下载安装包，一路下一步即可。Linux 用脚本：</p>

<pre><code class="language-bash">curl -fsSL https://ollama.com/install.sh | sh
</code></pre>

<p class="wp-block-paragraph">启动并验证：</p>

<pre><code class="language-bash"># 查看 Ollama 服务状态
ollama --version

# 拉取并运行一个模型（以 Qwen3-8B 为例）
ollama pull qwen3:8b
ollama run qwen3:8b
</code></pre>

<p class="wp-block-paragraph">进入交互界面后直接输入问题即可对话。输入 <code>/bye</code> 退出。</p>

<h3 class="wp-block-heading">方式 B：Docker 部署（服务器推荐）</h3>

<pre><code class="language-bash">docker run -d \
  --name ollama \
  -p 11434:11434 \
  --gpus all \
  -v ollama_data:/root/.ollama \
  ollama/ollama
</code></pre>

<h2 class="wp-block-heading">四、Step 2：拉取常用模型</h2>

<p class="wp-block-paragraph">根据硬件选择，常用命令如下：</p>

<pre><code class="language-bash"># 阿里通义千问，中文友好，全尺寸覆盖
ollama pull qwen3:8b
ollama pull qwen3:32b

# DeepSeek 推理/通用系列，性价比高
ollama pull deepseek-r1:8b
ollama pull deepseek-v3:latest

# Meta Llama 4 开放权重
ollama pull llama4:latest

# 轻量快速，适合做路由/分类
ollama pull qwen3:1.7b
</code></pre>

<blockquote class="is-layout-flow wp-block-quote-is-layout-flow">
<p>合规提醒：部分模型（如 FLUX 的某些权重、Llama 的个别版本）有非商业许可限制，商用前请核对许可证（LICENSE）与官方条款。</p>
</blockquote>

<h2 class="wp-block-heading">五、Step 3：用 Docker 一键部署 Open WebUI</h2>

<p class="wp-block-paragraph">最干净的方式是把 Open WebUI 也跑在 Docker 里，并直接连到 Ollama：</p>

<pre><code class="language-bash">docker run -d \
  --name open-webui \
  -p 3000:8080 \
  -e OLLAMA_BASE_URL=http://host.docker.internal:11434 \
  -v openwebui_data:/app/backend/data \
  --add-host=host.docker.internal:host-gateway \
  ghcr.io/open-webui/open-webui:main
</code></pre>

<p class="wp-block-paragraph">启动后，浏览器访问 <code>http://localhost:3000</code>，首次进入会要求注册管理员账号（第一个注册的人即管理员）。</p>

<blockquote class="is-layout-flow wp-block-quote-is-layout-flow">
<p>如果 Ollama 和 Open WebUI 都跑在同一台主机且 Ollama 是原生安装的，<code>OLLAMA_BASE_URL</code> 用 <code>http://host.docker.internal:11434</code> 即可（Docker 已加 <code>host-gateway</code> 映射）。</p>
</blockquote>

<h2 class="wp-block-heading">六、Step 4：在 Open WebUI 里对话与切换模型</h2>

<ol class="wp-block-list">
<li>登录后，左上角选择模型（如 <code>qwen3:8b</code>）。</li>
<li>直接对话，体验类 ChatGPT 的界面。</li>
<li>进入「设置 → 模型」，可看到 Ollama 已加载的所有模型，支持参数调节（温度、上下文长度、系统提示词）。</li>
</ol>

<h2 class="wp-block-heading">七、进阶：把本地模型当 API 用</h2>

<p class="wp-block-paragraph">Open WebUI 和 Ollama 都提供兼容 OpenAI 格式的 API，方便接入你自己的应用、代码编辑器（如 Cursor、VS Code）或 Agent 框架。</p>

<h3 class="wp-block-heading">Ollama 原生 API</h3>

<pre><code class="language-bash"># 通过 Ollama 的 OpenAI 兼容接口调用
curl http://localhost:11434/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3:8b",
    "messages": [{"role": "user", "content": "用一句话解释什么是向量数据库"}]
  }'
</code></pre>

<h3 class="wp-block-heading">Open WebUI 的 API Key</h3>

<p class="wp-block-paragraph">在 Open WebUI「设置 → 账号 → API Keys」生成密钥，之后用 <code>http://localhost:3000/api/chat/completions</code> 调用，适合团队统一网关。</p>

<h2 class="wp-block-heading">八、进阶：开启本地知识库（RAG）</h2>

<p class="wp-block-paragraph">Open WebUI 内置 RAG 能力，无需额外组件：</p>

<ol class="wp-block-list">
<li>进入「知识库 → 新建文档集」，上传 PDF / Word / Markdown / 网页。</li>
<li>对话时 <code>@</code> 选择该文档集，模型会基于你的私有资料回答。</li>
<li>底层用本地嵌入模型（如 <code>nomic-embed-text</code>）做向量化，全程离线。</li>
</ol>

<pre><code class="language-bash"># 拉取一个本地嵌入模型供 RAG 使用
ollama pull nomic-embed-text
</code></pre>

<h2 class="wp-block-heading">九、性能与体验优化</h2>

<ul class="wp-block-list">
<li><strong>量化选择</strong>：优先 <code>q4_K_M</code> / <code>q5_K_M</code> 量化，在精度与显存间取平衡；显存紧张用 <code>q3_K</code>。</li>
<li><strong>上下文长度</strong>：对话设置里把 context length 调大到 8K–32K，长文档更连贯。</li>
<li><strong>GPU 加速</strong>：确保 Ollama 识别到显卡（<code>ollama ps</code> 查看是否 <code>100% GPU</code>）。Windows 下需安装对应 CUDA 驱动。</li>
<li><strong>多模型路由</strong>：在 Open WebUI 里把简单问答路由到 <code>qwen3:1.7b</code>，复杂任务才用 32B，省显存又提速。</li>
</ul>

<h2 class="wp-block-heading">总结</h2>

<p class="wp-block-paragraph">Ollama + Open WebUI 是目前最省心、最完整的&#8221;本地私有 ChatGPT&#8221;组合：十分钟装好，支持主流开放模型，自带 RAG 与 API。对个人是隐私护盾，对企业是数据合规的低成本起点。把敏感数据留在自己机器上，通用能力按需上云——这才是 2026 年务实的 AI 使用姿势。</p>

<h2 class="wp-block-heading">FAQ</h2>

<p class="wp-block-paragraph"><strong>Q1：本地部署真的能完全离线吗？</strong><br />
首次拉取模型文件需要联网，之后推理、对话、RAG 全部在本地完成，不向外发送任何数据。若彻底断网，请确保模型已下载完毕。企业可在内网镜像仓库预置模型以实现完全离线。</p>

<p class="wp-block-paragraph"><strong>Q2：本地模型效果能赶上 GPT-5 / Claude 吗？</strong><br />
通用对话仍有差距，但在中文、垂直知识、私有数据场景下，配合 RAG 与微调，Qwen3 / DeepSeek 已能替代闭源模型处理大量日常任务。判断标准是&#8221;在你的任务上够不够用&#8221;，而非盲目追参数。</p>

<p class="wp-block-paragraph"><strong>Q3：多人/团队怎么用？</strong><br />
Open WebUI 支持多用户、权限分组与共享文档集，可部署在一台内网服务器上供团队访问。配合账号管理与 API Key，能作为企业内部统一的私有模型网关。</p>

   └─ LinkedIn：发长文动态
</code></pre>

<h2 class="wp-block-heading">第一步：让 WordPress/Ghost 在发布时通知 n8n</h2>

<p class="wp-block-paragraph"><strong>WordPress</strong>：安装「WP Webhooks」或「AutomateWoo」，在文章 <code>publish</code> 时 POST 到：</p>

<pre><code>https://n8n.example.com/webhook/blog-published
</code></pre>

<p class="wp-block-paragraph"><strong>Ghost</strong>：Ghost 自带 Webhook（Settings → Integrations → Add webhook）：</p>

<pre><code>Target URL: https://n8n.example.com/webhook/blog-published
Event: post.published
</code></pre>

<p class="wp-block-paragraph">n8n 端用 <strong>Webhook</strong> 节点接收，<code>Response Mode</code> 设 <code>On Received</code>。</p>

<h2 class="wp-block-heading">第二步：解析文章字段</h2>

<p class="wp-block-paragraph">Webhook 收到的 Ghost 负载示例：</p>

<pre><code class="language-json">{
  "post": {
    "title": "如何用 n8n 搭建监控告警",
    "url": "https://blog.example.com/n8n-monitor",
    "html": "<p>正文...</p>",
    "feature_image": "https://cdn.example.com/cover.jpg",
    "custom_excerpt": "本文介绍..."
  }
}
</code></pre>

<p class="wp-block-paragraph">用 <strong>Set / Edit Fields</strong> 节点提取并清洗：</p>

<ul class="wp-block-list">
<li><code>title</code> ← <code>post.title</code></li>
<li><code>url</code> ← <code>post.url</code></li>
<li><code>cover</code> ← <code>post.feature_image</code></li>
<li><code>plain</code> ← 用 Code 节点剥离 HTML 标签：</li>
</ul>

<pre><code class="language-javascript">const html = $json.post.html || '';
const text = html.replace(/<[^>]+>/g, ' ').replace(/\s+/g, ' ').trim();
return [{ json: { ...$json, plain: text.slice(0, 4000) } }];
</code></pre>

<h2 class="wp-block-heading">第三步：用 AI 改写文案</h2>

<p class="wp-block-paragraph">调用模型把长文拆成适合社媒的片段。用 <strong>LangChain</strong> 链或 <strong>HTTP Request</strong>：</p>

<pre><code>System: 你是一名社媒运营，擅长把技术博客改写成吸引人的短文案。
User: 请把下面的文章改写为：
  1) 一条推特 Thread（5 条以内，每条 < 270 字，含 emoji 与话题标签 #n8n #自动化）
  2) 一条 LinkedIn 长动态（< 2900 字，专业语气，结尾加 2 个话题）
文章标题：{{ $json.title }}
文章正文：{{ $json.plain }}
</code></pre>

<p class="wp-block-paragraph">把返回解析为 <code>thread</code>（数组）与 <code>linkedin</code>（字符串）。</p>

<h2 class="wp-block-heading">第四步：发推特 Thread</h2>

<p class="wp-block-paragraph">推特 API v2 用 <strong>HTTP Request</strong> 节点。先发第一条取到 <code>id</code>，再用 <code>in_reply_to_tweet_id</code> 串起来：</p>

<pre><code>POST https://api.twitter.com/2/tweets
Headers: Authorization: Bearer {{ <span class="katex math inline">env.TWITTER_TOKEN }}
Body:
{
  "text": "{{</span>json.tweet_text }}",
  "media": { "media_ids": ["{{ $env.COVER_MEDIA_ID }}"] }  // 可选上传封面
}
</code></pre>

<p class="wp-block-paragraph"><strong>循环发 Thread</strong> 用 <strong>Split Out</strong> + <strong>Loop Over Items</strong>：第一条不带 <code>in_reply_to_tweet_id</code>，后续每条带前一条的 id。简化为用 <strong>Code</strong> 节点批量调用：</p>

<pre><code class="language-javascript">const tweets = <span class="katex math inline">json.thread; // 字符串数组
const token =</span>env.TWITTER_TOKEN;
let lastId = null;
const sent = [];
for (const t of tweets) {
  const body = { text: t };
  if (lastId) body.reply = { in_reply_to_tweet_id: lastId };
  const r = await fetch('https://api.twitter.com/2/tweets', {
    method: 'POST',
    headers: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json' },
    body: JSON.stringify(body)
  }).then(res => res.json());
  lastId = r.data?.id;
  sent.push(r.data?.id);
}
return [{ json: { thread_ids: sent } }];
</code></pre>

<p>推特 API 免费层已大幅收紧，Thread 自动化通常需要至少 Basic 套餐。请评估成本。</p>
</blockquote>

<h2 class="wp-block-heading">第五步：发 LinkedIn 动态</h2>

<p class="wp-block-paragraph">LinkedIn 用 <strong>HTTP Request</strong> 发 <code>ugcPosts</code>：</p>

<pre><code>POST https://api.linkedin.com/v2/ugcPosts
Headers: Authorization: Bearer {{ <span class="katex math inline">env.LINKEDIN_TOKEN }}
        X-Restli-Protocol-Version: 2.0.0
Body:
{
  "author": "urn:li:person:{{</span>env.LI_PERSON_URN }}",
  "lifecycleState": "PUBLISHED",
  "specificContent": {
    "com.linkedin.ugc.ShareContent": {
      "shareCommentary": { "text": "{{ <span class="katex math inline">json.linkedin }}" },
      "shareMediaCategory": "ARTICLE",
      "media": [{
        "status": "READY",
        "originalUrl": "{{</span>json.url }}"
      }]
    }
  },
  "visibility": { "com.linkedin.ugc.MemberNetworkVisibility": "PUBLIC" }
}
</code></pre>

<blockquote class="is-layout-flow wp-block-quote-is-layout-flow">
<p>LinkedIn 个人令牌需申请开发者应用并审核，企业页可用 <code>organization</code> URN 替代。</p>
</blockquote>

<h2 class="wp-block-heading">第六步：失败处理与幂等</h2>

<ul class="wp-block-list">
<li><strong>幂等</strong>：用文章 <code>url</code> 做去重键，已分发过则跳过，避免 Webhook 重复触发导致重复发帖。</li>
<li><strong>重试</strong>：开 <code>Retry On Fail</code>，指数退避。</li>
<li><strong><a href="https://waynetalk.com/523/">告警</a></strong>：分发失败写入飞书/邮件，方便人工补发。</li>
</ul>

<h2 class="wp-block-heading">合规提醒</h2>

<p class="wp-block-paragraph">推特、LinkedIn 均对自动化发布有平台政策限制（频率、内容真实性）。请遵守其开发者协议，勿刷屏、勿发布违规内容；商用账号注意 API 费用与审核要求。</p>

<p class="wp-block-paragraph">把「写博客」和「做分发」解耦：你只管产出，n8n 负责把一篇长文自动变身为推特 Thread 与 LinkedIn 动态。矩阵分发从奢侈品变成默认能力。</p>

<h2 class="wp-block-heading">FAQ</h2>

<p class="wp-block-paragraph"><strong>Q1：Ghost 免费版支持 Webhook 吗？</strong><br />
支持。Ghost 自 v4 起内置 Webhook（含 <code>post.published</code>），在 Integrations 中配置即可，无需插件。</p>

<p class="wp-block-paragraph"><strong>Q2：推特 Thread 自动发布成本如何？</strong><br />
2026 年推特 API 对写操作基本收费，Thread 逐条发需要可用配额。个人低频可用 Basic，量大的团队需评估 Pro/Enterprise。</p>

<p class="wp-block-paragraph"><strong>Q3：AI 改写会不会偏离原意？</strong><br />
会。建议在提示词中强调「保留关键结论与数据」，并在发布前加一个人工审核分支（先发到草稿群，确认后再正式发布）。</p>

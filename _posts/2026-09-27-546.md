<p class="wp-block-paragraph">本文教你用 <a href="https://waynetalk.com/free-image-hosting-r2-picgo/">Cloudflare R2 + PicGo</a> 搭一个<strong>几乎 0 成本、高可用、可自定义域名</strong>的个人图床。<a href="https://waynetalk.com/543/">配合本博客《Cloudflare Pages 建站》一文</a>，你的博客配图就彻底不用再求人。</p>

<p class="wp-block-paragraph">图床的流量特征是&#8221;读多写少、且出站流量大&#8221;。S3 类按出站流量计费，图片一旦被热加载，月底账单吓人；<strong>R2 出站流量免费</strong>，正好命中图床痛点。R2 还兼容 S3 API，工具生态通用。</p>

</blockquote>

<h2 class="wp-block-heading">二、创建 R2 存储桶</h2>

<ol class="wp-block-list">
<li>登录 Cloudflare 控制台 → R2 → 开通（首次可能要求绑定支付方式用于超额计费，但免费额度内不扣费）。</li>
<li>创建存储桶（Bucket），例如 <code>my-image-bed</code>，区域选自动/就近。</li>
<li>记下桶名与账户 ID（Account ID 在右侧栏）。</li>
</ol>

<pre><code class="language-text">桶名：my-image-bed
账户 ID：<你的 Cloudflare Account ID>
</code></pre>

<h2 class="wp-block-heading">三、创建 API 令牌</h2>

<p class="wp-block-paragraph">PicGo 需要通过 S3 兼容 API 上传，需生成访问密钥：</p>

<ol class="wp-block-list">
<li>R2 → 管理 R2 API 令牌 → 创建令牌。</li>
<li>权限设为&#8221;对象读/写&#8221;，作用域限定到你的桶。</li>
<li>保存好 <code>Access Key ID</code> 与 <code>Secret Access Key</code>（只显示一次）。</li>
</ol>

<pre><code class="language-yaml"># 你需要的四个值
access_key_id: <R2 Access Key ID>
secret_access_key: <R2 Secret Access Key>
account_id: <Cloudflare Account ID>
bucket: my-image-bed
</code></pre>

<h2 class="wp-block-heading">四、PicGo 配置（S3 兼容）</h2>

<p class="wp-block-paragraph">PicGo 是开源图床客户端，支持 R2（S3 模式）。</p>

<ol class="wp-block-list">
<li>安装 PicGo（开源，GitHub 可下载）。</li>
<li>图床设置 → 亚马逊 S3（或安装 <code>picgo-plugin-s3</code> 插件）。</li>
<li>填写：</li>
</ol>

<pre><code class="language-text">设定桶名：my-image-bed
设定区域：auto
设定访问密钥：<Access Key ID>
设定密匙：<Secret Access Key>
路径风格：vhost 风格（或按插件要求）
自定义节点（Endpoint）：https://<account_id>.r2.cloudflarestorage.com
自定义域名（可选）：https://img.你的域名.com
</code></pre>

<ol class="wp-block-list" start="4">
<li>测试上传，成功即配置完成。</li>
</ol>

<blockquote class="is-layout-flow wp-block-quote-is-layout-flow">
<p>小贴士：在 PicGo 里开启&#8221;时间戳重命名&#8221;或加随机前缀，避免文件名冲突覆盖。</p>
</blockquote>

<h2 class="wp-block-heading">五、自定义域名 + CDN 加速</h2>

<p class="wp-block-paragraph">默认 R2 提供 <code>pub-xxx.r2.dev</code> 临时域名（有速率限制、不建议长期用）。生产用法是<a href="https://waynetalk.com/221/">绑定自己的域名</a>走 Cloudflare CDN：</p>

<ol class="wp-block-list">
<li>在 R2 桶 → 设置 → 公开访问（Public），绑定自定义域（如 <code>img.yourdomain.com</code>）。</li>
<li>域名 DNS 已在 Cloudflare 托管时，会自动加 CNAME 并签发 SSL。</li>
<li>在 PicGo 的&#8221;自定义域名&#8221;填入 <code>https://img.yourdomain.com</code>。</li>
</ol>

<p class="wp-block-paragraph">这样图片 URL 就变成你自己的域名，且经 Cloudflare 全球缓存，加载快、出站 0 流量费。</p>

<pre><code class="language-dns">CNAME  img  <桶的 R2 公开域名>
</code></pre>

<h2 class="wp-block-heading">六、把成本压到真正的 0</h2>

<ul class="wp-block-list">
<li><strong>控制存储量</strong>：图床只放网页用图，原图本地备份；R2 免费档覆盖个人博客绰绰有余，超出再按量。</li>
<li><strong>加缓存头</strong>：在 R2 / Workers 层设置长缓存（<code>Cache-Control: public, max-age=31536000</code>），让边缘少回源。</li>
<li><strong><a href="https://waynetalk.com/781/">图片压缩</a></strong>：上传前用工具压到合理尺寸（WebP），省钱又提速。</li>
</ul>

<h2 class="wp-block-heading">七、高可用与备份</h2>

<ul class="wp-block-list">
<li>R2 本身是多副本对象存储，可靠性高；但&#8221;可用&#8221;也取决于你的域名与 Cloudflare 账户状态。</li>
<li>本地保留原图副本，万一桶被误删可重建。</li>
<li>不要把图床当唯一存储——它服务于展示，源文件自己留底。</li>
</ul>

<h2 class="wp-block-heading">八、FAQ</h2>

<p class="wp-block-paragraph"><strong>Q1：R2 真的出站免费吗？会不会有隐藏费用？</strong><br />
A：R2 的核心卖点就是出站流量不收费，但存储与 A/B 类请求在免费额度外会按量计费。个人图床通常落在免费档内；具体阈值以官网定价页为准。</p>

<p class="wp-block-paragraph"><strong>Q2：能不能不用 PicGo，用其他工具？</strong><br />
A：可以。任何支持 S3 协议的客户端（如 rclone、Typora 自定义命令、VS Code 插件）都能对接 R2，原理相同。</p>

<p class="wp-block-paragraph"><strong>Q3：图片被刷量会产生费用吗？</strong><br />
A：出站免费，所以被大量访问也不会产生流量费；但极端请求量可能涉及请求次数计费，建议加 WAF 规则防滥用。</p>

<p class="wp-block-paragraph">Cloudflare R2 + PicGo 是个人图床的&#8221;黄金组合&#8221;：出站流量免费击中图床痛点，S3 兼容让工具随手可用，自定义域名 + CDN 让链接体面又快速。配合 Cloudflare Pages 博客，你拥有了一套从写作、配图到托管的完整 0 成本低可用内容工作流。</p>

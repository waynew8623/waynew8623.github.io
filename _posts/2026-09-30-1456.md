<h2>二、Gemini：免费额度最大，2 分钟拿到 Key</h2>
<p>Gemini API 免费额度是这几家里最慷慨的之一。Google AI Studio 对个人开发者开放免费层，<strong>不需要绑定任何结算方式</strong>，用 Google 账号登录即可创建 API Key。</p>
<h3>申请步骤</h3>
<ol>
<li>打开 <a class="wp-editor-md-post-content-link" href="https://aistudio.google.com/">Google AI Studio</a>（aistudio.google.com），用 Google 账号登录。</li>
<li>点击左下角的 <strong>Get API Key</strong>（钥匙图标）。</li>
<li>选择 <strong>Create API Key in new project</strong>（或在已有 Google Cloud 项目下创建），系统会生成一串以 <code>AIzaSy</code> 开头的 Key。</li>
<li>复制 Key，存到环境变量或项目配置里即可调用。</li>
</ol>
<h3>额度与注意事项（参考）</h3>
<ul>
<li>免费层按模型限速：社区 2026 年口径中，Flash 级别模型约 15 RPM、每天约 1000–1500 次请求；更强的 Pro 系列配额明显更低。<strong>具体数字以 AI Studio 控制台的 &#8220;Rate limits&#8221; 页面为准</strong>。</li>
<li>免费档的请求内容<strong>可能被 Google 用于改进模型</strong>，合同、隐私数据不要上传；如需关闭，可在账号设置中查找 opt-out 选项（以官网为准）。</li>
<li>配额耗尽会返回 429 错误，第二天自动重置，适合开发、演示和低流量场景。</li>
</ul>

<h2>三、Groq：极速推理，OpenAI 兼容切换成本最低</h2>
<p>Groq 用自研 LPU 芯片跑开源模型，推理速度是免费层里的第一梯队，做实时对话、语音转写体验极好。注册<strong>不需要信用卡、不需要手机验证</strong>，邮箱或 Google / GitHub 一键登录即可。</p>
<h3>申请步骤（Groq 免费 API 申请教程）</h3>
<ol>
<li>打开 <a class="wp-editor-md-post-content-link" href="https://console.groq.com/">Groq 控制台</a>（console.groq.com），用 Google / GitHub 账号登录（邮箱注册也可以）。</li>
<li>左侧菜单进入 <strong>API Keys</strong>，点击 <strong>Create API Key</strong>。</li>
<li>复制生成的 <code>gsk_</code> 开头 Key（只完整显示一次，丢了就重新生成）。</li>
<li>调用地址为 <code>https://api.groq.com/openai/v1</code>，<strong>完全兼容 OpenAI SDK</strong>，改两行代码就能从 OpenAI 切过来。</li>
</ol>
<pre><code class="language-python line-numbers">from openai import OpenAI

client = OpenAI(
    base_url="https://api.groq.com/openai/v1",
    api_key="你的_GROQ_API_KEY",
)
r = client.chat.completions.create(
    model="llama-3.3-70b-versatile",
    messages=[{"role": "user", "content": "你好"}],
)
print(r.choices[0].message.content)
</code></pre>
<h3>额度与注意事项（参考）</h3>
<ul>
<li>免费开发者层约 30 RPM / 约 14400 次请求每天，每分钟 token 上限因模型而异（以控制台 Limits 页面为准）。</li>
<li>模型列表更新快（Llama、Qwen、Whisper 等），<strong>不要在代码里硬编码模型名</strong>，上线前先调一次 <code>/models</code> 接口确认。</li>
<li>控制台有 Cloudflare 防护，国内网络访问控制台页面可能需要稳定线路，但 API 调用本身走常规 HTTPS。</li>
</ul>
<h2>四、硅基流动：国内直连，免信用卡的&#8221;本土最优解&#8221;</h2>
<p>硅基流动是国内访问最顺的免费 AI API 入口之一：注册后即送约十几元的体验代金券，另有部分小模型长期免费调用，<strong>手机号/邮箱注册即可，无需信用卡</strong>，国内网络直连不需要任何代理。</p>
<h3>申请步骤</h3>
<ol>
<li>打开硅基流动官网（cloud.siliconflow.cn），用手机号或邮箱注册登录。</li>
<li>新账号通常自动到账一笔<strong>体验代金券</strong>（社区 2026 年口径约十几元，具体金额与有效期以官网活动页为准）。</li>
<li>进入控制台 <strong>API 密钥</strong> 页面，创建 Key。</li>
<li>调用地址为 <code>https://api.siliconflow.cn/v1</code>，同样兼容 OpenAI 接口规范，sdk 切换成本极低。</li>
</ol>
<h3>额度与注意事项（参考）</h3>
<ul>
<li><strong>硅基流动免费额度</strong>分两部分：代金券（按量抵扣，用完或过期即止）和长期免费的小模型清单（免费模型列表会在官网&#8221;模型广场&#8221;标注）。</li>
<li>代金券有有效期（参考口径到 2026 年底），领到后尽早安排在实际项目里消耗，不要囤着。</li>
<li>实名与否影响部分高级功能的开通，基础免费调用不受影响；以官网账号说明为准。</li>
</ul>
<h2>五、OpenRouter：一个 Key 调几十个免费模型</h2>
<p>OpenRouter 是模型聚合网关：一个 API Key、一个 OpenAI 兼容接口，能调上百个模型。其中带 <code>:free</code> 后缀的是免费模型，<strong>注册不需要信用卡</strong>，免费账户每天约 50 次免费调用。</p>
<h3>申请步骤</h3>
<ol>
<li>打开 <a class="wp-editor-md-post-content-link" href="https://openrouter.ai/">OpenRouter</a>（openrouter.ai）注册登录。</li>
<li>进入 <strong>Keys</strong> 页面创建 API Key（<code>sk-or-v1-...</code> 开头）。</li>
<li>调用时指定 <code>:free</code> 模型，例如 <code>google/gemma-3-27b-it:free</code>；想省心可以用官方聚合路由 <code>openrouter/free</code>，由平台自动选择当前可用的免费模型。</li>
</ol>
<pre><code class="language-bash line-numbers">curl https://openrouter.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"openrouter/free","messages":[{"role":"user","content":"你好"}]}'
</code></pre>
<h3>OpenRouter 免费模型有哪些？怎么查最准？</h3>
<p>免费模型名单轮换频繁（有的上线几周就下架转收费），<strong>不要背名单，要学会查</strong>：</p>
<ul>
<li>打开官方模型列表页，筛选价格为 0 的模型：<code>https://openrouter.ai/models?max_price=0</code></li>
<li>或直接请求官方模型接口 <code>https://openrouter.ai/api/v1/models</code>，找 <code>pricing</code> 双零且名称带 <code>:free</code> 的条目。</li>
<li>稳妥起见：生产/长任务不要硬编码某个 <code>:free</code> 模型名，优先用 <code>openrouter/free</code> 路由兜底。</li>
</ul>
<h3>额度与注意事项（参考）</h3>
<ul>
<li>免费账户：所有免费模型共享约 50 次/天、20 次/分钟；账户累计充值 ≥ $10 后可提升到约 1000 次/天（20 次/分钟不变）。以官网 FAQ 为准。</li>
<li>部分免费模型可能要求账户有余额记录，首次使用前先发一条真实请求验证。</li>
</ul>

<h2>七、FAQ</h2>
<p><strong>Q1：Gemini API 免费额度是多少？真的不用信用卡吗？</strong></p>
<p>真的不用。Google AI Studio 免费层只需 Google 账号，不绑定结算方式。额度参考：Flash 级别模型约 15 RPM、每天约 1000–1500 次请求，更强的模型配额更低，具体以 AI Studio 控制台 &#8220;Rate limits&#8221; 页面为准。免费档输入内容可能被用于改进模型，敏感数据请勿上传。</p>
<p><strong>Q2：Groq 免费 API 怎么申请？需要翻墙吗？</strong></p>
<p>申请只需三步：打开 console.groq.com → 用 Google / GitHub 登录 → API Keys 里创建 <code>gsk_</code> 开头的 Key，全程无信用卡、无手机验证。Groq 控制台和 API 在国内网络下访问可能不稳定，建议准备稳定线路；这是网络可达性问题，不是账号门槛。</p>
<p><strong>Q3：硅基流动免费额度有多少？怎么领取？</strong></p>
<p>新用户注册后通常自动到账一笔体验代金券（社区 2026 年口径约十几元），另有部分小模型长期免费调用。领取方式就是正常注册登录，无需信用卡；代金券有有效期，领到后尽早用在实际项目上。金额与有效期以官网活动页为准。</p>
<p><strong>Q4：OpenRouter 免费模型有哪些？</strong></p>
<p>带 <code>:free</code> 后缀的都是免费模型，但名单轮换很快。最靠谱的查法是打开 <code>https://openrouter.ai/models?max_price=0</code> 筛选价格为 0 的模型，或调官方 <code>/api/v1/models</code> 接口找定价双零的条目。想省事就用 <code>openrouter/free</code> 聚合路由，让平台自动选可用的免费模型。</p>
<p><strong>Q5：这四个平台，有没有哪个偷偷扣费？</strong></p>
<p>按免费层正常使用都不会扣费，因为它们<strong>从头到尾就没让你绑卡</strong>。真正的风险反而在&#8221;绑过卡的试用&#8221;（如部分云厂商）：额度用尽会自动按量扣费。所以策略是——免信用卡的平台放心用；一旦某天你升级到需要绑卡的付费档，务必第一时间设置预算告警。</p>
<p><strong>Q6：遇到 429 限速（Too Many Requests）怎么办？</strong></p>
<p>三板斧：指数退避重试、多平台 fallback 切换、结果缓存。免费层限速是按&#8221;每分钟/每天&#8221;重置的，不是封号，等一等或换一家继续即可。把四家 Key 按优先级排好，一个 <code>try/except</code> 就能搞定。</p>
<p><strong>Q7：免费 API 能用在商业项目里吗？</strong></p>
<p>看条款：多数免费层允许轻量商业用途，但<strong>无 SLA、无技术支持、配额随时调整</strong>。验证想法、跑 MVP 没问题；一旦有真实用户和收入，建议切到付费档或自建方案（如本地 Ollama），别把免费额度当生产依赖。</p>

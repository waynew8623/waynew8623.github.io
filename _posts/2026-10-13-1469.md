<h2>1. GlazeWM：Windows 也能玩平铺窗口</h2>
<p>Linux 用户有 i3、Hyprland，Windows 用户长期只能手动拖窗口。<a class="wp-editor-md-post-content-link" href="https://github.com/glzr-io/glazewm">GlazeWM</a> 就是给 Windows 做的平铺窗口管理器：窗口自动排列、键盘驱动、支持多工作区和多显示器，配置文件是人类可读的 YAML。</p>
<p>装上之后，<code>Alt+H/J/K/L</code> 在窗口间跳转，<code>Alt+数字</code> 切换工作区，<code>Alt+Shift+数字</code> 把窗口丢到指定工作区——一套肌肉记忆，告别&#8221;找窗口&#8221;的内耗。它支持 Winget/Scoop 一行命令安装，资源占用很轻，随时可以退出回到原生桌面。</p>
<p>适合：同时开着浏览器、IDE、终端、文档的多任务用户；想体验平铺窗口管理又离不开 Windows 生态的人。</p>
<h2>2. EarTrumpet：Windows 音量控制的&#8221;完全体&#8221;</h2>
<p>系统自带的音量滑块一次只能调&#8221;总音量&#8221;，想单独调某个应用？得钻进设置里翻半天。<a class="wp-editor-md-post-content-link" href="https://github.com/File-New-Project/EarTrumpet">EarTrumpet</a> 常驻系统托盘，点一下就能看到每个正在发声的应用各自的音量条，还能把不同应用指定到不同输出设备（比如游戏走音箱、会议走耳机），支持快捷键和亮/暗主题。</p>
<p>微软应用商店可直接安装，GitHub 也有完整开源仓库。开会时一键静音浏览器、游戏时压低背景音乐，这种&#8221;细粒度&#8221;控制用过就回不去。</p>
<p>适合：经常开线上会议、直播、游戏语音两不误的人。</p>
<h2>3. CopyQ：剪贴板也该有&#8221;历史记录&#8221;</h2>
<p>系统剪贴板一次只能记住一条复制内容，<a class="wp-editor-md-post-content-link" href="https://github.com/hluk/CopyQ/releases">CopyQ</a> 把它变成了一个可搜索的数据库：文字、图片、HTML 都能存，支持标签页分类、全文搜索，还能写脚本实现&#8221;复制即翻译&#8221;&#8221;自动去格式&#8221;这类自动化。它支持全局快捷键呼出，Windows/macOS/Linux 全平台覆盖，Mac 版还支持 iCloud 同步。</p>
<p>文字工作者、客服、运营每天复制粘贴上百次，有了剪贴板历史，找三天前复制的一段话就是几秒钟的事。</p>
<p>适合：写文案、做客服、整理资料的重度复制粘贴用户。</p>
<h2>4. Superfile：把终端变成&#8221;高颜值文件管理器&#8221;</h2>
<p>还在 <code>ls</code> + <code>cd</code> 一层层翻目录？<a class="wp-editor-md-post-content-link" href="https://github.com/yorukot/superfile">Superfile</a> 是用 Go 写的终端文件管理器：多面板并排、文件预览、20 多套内置主题、Vim 风格键位，敲 <code>spf</code> 即开即用。它本质上是个&#8221;不用鼠标的文件资源管理器&#8221;，批量复制、移动、重命名都能在键盘上完成。</p>
<p>相比传统终端文件管理器，它最大的优势是&#8221;开箱即好看&#8221;——主题和图标默认就调得很舒服，新手也不会被劝退。Windows/macOS/Linux 都支持。</p>
<p>适合：天天泡在终端里的开发者、运维，以及想&#8221;好用又好看&#8221;的命令行新手。</p>

<h2>5. Atuin：你的命令历史值得一个数据库</h2>
<p>终端命令历史默认是个纯文本文件，换台电脑就丢了，搜起来也费劲。<a class="wp-editor-md-post-content-link" href="https://github.com/atuinsh/atuin">Atuin</a> 用 SQLite 接管 shell 历史：每条命令附带执行目录、耗时、退出码、主机名，<code>Ctrl+R</code> 呼出全屏搜索，还支持端到端加密的多设备同步（也可以自建服务器或纯本地使用）。</p>
<p>它支持 zsh、bash、fish、nushell 和 PowerShell，旧历史可以一键导入。对多机党来说，&#8221;在公司敲过的那条长命令，回家照样能搜到&#8221;是真的香。</p>
<p>适合：多台电脑/服务器之间来回切的开发者和运维。</p>
<h2>6. PDF Arranger：PDF 页面&#8221;拼图式&#8221;整理</h2>
<p>合并几个 PDF、删掉其中几页、把横版页面转正——这类需求不值得开 Adobe Acrobat，也不放心上传到在线网站。<strong>PDF Arranger</strong>（在 GitHub 搜索即可找到官方仓库）就是干这个的：把 PDF 每一页显示成缩略图，拖拽排序、旋转、删除、合并、拆分，所见即所得，Windows 和 Linux 都有客户端。</p>
<p>注意它只做&#8221;页面级&#8221;操作（合并/拆分/旋转/裁剪），不编辑页面内的文字图片，定位非常清晰，学起来零成本。</p>
<p>适合：行政、教师、学生等经常处理扫描件和表格 PDF 的人。</p>
<h2>7. FastFlix：FFmpeg 的&#8221;图形化外壳&#8221;</h2>
<p>FFmpeg 是视频压制的王者，但命令行参数劝退了 99% 的人。<a class="wp-editor-md-post-content-link" href="https://github.com/cdgriffith/FastFlix/releases/latest">FastFlix</a> 给它套了一个清爽的图形界面：x264、x265、AV1、VP9 等 20 多种编码器随便选，支持 NVIDIA/Intel/AMD 硬件加速，还能完整保留 HDR10 元数据——收藏党把蓝光原盘压成小体积 HEVC，全程点鼠标就行。</p>
<p>它是 Python + Qt 写的开源项目，跨平台，压制队列、批量任务都支持，是&#8221;影音收藏党&#8221;的标配工具之一。</p>
<p>适合：整理影视收藏、做视频搬运/二创的 UP 主。</p>
<h2>8. Spek：一眼鉴别&#8221;假无损&#8221;音乐</h2>
<p>下载的 FLAC 号称无损，真是无损吗？<a class="wp-editor-md-post-content-link" href="https://github.com/alexkay/spek">Spek</a> 是个声学频谱分析仪：把音频文件拖进去，生成频谱图——真无损的高频能延伸到 20kHz 以上，而 MP3 转制的&#8221;假无损&#8221;通常在 16kHz 附近就被一刀切。它用 FFmpeg 解码、wxWidgets 做界面，Windows/macOS/Linux 通吃，打开文件秒出图。</p>
<p>它不做播放、不做转码，就解决&#8221;验货&#8221;这一个问题，堪称音乐发烧友的&#8221;照妖镜&#8221;。</p>
<p>适合：收藏无损音乐、混迹 PT 站的发烧友。</p>
<h2>9. Deskreen：旧设备变身第二块屏幕</h2>
<p>吃灰的旧平板、旧手机别扔：<a class="wp-editor-md-post-content-link" href="https://github.com/pavlobu/deskreen">Deskreen</a> 通过 WebRTC 把电脑画面串流到任何带浏览器的设备上，扫码即连，不用装客户端。看文档时把参考资料扔到平板上，宿舍、出差、咖啡馆秒变双屏。它是 Electron 应用，Windows/macOS/Linux 都有，社区版开源免费。</p>
<p>注意它走的是局域网串流，延迟和画质取决于你的 Wi-Fi，做设计、打游戏别指望，但看文档、挂聊天窗口绰绰有余。</p>
<p>适合：宿舍党、出差党、手头有闲置平板/手机的人。</p>
<h2>10. Barrier：一套键鼠操控多台电脑</h2>
<p>桌上有台式机加笔记本，来回换键鼠很烦？<a class="wp-editor-md-post-content-link" href="https://github.com/debauchee/barrier">Barrier</a> 是开源的&#8221;软件 KVM&#8221;：在所有电脑上都装上，鼠标滑到屏幕边缘就&#8221;穿&#8221;到另一台电脑，键盘跟随，剪贴板也是共享的。它是从 Synergy 1.9 分叉出来的免费版本，Windows/macOS/Linux/FreeBSD 全支持。</p>
<p>设置只需要一台设为服务端、其他设客户端填 IP，局域网内即连即用，是双机党的经典方案。</p>
<p>适合：同时用两台以上电脑的程序员、设计师、交易员。</p>

<h2>FAQ</h2>
<p><strong>Q1：这些小众开源软件真的免费吗？会不会有广告或捆绑？</strong><br />
A：本文 10 款全部是开源免费软件，无广告、无捆绑、无功能阉割。但务必从 GitHub 官方仓库的 Releases 页下载，第三方下载站的&#8221;高速下载器&#8221;才是捆绑的重灾区。</p>
<p><strong>Q2：小众项目会不会突然停更、跑路？</strong><br />
A：有可能，这是小众软件的固有风险。降低风险的方法：优先选 README 完善、近几个月有 commit、issue 有人回复的项目；工具类软件即使停更，已下载的版本通常也能继续用很久。</p>
<p><strong>Q3：我是 Mac 用户，这份清单还适用吗？</strong><br />
A：部分适用。CopyQ、Superfile、Atuin、FastFlix、Spek、Deskreen、Barrier 都有 macOS 版；GlazeWM、EarTrumpet 是 Windows 专属；PDF Arranger 主要支持 Linux/Windows。每款的平台在上文一览表里都已标注，安装前先核对。</p>
<p><strong>Q4：和 VLC、Blender 这些大众开源软件比，小众工具有什么优势？</strong><br />
A：大众软件解决的是&#8221;人人都有&#8221;的需求，小众工具解决的是&#8221;长尾痛点&#8221;——比如&#8221;每个应用单独调音量&#8221;&#8221;鉴别假无损&#8221;。它们往往更轻量、更专注，装上即用不臃肿。</p>
<p><strong>Q5：新手应该从哪一款开始尝试？</strong><br />
A：零门槛：EarTrumpet（装完即用）、Deskreen（扫码即连）。效率提升最明显：CopyQ。想折腾：GlazeWM + Superfile + Atuin 三件套。</p>
<p><strong>Q6：在哪里能第一时间发现这类冷门开源工具？</strong><br />

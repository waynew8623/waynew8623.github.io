<p><a href="https://waynetalk.com/510/">数字货币交易市场</a>日益成熟，<a href="https://waynetalk.com/98/">量化交易</a>因其高效、自动化的特点，成为众多交易者的选择。<strong>HowTrader</strong> 是一款专为数字货币市场设计的开源量化交易框架，基于 <strong>VNPY</strong> 进行优化，修复了部分 BUG，增强了对 <strong>TradingView</strong> 信号的支持，并增加了 <strong>网格交易</strong> 等功能。本文将详细介绍 HowTrader 的功能、安装方法及使用示例，帮助新手快速上手.</p>
<hr>
<h2 id="howtrader-de-te-dian-yu-you-shi" tabindex="-1"><strong>HowTrader 的特点与优势</strong></h2>
<p>HowTrader 在 VNPY 的基础上进行了多项优化，使其更适合数字货币量化交易：</p>
<ol>
<li><strong>交易数据精度提升</strong>：</li>
</ol>
<ul>
<li>
<code>OrderData</code></p>
<p>（订单数据）、<code>TradeData</code>（成交数据）、<code>ContractData</code>（交易对信息）等核心数据结构采用 <code>Decimal</code> 而非 <code>float</code>，提高计算精度。
</li>
</ul>
<ol start="3">
<li><strong>交易回调顺序优化</strong>：</li>
</ol>
<ul>
<li>VNPY 先推送 <code>on_order</code>，后推送 <code>on_trade</code>，导致仓位计算可能滞后。HowTrader 先推送 <code>on_trade</code>，再推送 <code>on_order</code>，确保仓位信息的实时性。</li>
</ul>
<ol start="5">
<li><strong>交易网关优化</strong>：</li>
</ol>
<ul>
<li>增强了 <strong>断线重连</strong> 及 <strong>异常处理机制</strong>，提高系统稳定性。</li>
</ul>
<ol start="7">
<li><strong>支持 TradingView 信号对接</strong>：</li>
</ol>
<ul>
<li>允许通过 <strong>HTTP Webhook</strong> 接收来自 TradingView 的交易信号，实现自动化交易。</li>
</ul>
<ol start="9">
<li><strong>精简代码，减少依赖</strong>：</li>
</ol>
<ul>
<li>相较于 VNPY，删除了部分冗余代码，仅保留核心交易功能，降低学习成本，提高运行效率。</li>
</ul>

<h2 id="tradingview-xin-hao-dui-jie" tabindex="-1"><strong>TradingView 信号对接</strong></h2>
<p>HowTrader 支持接收来自 <strong>TradingView</strong> 的交易信号，实现全自动化交易。</p>
<p><strong>1.配置 Webhook 服务器</strong></p>
<pre><code class="hljs language-csharp">
<span class="hljs-keyword">from</span> flask import Flask, request
<span class="hljs-keyword">from</span> howtrader.<span class="hljs-keyword">event</span> import Event, EventEngine
<span class="hljs-keyword">from</span> howtrader.trader.<span class="hljs-keyword">event</span> import EVENT_TV_SIGNAL

app = Flask(__name__)
event_engine = EventEngine()

@app.route(<span class="hljs-string">'/webhook'</span>, methods=[<span class="hljs-string">'POST'</span>])
<span class="hljs-function">def <span class="hljs-title">webhook</span>():
    data</span> = request.json
    <span class="hljs-keyword">event</span> = Event(EVENT_TV_SIGNAL, data)
    event_engine.put(<span class="hljs-keyword">event</span>)
    <span class="hljs-keyword">return</span> {<span class="hljs-string">"status"</span>: <span class="hljs-string">"success"</span>}

<span class="hljs-keyword">if</span> __name__ == <span class="hljs-string">"__main__"</span>:
    app.run(host=<span class="hljs-string">"0.0.0.0"</span>, port=<span class="hljs-number">9999</span>)
</code></pre>
<p><code>2.在 TradingView 中添加 Webhook</code></p>
<ul>
<li>
进入 TradingView，创建一个新策略
</li>
<li>
选择 <strong>Webhook URL</strong>
</li>
<li>
输入 <code>http://your-server-ip:9999/webhook</code>
</li>
<li>
交易信号触发时，HowTrader 将自动执行对应的交易指令
</li>
</ul>

<h2 class="wp-block-heading">第一步：连接邮箱读取发票附件</h2>

<p class="wp-block-paragraph">n8n 支持 IMAP（收件）与 Microsoft Outlook / Gmail 节点。以 <strong>IMAP</strong> 为例：</p>

<ul class="wp-block-list">
<li>Host：<code>imap.example.com</code></li>
<li>User / Password：专用发票邮箱</li>
<li>搜索条件：<code>UNSEEN</code>（未读）+ 主题含「发票」「invoice」</li>
<li>勾选「Download Attachments」</li>
</ul>

<pre><code>关键配置：
  Mailbox: INBOX
  Post Process Action: "Nothing"（处理完再标记，避免丢信）
  Search Criteria: UNSEEN
</code></pre>

<p class="wp-block-paragraph">用 <strong>Filter / IF</strong> 节点只保留附件名以 <code>.pdf</code> 结尾的：</p>

<pre><code>条件：attachment.fileName 以 ".pdf" 结尾
</code></pre>

<h2 class="wp-block-heading">第二步：用 OCR 节点提取文本</h2>

<p class="wp-block-paragraph">n8n 1.x 及以上版本内置 <strong>Extract from File</strong> 节点，可选引擎：</p>

<ul class="wp-block-list">
<li><strong>Built-in OCR（暂态）</strong>：轻量，适合标准 PDF</li>
<li>接 Google Vision / Azure Document Intelligence / 自建 OCR：精度更高</li>
</ul>

<p class="wp-block-paragraph">以 <strong>Extract from File</strong> 节点为例：</p>

<ul class="wp-block-list">
<li>Operation：<code>Extract from PDF</code></li>
<li>选 <code>Text</code> 或配合 OCR 引擎得到文本层</li>
</ul>

<p class="wp-block-paragraph">若 PDF 是扫描件（无文本层），需走 OCR 引擎：</p>

<pre><code>调用示例（Google Vision）：
POST https://vision.googleapis.com/v1/images:annotate?key={{ <span class="katex math inline">env.GOOGLE_KEY }}
Body:
{
  "requests": [{
    "image": { "content": "{{</span>binary.data }}" },
    "features": [{ "type": "DOCUMENT_TEXT_DETECTION" }]
  }]
}
</code></pre>

<p class="wp-block-paragraph">把返回的 <code>fullTextAnnotation.text</code> 存为 <code>ocrText</code>。</p>

<h2 class="wp-block-heading">第三步：用正则提取关键字段</h2>

<p class="wp-block-paragraph">中文发票常见字段，用 <strong>Code</strong> 节点配合正则抽取：</p>

<pre><code class="language-javascript">const t = <span class="katex math inline">json.ocrText || '';
const pick = (re, def = '') => {
  const m = t.match(re);
  return m ? m[1].trim() : def;
};
const amount   = pick(/价税合计[（(]?大写[)）]?.*?￥?\s*([\d,]+\.?\d*)/i)
              || pick(/金额[：:]\s*([\d,]+\.?\d*)/);
const taxNo    = pick(/纳税人识别号[：:]\s*([A-Z0-9]{15,20})/i);
const seller   = pick(/销售方名称[：:]\s*([^\n]+)/);
const date     = pick(/开票日期[：:]\s*(\d{4})年(\d{2})月(\d{2})日/);
const invoiceNo= pick(/发票号码[：:]\s*(\d{8,20})/);
return [{
  json: {
    amount: parseFloat((amount || '0').replace(/,/g, '')),
    taxNo, seller, invoiceNo,
    date: date ? `</span>{date[1]}-<span class="katex math inline">{date[2]}-</span>{date[3]}` : ''
  }
}];
</code></pre>

<p class="wp-block-paragraph">常用正则速查：</p>

<ul class="wp-block-list">
<li>税号：<code>[A-Z0-9]{15,20}</code></li>
<li>金额：<code>[¥￥]?\s*([\d,]+\.\d{2})</code></li>
<li>日期：<code>\d{4}[-/年]\d{1,2}[-/月]\d{1,2}</code></li>
</ul>

<h2 class="wp-block-heading">第四步：校验与去重</h2>

<ul class="wp-block-list">
<li><strong>必填校验</strong>：<code>amount</code>、<code>taxNo</code>、<code>invoiceNo</code> 任一缺失 → 进「人工复核」分支并告警。</li>
<li><strong>去重</strong>：用 <code>invoiceNo + taxNo</code> 查询 Google Sheets 是否已存在，避免重复记账。</li>
</ul>

<h2 class="wp-block-heading">第六步：对账与汇总</h2>

<p class="wp-block-paragraph">在 Google Sheets 里加公式做自动对账：</p>

<pre><code>=SUMIF(销售方列, "某供应商", 金额列)   // 按供应商汇总
=COUNTIF(发票号码列, "")               // 检查缺号
</code></pre>

<p class="wp-block-paragraph">也可在 n8n 里加一个「每月 1 号生成上月汇总」的 Schedule 工作流，自动发邮件/飞书给财务。</p>

<h2 class="wp-block-heading">第七步：异常处理与人工兜底</h2>

<p class="wp-block-paragraph">OCR 不是 100% 准。务必保留原始 PDF：把附件转存到 Google Drive 子文件夹，文件名用 <code>发票号码_销售方.pdf</code>，表格里留下载链接，财务可一键复核。</p>

<h2 class="wp-block-heading">合规与安全</h2>

<ul class="wp-block-list">
<li>发票含敏感税务信息，建议邮箱与工作流限定内网或加密存储。</li>
<li>OCR 用第三方云服务时，确认供应商具备数据合规资质，或改用自托管 OCR（如 PaddleOCR）保证数据不出域。</li>
</ul>

<h2 class="wp-block-heading">总结</h2>

<p class="wp-block-paragraph">发票对账的自动化不在于「多聪明」，而在于「把重复的抄写外包给机器」。n8n + OCR + Google Sheets 这套组合，让财务从录表工变成审单员，准确率与效率双升。</p>

<h2 class="wp-block-heading">FAQ</h2>

<p class="wp-block-paragraph"><strong>Q1：扫描件（图片型 PDF）也能识别吗？</strong><br />
能，但需走 OCR 引擎（Google Vision / Azure / 自托管 PaddleOCR）。纯文本提取节点对无文字层的 PDF 无效。</p>

<p class="wp-block-paragraph"><strong>Q2：OCR 识别金额出错怎么办？</strong><br />
保留原始附件链接 + 人工复核分支；对「金额缺失/格式异常」的发票自动挂起并告警，不写表，由财务确认。</p>

<p class="wp-block-paragraph"><strong>Q3：Google Sheets 免费版接口有限频吗？</strong><br />
有（约 60 次/分钟读、写入更少）。低频发票场景够用；量大的团队建议批量写入（一次多行）或迁移到 Postgres。</p>

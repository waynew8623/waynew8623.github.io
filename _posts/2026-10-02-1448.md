<h2>二、Bitwarden 免费版 10 分钟上手</h2>
<h3>1. 注册账号，设好主密码</h3>
<p>打开 bitwarden.com 注册，只需要邮箱。最关键的一步是<strong>主密码</strong>：这是你唯一要记住的密码，也是解密整个密码库的钥匙。建议用&#8221;密码短语&#8221;——比如 4-5 个随机中文词组合，长度 20 位以上，例如&#8221; correct-horse-battery-staple &#8220;式的中文版。它既好记又难破解。</p>
<p>⚠️ <strong>主密码没有&#8221;找回&#8221;按钮</strong>。零知识架构意味着官方也解不开你的库，忘了主密码就只能删号重来。写在纸上锁进抽屉，是比存在备忘录里更安全的做法。</p>
<h3>2. 装上全平台客户端</h3>
<ul>
<li><strong>浏览器扩展</strong>：Chrome / Edge / Firefox / Safari 商店搜&#8221;Bitwarden&#8221;，登录后开启自动填充。</li>
<li><strong>手机 App</strong>：iOS / Android 官方应用，开启指纹/面容解锁，以后打开 App 刷脸就行。</li>
<li><strong>桌面端</strong>：Windows / macOS / Linux 客户端，可选。</li>
</ul>
<p>登录一次，全设备自动同步。免费版支持无限设备，这点很多竞品的免费版都做不到。</p>
<h3>3. 把旧密码搬进来</h3>
<p>还在用 Chrome 记住密码或 LastPass？Bitwarden 支持一键导入：</p>
<ol>
<li>在 Chrome 设置 → 自动填充 → 密码管理 → 导出（得到 CSV 文件）；</li>
<li>打开 Bitwarden 网页版 → 工具 → 导入 → 选择&#8221;Chrome (csv)&#8221;上传；</li>
<li>导入完成后<strong>立刻删除 CSV 文件</strong>，它是明文的。</li>
</ol>
<p>然后去&#8221;设置 → 安全 → 双重登录&#8221;，用 Authenticator App（如 Google Authenticator）给 Bitwarden 账号加上 TOTP 两步验证。注意区分：<strong>用 TOTP App 保护 Bitwarden 登录是免费的</strong>；而 Bitwarden 内置的&#8221;TOTP 验证器&#8221;（自动帮你填网站验证码）是 Premium 功能，每年约 $19.80（2026 年调价后价格，以下单时官网为准）。如果这点让你心动，看到第五节的 Vaultwarden 自建方案——自建直接免费用上。</p>
<h2>三、为什么要自建？Vaultwarden 是什么</h2>
<p>Vaultwarden（原名 bitwarden_rs）是一个用 Rust 写的<strong>非官方 Bitwarden 兼容服务器</strong>，和 Bitwarden 公司没有隶属关系。它的特点：</p>
<ul>
<li><strong>极轻量</strong>：单个容器，空闲内存约 10MB 级别，树莓派、1 核 1G 小鸡都能跑；官方服务器则是一堆容器 + SQL Server 级别的重量。</li>
<li><strong>客户端通用</strong>：所有官方 Bitwarden 客户端（浏览器扩展、手机 App、桌面端）都能直接连，体验和官方云一模一样。</li>
<li><strong>高级功能免许可</strong>：组织共享、TOTP 验证器、文件附件、Bitwarden Send、紧急访问等，在官方云需要付费的功能，自建全部可用。</li>
<li><strong>数据主权</strong>：加密后的密码库只存在你自己的服务器上，没有任何第三方经手。</li>
</ul>
<p>代价也很实在：备份、更新、防护都得自己来。能接受这点，继续往下看。</p>

<h2>四、Vaultwarden Docker 自建分步教程</h2>
<h3>步骤 0：准备工作</h3>
<ul>
<li>一台 VPS：1 核 1G 内存、10G 硬盘就绰绰有余。没有服务器可以看本站《<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/542/">永久免费云服务器盘点：Oracle Cloud（甲骨文）保活与网络调优全攻略</a>》，免费 VPS 就能跑。</li>
<li>一个域名（如 <code>vault.example.com</code>），并把 A 记录解析到 VPS 的 IP。<strong>手机/桌面客户端只认 HTTPS</strong>（localhost 除外），所以域名 + 证书是刚需。</li>
<li>VPS 上装好 Docker 和 Docker Compose 插件。</li>
</ul>
<p>没有公网 IP 的家庭宽带用户，可以用 Cloudflare Tunnel 把服务暴露出去，参考本站《<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/547/">无公网 IP 方案：利用 Cloudflare Tunnel、Tailscale 与 Zerotier 实现远程访问</a>》。</p>
<h3>步骤 1：写 Docker Compose 配置</h3>
<pre><code class="language-bash line-numbers">mkdir -p ~/vaultwarden && cd ~/vaultwarden
nano compose.yml
</code></pre>
<p>填入以下内容（把域名换成你自己的）：</p>
<pre><code class="language-yaml line-numbers">services:
  vaultwarden:
    image: vaultwarden/server:latest
    container_name: vaultwarden
    restart: always
    environment:
      DOMAIN: "https://vault.example.com"   # 你的域名，反向代理场景必填
      SIGNUPS_ALLOWED: "true"               # 先允许注册，建好账号后改成 false
      ADMIN_TOKEN: "换成一串强随机字符串"    # 管理后台 /admin 的密码
    volumes:
      - ./vw-data:/data                     # 密码库数据，务必备份这个目录
    ports:
      - "127.0.0.1:8080:80"                 # 只监听本机，由反向代理转发
</code></pre>
<p>生成强随机 ADMIN_TOKEN 的命令：</p>
<pre><code class="language-bash line-numbers">openssl rand -base64 48
</code></pre>
<h3>步骤 2：Caddy 反向代理 + 自动 HTTPS</h3>
<p>Caddy 会自动申请并续期 Let&#8217;s Encrypt 证书，最省心。同一目录下再起一个 Caddy（或复用已有的）：</p>
<pre><code class="language-bash line-numbers">nano Caddyfile
</code></pre>
<pre><code class="line-numbers">vault.example.com {
    reverse_proxy 127.0.0.1:8080
}
</code></pre>
<pre><code class="language-bash line-numbers">docker run -d --name caddy --restart always \
  -p 80:80 -p 443:443 \
  -v ./Caddyfile:/etc/caddy/Caddyfile \
  -v caddy-data:/data caddy:alpine
</code></pre>
<p>然后启动 Vaultwarden：</p>
<pre><code class="language-bash line-numbers">docker compose up -d && docker compose logs -f
</code></pre>
<p>看到日志正常后，浏览器打开 <code>https://vault.example.com</code>，应该能看到 Bitwarden 风格的登录页。</p>
<h3>步骤 3：注册账号，然后立刻关闭公开注册</h3>
<ol>
<li>点&#8221;创建账号&#8221;，用邮箱 + 强主密码注册（主密码的要求见第二节，同样没有找回按钮）。</li>
<li>回到服务器，把 <code>compose.yml</code> 里的 <code>SIGNUPS_ALLOWED</code> 改成 <code>"false"</code>，然后 <code>docker compose up -d</code> 重建容器。从此陌生人再也无法在你的服务器上注册。</li>
<li>访问 <code>https://vault.example.com/admin</code>，输入 ADMIN_TOKEN 进入管理后台，可以查看用户、做诊断配置。</li>
</ol>
<h3>步骤 4：客户端指向自建服务器</h3>
<ul>
<li><strong>手机 App</strong>：登录界面点左上角齿轮/设置 → &#8220;自托管&#8221; → 服务器 URL 填 <code>https://vault.example.com</code> → 返回登录。</li>
<li><strong>浏览器扩展</strong>：登录页同样有&#8221;服务器区域&#8221;设置，选&#8221;自托管&#8221;并填写域名。</li>
<li><strong>桌面端</strong>：设置 → 自托管服务器，填写域名。</li>
</ul>
<p>之后的使用和官方云完全一致：自动填充、密码生成器、组织共享、TOTP 验证器全部可用。</p>
<h3>步骤 5：从官方云（或其他密码管理器）迁移</h3>
<p>已经在用 Bitwarden 官方版？迁移就是一次导出导入：</p>
<ol>
<li>旧 vault：网页版 → 工具 → 导出 → 选择&#8221;加密的 JSON（密码保护）&#8221;并设密码，下载文件；</li>
<li>新自建 vault：同样位置选择导入，上传文件并输入导出密码；</li>
<li>确认条目无误后，可注销旧账号。</li>
</ol>
<p>从 Chrome / 1Password / KeePass 迁移同理，Bitwarden 的导入向导支持几十种格式。</p>
<h3>步骤 6：备份与更新（自建的必修课）</h3>
<p><strong>备份</strong>：所有数据都在 <code>./vw-data</code> 目录（核心是 <code>db.sqlite3</code>）。加一条定时任务每天打包：</p>
<pre><code class="language-bash line-numbers"># 每天凌晨 3 点备份到 /backup，保留 7 天
0 3 * * * tar -czf /backup/vw-$(date +\%F).tar.gz -C ~/vaultwarden vw-data && find /backup -name 'vw-*.tar.gz' -mtime +7 -delete
</code></pre>
<p>备份文件最好再异地存一份（对象存储、网盘、另一台机器都行），<strong>丢了这个目录就等于丢了所有密码</strong>。</p>
<p><strong>更新</strong>：Vaultwarden 更新频繁，一条命令搞定：</p>
<pre><code class="language-bash line-numbers">cd ~/vaultwarden && docker compose pull && docker compose up -d
</code></pre>
<p>建议每月检查一次更新。</p>

<h2>七、FAQ</h2>
<p><strong>Q1：Vaultwarden 和 Bitwarden 官方是什么关系？</strong><br />
没有隶属关系。Vaultwarden 是社区开源项目（原名 bitwarden_rs），用 Rust 重新实现了兼容 Bitwarden 客户端协议的服务器。它不经过 Bitwarden 公司审计，适合信任社区代码、愿意自己运维的用户；企业合规场景建议用官方方案。</p>
<p><strong>Q2：Bitwarden 免费版真的够用吗？什么时候需要付费？</strong><br />
对个人用户基本够用：无限条目、无限设备、密码生成器、Passkey 都免费。只有当你需要内置 TOTP 验证器、1GB 加密文件附件、密码健康报告、紧急访问时，才需要 Premium（约 $19.80/年，以官网为准）——或者直接自建 Vaultwarden，这些功能免费用。</p>
<p><strong>Q3：自建一定要买 VPS 和域名吗？</strong><br />
手机和桌面客户端强制要求 HTTPS，所以对外提供服务时域名 + 证书是刚需（Caddy 可全自动搞定）。如果只在家庭内网用，可以不买域名，配合内网穿透/Tailscale 访问。服务器用免费 VPS 或家里旧电脑/树莓派都行。</p>
<p><strong>Q4：忘记主密码怎么办？</strong><br />
没有办法找回。零知识架构下连服务器运营者（也就是你自己）都解不开。预防措施：主密码写在纸上异地保存；Bitwarden 官方云用户可购买 Premium 开通&#8221;紧急访问&#8221;指定可信联系人；自建用户务必做好加密导出备份。</p>
<p><strong>Q5：KeePass 和 Bitwarden/Vaultwarden 怎么选？</strong><br />
KeePass 是纯本机密码库文件，同步靠自己（网盘/WebDAV），适合不信任任何服务器的极客；Bitwarden 系是&#8221;服务器同步&#8221;模式，多设备体验好得多。想要两者兼得，可以用 KeePassXC + 自建同步，但复杂度更高。</p>
<p><strong>Q6：自建的 Vaultwarden 数据存在哪？重装系统会丢吗？</strong><br />
存在你映射的 <code>./vw-data</code> 目录（SQLite 数据库 <code>db.sqlite3</code> + 附件）。重装系统前备份这个目录即可迁移；建议按本文步骤 6 做自动定时备份。</p>
<p><strong>Q7：手机 App 连接自建服务器一直失败？</strong><br />
按这个顺序排查：① 域名 DNS 是否解析到服务器 IP；② 浏览器访问 <code>https://域名</code> 有无证书警告；③ 服务器防火墙是否放行 80/443；④ App 登录页是否切换到了&#8221;自托管&#8221;并填对了 <code>https://</code> 开头的完整地址。</p>
<p><strong>Q8：Bitwarden 官方也有自托管方案，还用 Vaultwarden 吗？</strong><br />
官方提供 Bitwarden Unified 自托管镜像，但资源占用和配置复杂度都高于 Vaultwarden。个人/家庭场景下，Vaultwarden 的单容器 + SQLite 方案更轻更快；企业需要合规审计和官方支持时再考虑官方方案。</p>

<p>在服务器上部署一个随时可以访问的 JupyterLab，是很多开发者数据分析、机器学习和远程开发的首选方案。本教程将带你从零开始在 Linux 服务器上用 Docker 部署 JupyterLab，并解决每次登录都要输入 Token 的烦恼。</p>
<h2>为什么选择用 Docker 部署 JupyterLab</h2>
<p>JupyterLab 是集合了 Jupyter Notebook 所有功能的在线 IDE，可以通过 Web 随时随地访问。</p>
<p>相比直接在服务器上安装，使用 Docker 部署有三大好处：</p>
<ul>
<li><strong>环境隔离</strong>：容器与宿主机互相独立，不会污染服务器环境；</li>
<li><strong>一键部署</strong>：拉取镜像后一条命令即可运行，升级、迁移都很方便；</li>
<li><strong>多架构支持</strong>：官方镜像同时提供 x86_64 和 ARM64 版本，适合各种服务器。</li>
</ul>
<h2>准备工作</h2>
<p>开始之前，你需要确认以下几点：</p>
<ol>
<li>一台可以访问的 Linux 服务器（本文使用的是<a href="https://waynetalk.com/542/">甲骨文 Oracle Cloud</a> 的 ARM64 Debian 10）；</li>
<li>服务器上已安装 Docker；</li>
<li>一个用于存放代码文件的挂载目录。</li>
</ol>
<h2>Docker 部署 JupyterLab 步骤</h2>
<p>整个部署过程只有四步：拉取镜像、创建挂载目录、运行容器、访问页面。</p>
<h3>1. 拉取镜像</h3>
<p>去 Docker Hub 搜索 Jupyter 相关镜像，有很多选择，安装方式基本一样。这里我选择的是 <code>jupyter/scipy-notebook</code>，它预装了科学计算常用的库（SciPy、NumPy、Pandas 等）。</p>
<p><img decoding="async" src=":/4cd6d933c0a04420916f0a4dc96436f8" alt="b718d718bb7eae998af3e4befa947a70.png" /></p>
<pre><code class="language-bash line-numbers">docker pull jupyter/scipy-notebook
</code></pre>
<h3>2. 创建挂载目录</h3>
<p>这个目录是 Jupyter 的文件存储目录，你在 Jupyter 上创建的所有项目都会保存在这里。为了防止容器内用户（默认 <code>jovyan</code>）写文件时出现权限问题，这里直接修改为 777。</p>
<pre><code class="language-bash line-numbers">mkdir -p /opt/jupyter/book
chmod 777 /opt/jupyter/book
</code></pre>
<h3>3. 运行容器</h3>
<p>JupyterLab 的部署很简单，一条 <code>docker run</code> 命令就够了：</p>
<pre><code class="language-bash line-numbers">sudo docker run --name my-jupyter -d \
  -p 8080:8888 \
  -v /opt/jupyter/book:/home/jovyan \
  jupyter/scipy-notebook
</code></pre>
<p>简单解释一下两个关键参数：</p>
<ul>
<li><strong><code>-p 8080:8888</code></strong>：对外暴露的端口是 8080，映射到容器内部的 8888 端口。可以根据需要修改对外端口；</li>
<li><strong><code>-v /opt/jupyter/book:/home/jovyan</code></strong>：宿主机目录挂载到容器目录。其中 <code>/home/jovyan</code> 是写死的，不能更改，改了会导致容器启动失败（亲测）。</li>
</ul>
<h3>4. 访问 JupyterLab</h3>
<p>容器启动成功后，通过「服务器 IP + 端口」即可访问 JupyterLab：</p>
<pre><code class="line-numbers">http://你的服务器IP:8080
</code></pre>
<p>第一次访问时，页面会要求填写 Token 才能登录。</p>
<h2>如何解决每次登录都需要 Token 的问题</h2>
<p>默认情况下，Jupyter 每次重启都会生成一个新的 Token，登录非常麻烦。下面提供两种解决方案。</p>
<h3>方式一：查询并保存当前 Token</h3>
<p>Token 有两个来源：</p>
<p><strong>方法 A：查看容器日志</strong></p>
<pre><code class="language-bash line-numbers">docker logs my-jupyter
</code></pre>
<p>在日志中找到 <code>?token=xxxxxxxx</code> 这一行，后面的字符串就是 Token。</p>
<p><strong>方法 B：在容器内直接查询</strong></p>
<pre><code class="language-bash line-numbers">docker exec my-jupyter jupyter server list
</code></pre>
<h3>方式二：设置固定密码（推荐）</h3>
<p>设置密码后，登录界面会从「Token 输入框」变成「密码输入框」，以后登录只需输入密码，一劳永逸：</p>
<pre><code class="language-bash line-numbers">docker exec -it my-jupyter jupyter server password
</code></pre>
<p>按提示输入并确认密码即可。下次访问 JupyterLab 时，直接使用该密码登录，不再需要每次查询 Token。</p>
<h2>常见问题</h2>
<p><strong>Q1：为什么改了 <code>/home/jovyan</code> 就启动失败？</strong></p>
<p>Jupyter 官方镜像约定工作目录就是 <code>/home/jovyan</code>，这个路径不能修改，只改宿主机一侧的挂载目录即可。</p>
<p><strong>Q2：部署后无法访问页面？</strong></p>
<p>先检查 Docker 容器是否正常运行：</p>
<pre><code class="language-bash line-numbers">docker ps
</code></pre>
<p>再确认服务器安全组/<a href="https://waynetalk.com/75/">防火墙是否放行了对应的端口</a>（如 8080）。</p>
<p><strong>Q3：ARM 服务器能用这个镜像吗？</strong></p>
<p>可以。<code>jupyter/scipy-notebook</code> 官方提供 ARM64 镜像，在甲骨文 ARM 服务器上可直接使用。</p>
<p><strong>Q4：把端口暴露到公网安全吗？</strong></p>
<p><a href="https://waynetalk.com/547/">不建议直接把 Jupyter 端口暴露到公网</a>。如果必须开放，请务必设置强密码或固定 Token，并建议配合 HTTPS <a href="https://waynetalk.com/cloudflare-tunnel-nas-guide/">反向代理</a>（如 Caddy、Nginx）使用。</p>
<h2>总结</h2>
<p>通过 Docker 部署 JupyterLab 非常简单：拉取镜像 → 创建挂载目录 → <code>docker run</code> 一条命令运行 → 设置固定密码后登录。整个过程只需几分钟，而且环境完全隔离，非常适合在服务器上长期使用。</p>

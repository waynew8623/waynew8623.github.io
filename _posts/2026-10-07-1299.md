<h2>二、准备工作：你需要什么</h2>
<ul>
<li>一个 Cloudflare 账号（免费注册即可；开通 R2 时可能要求绑定支付方式用于超额计费，免费额度内不扣费）</li>
<li>一个托管在 Cloudflare 的域名（用于自定义图床域名；没有也行，先用 R2 提供的临时域名顶着）</li>
<li>PicGo（开源免费，从 GitHub 下载最新版）</li>
</ul>
<h2>三、分步搭建：R2 + PicGo</h2>
<h3>步骤 1：创建 R2 存储桶</h3>
<ol>
<li>登录 Cloudflare 控制台 → 左侧 <strong>R2</strong> → 首次使用点&#8221;开通&#8221;。</li>
<li>创建存储桶（Bucket），比如 <code>my-image-bed</code>，位置选&#8221;自动&#8221;。</li>
<li>记下<strong>桶名</strong>和<strong>账户 ID</strong>（Account ID，在控制台右侧栏可见）。</li>
</ol>
<h3>步骤 2：创建 API 令牌</h3>
<p>PicGo 通过 S3 兼容 API 上传，需要一对访问密钥：</p>
<ol>
<li>R2 → 管理 R2 API 令牌 → 创建令牌。</li>
<li>权限选&#8221;对象读 / 写&#8221;，作用域限定到你的图床桶（最小权限原则）。</li>
<li>保存好 <code>Access Key ID</code> 与 <code>Secret Access Key</code>——只显示一次，丢了只能重建。</li>
</ol>
<blockquote><p>
  🔒 安全提醒：密钥只填在本地 PicGo 配置里，不要写进 Markdown、提交到公开仓库，更不要截图外传。
</p></blockquote>
<h3>步骤 3：安装并配置 PicGo</h3>
<ol>
<li>从 PicGo 官方 GitHub 发布页（<code>Molunerfinn/PicGo</code>）下载对应系统的最新版安装（Windows 选 exe，macOS 选 dmg）。</li>
<li>打开 PicGo → 插件设置 → 搜索安装 S3 兼容插件（<code>picgo-plugin-s3</code>，或专用的 <code>@tianlelyd/picgo-plugin-cloudflare-r2</code>）。</li>
<li>图床设置 → 选择 S3（或 cloudflare-r2），按下面对照表填写：</li>
</ol>

</p></blockquote>
<h3>步骤 4：绑定自定义域名 + CDN 加速</h3>
<p><code>pub-xxx.r2.dev</code> 是临时域名，有速率限制、不适合长期用，生产姿势是绑定自己的域名：</p>
<ol>
<li>R2 桶 → 设置 → 公开访问，添加自定义域（如 <code>img.yourdomain.com</code>）。</li>
<li>域名 DNS 已托管在 Cloudflare 时，会自动添加 CNAME 并签发 SSL 证书。</li>
<li>回到 PicGo，把&#8221;自定义域名&#8221;改成 <code>https://img.yourdomain.com</code>。</li>
</ol>
<p>从此图片 URL 就是你自己的域名，且走 Cloudflare 全球 CDN 缓存——加载快、出站依然 0 流量费。</p>

<h2>五、进阶用法</h2>
<h3>1. Typora 联动：截图粘贴即上传</h3>
<p>写 Markdown 最爽的姿势：截图 → 粘贴 → 图片自动上传并替换为图床链接。</p>
<p>Typora 开启路径：偏好设置 → 图像 → 插入图片时选&#8221;上传图片&#8221;，服务选&#8221;PicGo (app)&#8221;并指定安装路径，验证通过后，粘贴 / 拖入的图片都会自动走 R2。</p>
<h3>2. CDN 缓存优化</h3>
<p>图片适合长缓存：设置 <code>Cache-Control: public, max-age=31536000, immutable</code> 让边缘节点长期缓存，减少回源——B 类读取操作免费额度约 1000 万次 / 月，能省则省。</p>
<h3>3. 上传前压缩：WebP 是省钱利器</h3>
<p>5MB 的截图压成 300KB 的 WebP，画质几乎无损，存储和请求量直降 90%。推荐用 Google 开源的 Squoosh 本地压缩（本站另有<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/781/">详细介绍</a>）后再上传。</p>
<h3>4. 配合博客：写作 &#8211; 配图 &#8211; 托管一条龙</h3>
<p>如果你用 Cloudflare Pages + Hugo / Hexo 搭博客（参考本站<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/543/">《0 元搭建个人独立博客》</a>），R2 图床 + 自定义域名就是天然搭档：文章图片全走 <code>img.你的域名.com</code>，换主题、迁移平台都不用改图链。R2 也只是 Cloudflare 免费生态的一环，Workers、Tunnel、Pages 都能白嫖，详见<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/767/">《Cloudflare 免费生态实战指南》</a>。</p>
<h2>六、使用中的常见问题（避坑）</h2>
<ul>
<li><strong>图片被刷量会扣费吗？</strong> 出站免费，访问量再大也不产生流量费；但极端请求量可能触及 B 类额度，建议加 WAF 速率限制规则防滥用。</li>
<li><strong>临时域名 <code>r2.dev</code> 能长期用吗？</strong> 不建议，有速率限制，尽早换成自定义域名。</li>
<li><strong>密钥泄露了怎么办？</strong> 立刻删除旧令牌、重建新令牌，并更新 PicGo 配置。</li>
<li><strong>本地原图要不要留？</strong> 要。图床只服务于展示，源文件自己留备份，桶误删可重建。</li>
<li><strong>一个桶还是多个桶？</strong> 个人博客一个桶足够；R2 按账户计费，多建桶也不多花钱。</li>
</ul>
<h2>七、FAQ</h2>
<p><strong>Q1：R2 免费额度到底是多少？</strong><br />
A：按 2026 年 9 月公开定价整理：每月约 10GB 标准存储、约 100 万次 A 类操作（写入 / 列出）、约 1000 万次 B 类操作（读取），出站流量免费；超出部分按量计费（存储约 $0.015 / GB·月）。政策会变，以官网定价页为准。</p>
<p><strong>Q2：开通 R2 一定要绑定支付方式吗？</strong><br />
A：可能要求绑定支付方式用于超额计费，免费额度内不会扣费，属常规防滥用手段。</p>
<p><strong>Q3：不用 PicGo 可以吗？</strong><br />
A：可以。rclone、编辑器插件、R2 网页控制台都行，原理相同，见第四节对比。</p>
<p><strong>Q4：国内访问速度怎么样？</strong><br />
A：Cloudflare 国内无节点，直连速度看运营商；图片经 CDN 缓存后通常可接受。速度敏感可叠加国内 CDN 回源（需备案域名）。</p>
<p><strong>Q5：R2 能当网盘存大文件 / 视频吗？</strong><br />
A：技术上可以，但免费额度仅约 10GB，大文件高频读取还消耗 B 类额度。图床定位是&#8221;网页展示用图&#8221;，别当网盘使。</p>
<p><strong>Q6：自定义域名需要备案吗？</strong><br />
A：走 Cloudflare CDN（境外节点）无需备案；但微信 / QQ 内打开境外域名可能被拦截，分享到国内社交场景时注意。</p>
<p><strong>Q7：旧文（/546/）的方法还适用吗？</strong><br />
A：核心步骤依然适用；本文刷新了额度数字，补充了方案横评、多种上传方式对比与进阶内容，建议按本文操作。</p>
<p><strong>Q8：图片 URL 想换个路径前缀怎么办？</strong><br />
A：在 PicGo S3 插件配置里设 Path（如 <code>%Y/%m/</code>），上传自动按年月分目录。</p>
<h2>总结</h2>
<p>R2 + PicGo 依然是 2026 年个人免费图床的最优解：出站流量免费击中成本痛点，S3 兼容让工具随手可用，自定义域名 + CDN 让链接体面又快速。每月约 10GB 存储与千万级请求额度，撑起个人博客配图绰绰有余。</p>

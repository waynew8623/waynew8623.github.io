<h2>二、逐渠道详解</h2>
<h3>1. Mistral La Plateforme：欧洲厂商的约 10 亿 token/月</h3>
<p>Mistral 的 &#8220;Experiment&#8221; 免费计划是目前免费档里额度上限最夸张的之一：<strong>约 1 req/s、约 50 万 token/分钟、约 10 亿 token/月</strong>，覆盖 Mistral Large、Medium、Small、Ministral、Codestral 全系模型，OpenAI 接口兼容。</p>
<p>但有两个代价：<br />
&#8211; <strong>需要手机验证</strong>，国内手机号亲测可收码（以实际为准）；<br />
&#8211; <strong>必须同意数据用于模型训练</strong>（有 opt-out 选项）。写敏感业务代码、传内部文档时，请避开免费档。</p>
<p>它最适合当<strong>代码补全和批量任务的低成本兜底</strong>：<code>mistral-small</code> 的免费限速相对宽松，可以给开发环境的脚本、评测任务用。注意 <code>*-latest</code> 别名会漂移，正式用请 pin 具体 dated 模型名。</p>
<pre><code class="language-python line-numbers">from openai import OpenAI
client = OpenAI(api_key="YOUR_MISTRAL_KEY", base_url="https://api.mistral.ai/v1")
r = client.chat.completions.create(model="mistral-small-latest",
    messages=[{"role": "user", "content": "解释一下什么是向量数据库"}])
print(r.choices[0].message.content)
</code></pre>
<h3>2. Cerebras：每天约 100 万 token 的&#8221;速度怪物&#8221;</h3>
<p>Cerebras 靠自研 WSE 芯片做推理，免费档约 <strong>100 万 token/天、约 30 RPM、约 6 万 token/分钟</strong>，注册无需信用卡。免费模型有 GPT-OSS、Llama、Qwen3、GLM 等大体量开源模型（免费层上下文约 8K token 上限）。本站之前写过一期 <a class="wp-editor-md-post-content-link" href="https://waynetalk.com/313/">Cerebras 白嫖攻略</a>，站内用户应该不陌生。</p>
<p>三个实测经验：<br />
&#8211; <strong>TPM 才是真天花板</strong>：一天 100 万 token 听起来多，但每分钟约 6 万的限制意味着，一次塞 4 万 token 的长文档请求直接被拒，而不是排队。免费档适合&#8221;大量小请求&#8221;，不适合&#8221;少量大请求&#8221;。<br />
&#8211; <strong>适合长跑迭代</strong>：每天 UTC 午夜重置，做 Agent 调试、批量评测时，Cerebras 的每日重置比 Groq 的按分钟限速更友好。<br />
&#8211; <strong>政策风险预警</strong>：2026 年 9 月有第三方资料称 Cerebras 免费政策可能调整为&#8221;新用户赠金+绑定付款方式&#8221;模式。两个说法并存，说明它在变动期。<strong>注册时看清当前条款，别把免费档当成生产依赖。</strong></p>
<h3>3. Kimi 开放平台：国内直连的长文本利器</h3>
<p>月之暗面的 Kimi 开放平台（platform.moonshot.cn）给新用户约 <strong>15 元体验代金券</strong>，有效期约 3 个月。门槛是国内手机号注册 + 个人实名认证，OpenAI 接口兼容，<code>base_url</code> 换成 <code>https://api.moonshot.cn/v1</code> 即可。</p>
<p>它的杀手锏是<strong>长上下文</strong>：新一代 Kimi K3 支持约 100 万 token 上下文，对长文档问答、代码库级分析这类场景特别友好。顺带一提，Kimi 模型在阿里云百炼上也有约 100 万 token / 90 天的免费试用（参考），想体验又不想多注册一个账号可以走百炼。</p>
<p>注意 Kimi 官方协议明确禁止转让/出借 API Key，<strong>不要在公益站之间倒卖或分享你的 Kimi Key</strong>，轻则限流重则封号。</p>

<h3>6. Claude 平替路线：Anthropic 官方没有免费 API 怎么办？</h3>
<p>先说清楚：<strong>Anthropic 官方没有永久免费的 Claude API</strong>。任何声称&#8221;免费 Claude API&#8221;的公开 key，基本是以下三种之一：别人分享的裸 key（几小时就死）、公益站的赠送额度（随时关停）、网页逆向通道（违反 ToS、随时失效、还有降智风险）。</p>
<p>靠谱的平替路线有三条：</p>
<ol>
<li><strong>GitHub Models 限次体验</strong>：官方授权的免费入口，额度虽少，但用来验证&#8221;这个需求是否真的需要 Claude 级别&#8221;足够了。</li>
<li><strong>开源模型代打</strong>：Kimi K3（约 2.8T 参数、约 100 万上下文）、DeepSeek、智谱 GLM，在代码和中文任务上已经是 Claude 的合格替补，且都有官方免费额度。</li>
<li><strong>Claude Code 类工具的平替姿势</strong>：本站的 <a class="wp-editor-md-post-content-link" href="https://waynetalk.com/534/">Cursor / Claude Code 实战</a> 里提到过，工具本身支持换模型，把底层换成免费档的 Mistral/Groq/Cerebras，Agent 流程照样跑。</li>
</ol>
<p>结论：<strong>把&#8221;Claude 平替&#8221;理解成&#8221;能力平替 + 成本平替&#8221;，而不是&#8221;找一个免费的 Claude 接口&#8221;</strong>，心态就对了。</p>

<p>三个必须知道的风险：</p>
<p><strong>1. 稳定性：随时关停是常态。</strong> 公益站的额度来自站长的钱包或薅来的 key，站长不想续费了就直接关。任何把生产流量押在公益站上的做法，都是在赌博。</p>
<p><strong>2. 隐私：你传的东西都经过第三方。</strong> 中转站能看到你全部的 prompt 和返回内容。做实验、跑公开数据没问题；<strong>内部文档、客户数据、带 token 的代码，一律不走中转</strong>。数据敏感的场景请用官方免费档，或本地 Ollama。</p>
<p><strong>3. 跑路与降智：便宜得离谱的一定有问题。</strong> 社区对中转站的研究发现，约 45.83% 的端点返回的模型与请求不符——&#8221;降智&#8221;常常发生在你充值之后。跑路前兆包括：客服消失、账单页打不开、回答质量突然变差、大力推&#8221;充 100 送 50&#8243;。<strong>原则：只小额充值，绝不大额预存；免费额度用完就换站，别留恋。</strong></p>
<p>找公益站的正确姿势：去 GitHub 的 awesome 清单（如 awesome-ai-api-proxy、awesome-ai-api 这类社区维护项目）看实时排行榜和黑名单，而不是搜&#8221;免费 API key&#8221;点进第一个广告站。</p>
<h2>四、多 Key 管理实战：把免费额度叠成&#8221;无限&#8221;</h2>
<p>单个渠道都不够用，但<strong>把 5-8 个免费档叠起来</strong>，个人项目基本可以&#8221;无限续杯&#8221;。核心是做一个带兜底的路由层：</p>
<pre><code class="language-python line-numbers">import os
from openai import OpenAI

PROVIDERS = [
    ("GROQ",     "https://api.groq.com/openai/v1"),
    ("MISTRAL",  "https://api.mistral.ai/v1"),
    ("CEREBRAS", "https://inference.cerebras.ai/v1"),
    ("OPENROUTER","https://openrouter.ai/api/v1"),
    ("KIMI",     "https://api.moonshot.cn/v1"),
]

def chat(messages, model_hint=None):
    last_err = None
    for name, base in PROVIDERS:
        try:
            c = OpenAI(api_key=os.environ[f"{name}_KEY"], base_url=base)
            model = model_hint or "llama-3.3-70b-versatile"
            return c.chat.completions.create(model=model, messages=messages), name
        except Exception as e:  # 429/限流/宕机 → 下一家
            last_err = e
    raise last_err
</code></pre>
<p>工程建议：</p>
<ul>
<li><strong>密钥放环境变量</strong>，别写死在代码里；每个平台的 key 定期轮换一次。</li>
<li><strong>请求按成本排序</strong>：日常走 Groq（快）→ Cerebras（日额度多）→ Mistral（月额度多），长上下文任务单独走 Kimi/Gemini。</li>
<li><strong>监控剩余额度</strong>：OpenRouter 有 <code>/api/v1/key</code> 查剩余额度；其他平台看控制台。写个定时脚本，额度见底的渠道自动降级。</li>
<li><strong>进阶玩法</strong>：用 LiteLLM 或自建 One-API 网关统一管理，一份配置同时管官方 key 和公益站 key，切换时改配置不动代码。</li>
</ul>
<p>顺带一提，选模型前可以先看本站的<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/532/">主流大模型横评</a>，知道每个模型擅长什么，再决定把免费额度花在哪。</p>
<h2>五、FAQ</h2>
<p><strong>Q1：Mistral 的免费额度真的有约 10 亿 token/月吗？</strong><br />
A：是的，这是其 &#8220;Experiment&#8221; 免费计划的公开说法（约 1 req/s、约 50 万 token/分钟、约 10 亿 token/月），但需要手机验证且同意数据用于训练。注意它是按模型限速的，<code>mistral-large</code> 的实际可用速率比 <code>mistral-small</code> 紧得多。</p>
<p><strong>Q2：Cerebras 免费档需要信用卡吗？</strong><br />
A：按 2026 年 9 月主流资料，不需要信用卡，注册即有约 100 万 token/天。但有第三方资料称政策可能调整为新用户赠金+绑定付款方式模式，注册时请以官网当前条款为准。</p>
<p><strong>Q3：有没有真正免费的 Claude API？</strong><br />
A：没有。Anthropic 官方不提供永久免费 API。GitHub Models 的限次调用是少数官方授权的免费入口；其余&#8221;免费 Claude&#8221;多为公益站赠送额度或逆向通道，仅适合临时测试。</p>
<p><strong>Q4：公益站的额度能用来跑生产项目吗？</strong><br />
A：不建议。公益站寿命按天/周计，随时关停，且你的全部数据都会经过第三方。生产项目请用官方免费档起步，量上来后转付费或自建网关。</p>
<p><strong>Q5：Kimi API 的免费额度有多少？</strong><br />
A：新用户约 15 元体验代金券，有效期约 3 个月（参考）。需国内手机号注册+实名认证，国内直连，长上下文是它的强项。</p>
<p><strong>Q6：免费 Embedding 怎么做 RAG 知识库？</strong><br />
A：国内用硅基流动的 BAAI/bge-m3（注册送额度），海外用 Google AI Studio 的 Gemini Embedding 系列（免信用卡），OpenAI 兼容格式，一行改 <code>base_url</code> 即可切换。完全离线就用 Ollama + nomic-embed-text。</p>
<p><strong>Q7：中转站充值安全吗？</strong><br />

<p><strong>Q8：官方免费档 + 公益站 + 中转站，怎么组合最省心？</strong><br />

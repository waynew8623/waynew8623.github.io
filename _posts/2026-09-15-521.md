<h2 class="wp-block-heading">二、Wallabag 是什么</h2>

<p class="wp-block-paragraph">Wallabag 是老牌开源稍后读应用（AGPL 协议），核心能力：</p>

<ul class="wp-block-list">
<li><strong>一键保存</strong>：浏览器插件、移动 App、分享API 保存任意链接。</li>
<li><strong>全文提取</strong>：自动抓取并清洗文章正文，去除广告干扰。</li>
<li><strong>离线归档</strong>：文章内容存进你自己的数据库，原链接失效也不怕。</li>
<li><strong>标签/搜索/标注</strong>：可读、可高亮、可全文检索。</li>
<li><strong>多端</strong>：Web、iOS/Android、第三方客户端（如 Fever API 兼容阅读器）。</li>
</ul>

<h2 class="wp-block-heading">三、自托管 Wallabag（Docker 最简方案）</h2>

<p class="wp-block-paragraph">官方提供 <a href="https://waynetalk.com/756/">Docker</a> 镜像，几分钟拉起：</p>

<pre><code class="language-yaml"># docker-compose.yml 精简示例
services:
  wallabag:
    image: wallabag/wallabag:latest
    restart: always
    ports:
      - "8080:80"
    environment:
      - SYMFONY__ENV__DOMAIN_NAME=https://read.example.com
      - SYMFONY__ENV__SERVER_NAME="My Wallabag"
    volumes:
      - wallabag-data:/var/www/wallabag/data
      - wallabag-uploads:/var/www/wallabag/web/uploads
volumes:
  wallabag-data:
  wallabag-uploads:
</code></pre>

<p class="wp-block-paragraph">启动后访问 <code>http://localhost:8080</code> 注册账号即可。<a href="https://waynetalk.com/tailscale-fn-nas-guide/">若要外网访问</a>，建议用 <strong><a href="https://waynetalk.com/547/">Tailscale</a></strong> 组网或 <strong>Nginx + HTTPS</strong> 反向代理，别裸奔公网。</p>

<h2 class="wp-block-heading">四、把阅读流接进你的知识库</h2>

<p class="wp-block-paragraph">Wallabag 的 API 能与前面文章的工具联动：</p>

<pre><code class="language-yaml">联动思路:
  - Wallabag 保存文章 → 标 #精读 标签
  - 定时脚本拉取标精读的文章 → 转发到 Readwise / <a href="https://waynetalk.com/512/">Obsidian</a>
  - 高亮同步进 Notion "读书高亮"库（参见第2篇输入流）
</code></pre>

<p class="wp-block-paragraph">一个 Python 抓取示例（伪代码）：</p>

<pre><code class="language-python">import requests
token = get_wallabag_token()
r = requests.get("https://read.example.com/api/entries.json",
                 params={"archive": 0, "tags": "精读"},
                 headers={"Authorization": f"Bearer {token}"})
for item in r.json()["_embedded"]["items"]:
    print(item["title"], item["url"])
</code></pre>

<h3 class="wp-block-heading">5.1 怎么选</h3>

<ul class="wp-block-list">
<li>只想&#8221;存文章、离线读、能检索&#8221; → <strong>Wallabag</strong>（本文主线）。</li>
<li>还想管书签、图片、PDF，要 AI 自动整理 → <strong>Karakeep</strong>。</li>
<li>想要最干净的&#8221;读+永久归档&#8221;体验、讨厌花哨 → <strong>Readeck</strong>。</li>
</ul>

<h2 class="wp-block-heading">六、长久归档的三个纪律</h2>

<ol class="wp-block-list">
<li><strong>定期导出备份</strong>：Wallabag 支持导出 EPUB/PDF/JSON，重要文章定期导出<a href="https://waynetalk.com/519/">存 NAS</a>（见第8篇）。</li>
<li><strong>不要只信一家</strong>：核心文章同时存一份到 NAS 或本地 Markdown，平台再怎么变都不慌。</li>
<li><strong>克制订阅源</strong>：<a href="https://waynetalk.com/524/">RSS</a> 自动抓取很爽，但别让&#8221;自动囤&#8221;变成新焦虑，设上限。</li>
</ol>

<h2 class="wp-block-heading">七、从 Omnivore 迁移</h2>

<p class="wp-block-paragraph">如果你曾是 Omnivore 用户：</p>

<pre><code class="language-text">迁移路径:
  1. Omnivore 停服前已导出 → 得到 JSON/OPML
  2. Wallabag 支持导入（或经中间脚本）
  3. Karakeep 官方文档也提供 Omnivore 导入源
  4. 导入后核对标签与高亮是否完整
</code></pre>

<p class="wp-block-paragraph">教训是：<strong>迁移要趁早</strong>，别等服务真关了才发现导出入口也消失了。</p>

<h2 class="wp-block-heading">八、Wallabag 实用配置细节</h2>

<p class="wp-block-paragraph">装好后几个值得调整的设置：</p>

<pre><code class="language-yaml">设置路径（后台 → 设置）:
  - 阅读偏好: 默认深色 / 字号
  - 标签体系: 建 #待读 #精读 #归档 分类
  - 爬虫规则: 对知乎/公众号开启完整抓取
  - 导出格式: 开启 EPUB/PDF/JSON
  - API: 生成客户端令牌用于自动化
</code></pre>

<p class="wp-block-paragraph">移动端装官方 App，登录自建地址即可随时离线读；或用支持 Fever API 的阅读器（如 Fiery Feeds）聚合。</p>

<h2 class="wp-block-heading">九、从 Omnivore 迁移的具体步骤</h2>

<p class="wp-block-paragraph">若你存有 Omnivore 导出文件：</p>

<pre><code class="language-bash"># 1. Omnivore 导出得到 JSON（含文章+高亮）
# 2. 用社区脚本转换为 Wallabag 导入格式
python omnivore_to_wallabag.py export.json --token $WALLABAG_TOKEN
# 3. 导入后核对标签与高亮数量
</code></pre>

<p class="wp-block-paragraph">Karakeep 也提供 Omnivore 导入源，迁移时二选一即可。</p>

<h2 class="wp-block-heading">十、和 NAS / 知识库联动</h2>

<p class="wp-block-paragraph">把 Wallabag 数据落到 NAS 上，实现&#8221;自托管 + 自动备份&#8221;双保险：</p>

<pre><code class="language-yaml">联动:
  Wallabag 容器数据卷 → 放在 NAS 挂载目录
  NAS 每日快照 → 防误删
  重要文章定期导出 EPUB → 存 NAS 档案（见第8篇）
  Wallabag API 拉取精读文章 → 汇入 Obsidian（见第1、2篇）
</code></pre>

<p class="wp-block-paragraph">这样阅读资产同时拥有&#8221;在线可读&#8221;和&#8221;永久离线归档&#8221;两层保障。</p>

<h2 class="wp-block-heading">十一、阅读纪律：别让归档变新焦虑</h2>

<ul class="wp-block-list">
<li>设&#8221;待读上限&#8221;（如 50 篇），超了先清再存。</li>
<li>每月挑 5 篇真正精读，其余归档或删。</li>
<li>高亮要写一句自己的话，否则等于没读。</li>
<li>用 Wallabag 的&#8221;随机文章&#8221;功能重读旧藏，让归档活起来。</li>
</ul>

<h2 class="wp-block-heading">十二、阅读资产的&#8221;主权意识&#8221;</h2>

<p class="wp-block-paragraph">我们习惯把书签、稍后读、高亮交给各种免费服务，潜意识里认为&#8221;它们会一直在&#8221;。Omnivore 的停服打破了这个幻觉：免费往往意味着你不是客户，而是被打包的资产。当商业模式不成立，服务随时可能关门，而你的阅读积累随之面临导出窗口期。</p>

<p class="wp-block-paragraph">建立阅读主权，不等于拒绝所有服务，而是遵循一条原则：<strong>核心资产必须可导出、可自托管、可长期保存</strong>。Wallabag 这类<a href="https://waynetalk.com/best-open-source-software-2026/">开源工具</a>让你把数据落在自己硬盘；即便将来它也不再维护，纯文本与标准导出格式也能让你无痛迁移。这种&#8221;随时能走&#8221;的能力，才是数字时代最稳的安全感。</p>

<h2 class="wp-block-heading">十三、三步建立你的阅读主权</h2>

<ol class="wp-block-list">
<li><strong>立即导出</strong>：检查你正在用的稍后读/书签工具，把数据导出来存一份到本地。</li>
<li><strong>自建一处分发</strong>：用 Wallabag 或 Karakeep 起一个属于你的实例。</li>
<li><strong>养成归档习惯</strong>：精读后必写一句自己的话，重要文章导出 EPUB 存 NAS。</li>
</ol>

<h2 class="wp-block-heading">总结</h2>

<p class="wp-block-paragraph">Omnivore 的退场不是悲剧，而是提醒：阅读资产值得被自己拥有。用 Wallabag 自托管稍后读与离线归档，配合 Karakeep/Readeck 按需求补充，你的&#8221;第二图书馆&#8221;就能跨越任何一家公司的生命周期。今天就用 Docker 拉起第一个 Wallabag 实例，把下一篇想读的文章存进去——这一次，它真正属于你。</p>

<h2 class="wp-block-heading">常见问题 FAQ</h2>

<p class="wp-block-paragraph"><strong>Q1：Wallabag 和 Karakeep 到底选哪个？</strong><br />
只想安静读书+永久归档，选 <strong>Wallabag</strong>；如果你的需求溢出到&#8221;书签、图片、PDF、RSS 自动收藏、AI 标签&#8221;，选 <strong>Karakeep</strong>。两者都能自托管，也可并存。</p>

<p class="wp-block-paragraph"><strong>Q2：不会 Docker / 没有服务器能自托管吗？</strong><br />
可以先用 Wallabag 的官方托管账号（免费档有限）体验；长期建议用任意一台旧电脑、树莓派或 NAS（群晖有套件/Container Manager）跑 Docker，门槛比想象低。</p>

<p class="wp-block-paragraph"><strong>Q3：Readeck 和 Wallabag 比有什么不同？</strong><br />
Readeck 更&#8221;极简主义&#8221;：专注把网页变成干净、单文件、可永久保存的阅读副本，界面与配置更轻；Wallabag 功能更全（标注、多端 App、Fever API 等）。喜欢少而精选 Readeck，要功能全选 Wallabag。</p>

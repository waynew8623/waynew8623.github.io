<h2 class="wp-block-heading">架构</h2>

<pre><code>Schedule（每日 09:00）
   │
   ├─ HTTP Request 抓取价格页（带限速/UA）
   ├─ HTML 提取（Extract from HTML / 正则）
   ├─ 与昨日价格比对
   ├─ 变动 → 写 Google Sheets + <a href="https://waynetalk.com/524/">飞书告警</a>
   └─ 生成看板数据
</code></pre>

<h2 class="wp-block-heading">第一步：定时触发</h2>

<p class="wp-block-paragraph"><strong>Schedule Trigger</strong>：<code>Cron</code> 表达式每天 9 点：</p>

<pre><code>0 9 * * *
</code></pre>

<p class="wp-block-paragraph">避开对方高峰，降低压力。</p>

<h2 class="wp-block-heading">第二步：抓取公开价格页</h2>

<p class="wp-block-paragraph"><strong>HTTP Request</strong> 节点：</p>

<ul class="wp-block-list">
<li>Method：<code>GET</code></li>
<li>URL：竞品价格页（如 <code>https://competitor.com/pricing</code>）</li>
<li>Headers：<code>User-Agent: Mozilla/5.0 (兼容浏览器 UA)</code></li>
<li>选项：开启 <code>Retry On Fail</code>，设置超时与 <code>n8n</code> 默认限速</li>
</ul>

<pre><code class="language-javascript">// 若需多页，用 Code 节点生成 URL 列表
return [
  { json: { url: 'https://a.com/pricing' } },
  { json: { url: 'https://b.com/plans' } }
];
</code></pre>

<h2 class="wp-block-heading">第三步：提取价格字段</h2>

<p class="wp-block-paragraph">优先用 <strong>Extract from HTML</strong> 节点（基于 CSS 选择器），比正则稳：</p>

<ul class="wp-block-list">
<li>选择器示例：<code>.plan-price</code>（价格）、<code>h2.plan-name</code>（套餐名）</li>
<li>也可 Pair 模式：提取「名称—价格」配对</li>
</ul>

<p class="wp-block-paragraph">若页面结构简单，正则兜底：</p>

<pre><code class="language-regex">¥\s?([\d,]+(?:\.\d{2})?)     // 匹配 ¥199.00
\<span class="katex math inline">?\s?([\d,]+(?:\.\d{2})?)   // 匹配</span>199.00
</code></pre>

<p class="wp-block-paragraph">用 <strong>Code</strong> 节点整理为标准结构：</p>

<pre><code class="language-javascript">const html = $json.data;
// 示意：用正则抽取套餐与价格
const re = /<h3>(.*?)<\/h3>[\s\S]*?¥([\d.]+)/g;
const rows = [];
let m;
while ((m = re.exec(html)) !== null) {
  rows.push({ plan: m[1], price: parseFloat(m[2]) });
}
return rows.map(r => ({ json: r }));
</code></pre>

<h2 class="wp-block-heading">第四步：与历史价格比对</h2>

<p class="wp-block-paragraph">把今日结果和「昨日快照」（<a href="https://waynetalk.com/527/">存 Google Sheets</a> / DB）比对：</p>

<pre><code class="language-javascript">const today = <span class="katex math inline">json;            // 今日抓取
const last =</span>items('昨日快照').find(x => x.plan === today.plan)?.price;
const diff = today.price - (last ?? today.price);
const pct = last ? (diff / last * 100).toFixed(1) : '0';
return [{
  json: {
    ...today,
    lastPrice: last,
    change: diff,
    changePct: pct + '%',
    flag: diff > 0 ? '涨' : diff < 0 ? '降' : '平'
  }
}];
</code></pre>

<h2 class="wp-block-heading">第六步：变动告警</h2>

<p class="wp-block-paragraph">用 <strong>IF</strong> 节点判断：<code>|changePct| >= 5</code>（阈值可调）。命中则：</p>

<ul class="wp-block-list">
<li>飞书/企业微信推送：「竞品 A 的 Pro 套餐降价 8%，现 ¥xxx」</li>
<li>邮件抄送定价负责人</li>
</ul>

</code></pre>

<h2 class="wp-block-heading">第七步：限速与容错</h2>

<ul class="wp-block-list">
<li><strong>限速</strong>：Schedule 设每日 1–2 次；多目标用 <strong>Split + 间隔停顿</strong>（Wait 节点 sleep 数秒）。</li>
<li><strong>容错</strong>：抓取失败重试；连续失败 3 次告警「监控异常」，避免静默失效。</li>
<li><strong>结构漂移</strong>：竞品改版会导致选择器失效，用 <strong>IF</strong> 检测「抽取到 0 条」并告警「解析规则需更新」。</li>
</ul>

<h2 class="wp-block-heading">FAQ</h2>

<p class="wp-block-paragraph"><strong>Q1：对方页面改版导致抓不到怎么办？</strong><br />
在第三步加「抽取条数为 0 即告警」的检测，第一时间提醒你更新选择器/正则。建议把解析规则集中成可配置项，便于快速改。</p>

<p class="wp-block-paragraph"><strong>Q2：会不会被封 IP？</strong><br />
会，如果频率过高或违反 robots。遵守 robots、设每日低频、带正常 UA、加请求间隔，可大幅降低风险；必要时用代理池（注意合规）。</p>

<p class="wp-block-paragraph"><strong>Q3：有官方 API 还需要爬吗？</strong><br />
不需要，且不应爬。优先用官方 API/价格订阅，更稳定也更合规；本文方案仅作为「无 API 时的公开页面监控」补充。</p>

<h2>二、逐款详解</h2>
<h3>1. 向日葵：免费额度最慷慨的&#8221;六边形选手&#8221;</h3>
<p>向日葵（贝锐出品）是国内个人用户口碑最好的远控软件，核心优势只有一个字：<strong>稳</strong>。个人免费版<strong>不限总时长、不限连接次数</strong>，没有月度额度天花板，连续一周每天远程办公 4~6 小时也不会弹提醒。对&#8221;远程控制免费&#8221;需求来说，这是 2026 年唯一不掐着你用时间的商业远控软件。</p>
<p>功能上免费版覆盖远程控制、文件传输、屏幕录制、多设备管理，单个账号可绑定数百台设备；短板是免费画质锁 1080P，文件传输限速约 300KB/s（传大文件会慢）。独门绝技是远程开机：配套开机棒/开机插座（约 30~60 元），电脑完全断电也能远程通电开机，这一点同行几乎没有对手。安全性上有等保三级、ISO27001 认证，适合对合规有要求的人。</p>
<p><strong>一句话</strong>：把远控当日常办公工具、需要长期挂机的个人用户，首选向日葵。</p>
<h3>2. ToDesk：画质天花板最高，但免费额度是最大限制</h3>
<p>ToDesk 的强项是技术和画质：自研 ZeroSync 引擎，点对点直连下延迟可低至 1~3ms；付费版支持 2K 144 帧 / 4K 60 帧乃至 8K，是设计师和游戏玩家看重的画质上限。文件传输速度也不错，千兆环境下 1GB 文件约 2 分钟。</p>
<p>但 2026 年 2 月起，免费版每月远控时长从 120 小时下调到 <strong>80 小时</strong>，连接次数从 300 次降到 <strong>200 次</strong>（平均每天只能用约 2.6 小时）。超限后当月不能再发起新连接，只能等下月重置或付费。临时用、高频低画质场景它很能打；一旦变成重度用户，额度就是天花板。</p>
<p><strong>一句话</strong>：轻度使用、追求高画质低延迟、能接受每月额度的用户适合 ToDesk；高频用户建议掂量额度再用。</p>
<h3>3. RustDesk：开源免费、数据自主，极客的终极解</h3>
<p>RustDesk 是开源界的 TeamViewer 平替：<strong>完全开源、完全免费、无额度限制</strong>，客户端覆盖全平台。它最核心的价值是<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/756/">支持自建服务器</a>：官方提供 <code>hbbs</code>（ID 服务器）和 <code>hbbr</code>（中继服务器）两个服务端程序，一台 VPS 跑 Docker 就能搭建属于自己的远控中转站，数据不经过任何第三方，隐私彻底自主。</p>
<p>代价有两点：一是公共中继节点不稳定，必须自建才好用；二是需要一点动手能力（装 Docker、放行端口、填客户端配置）。如果你恰好有一台<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/542/">永久免费的云服务器</a>（比如 Oracle Cloud 免费层），RustDesk 的自建成本就是零。具体搭建步骤见第四节。</p>
<p>RustDesk 在本质上更偏向<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/549/">开源免费软件生态</a>的一员——无广告、无订阅、无暗坑。对技术人员来说，这是长期最安心的选择。</p>
<p><strong>一句话</strong>：有 VPS、爱折腾、重视数据主权的用户，直接选 RustDesk 自建。</p>
<h3>4. AnyDesk：轻量应急神器，但别当主力</h3>
<p>AnyDesk 的安装包只有几 MB，免安装版打开就能用，弱网环境下也能连上，适合&#8221;帮别人临时修电脑&#8221;这类救场场景。免费版仅限个人非商业用途。</p>
<p>它的最大坑是<strong>商业检测机制</strong>：频繁使用容易被误判为商业用途，连接几分钟就被掐断，需要申诉解封。免费版功能也偏基础（地址簿、自定义别名等受限）。把它当应急替补很好，但不适合作为每天用的主力工具。</p>
<h3>5. Chrome 远程桌面：零门槛的极简方案</h3>
<p>Google 出品，完全免费、无时长限制、不装客户端（浏览器+谷歌账号即可）。缺点是功能极其基础：不支持原生文件传输（新版本支持简单上下传），没有远程开机，画质和帧率也只是&#8221;能用&#8221;。而且它依赖谷歌服务，国内网络环境下可达性是个问题。</p>
<p>适合场景：手边只有浏览器、临时连一下自己电脑、海外用户快速访问。</p>
<h3>6. UU远程：新锐搅局者，免费给 4K/144Hz</h3>
<p>网易出品的 UU远程目前处于抢市场阶段，免费版直接开放 <strong>4K 分辨率、144Hz 刷新率、自定义码率</strong>，文件传输不限大小、支持断点续传，背靠网易游戏加速的底层技术，千兆环境实测延迟约 10ms。缺点是生态和企业级管理功能还不成熟，且存在未来商业化的不确定性。适合当第二工具尝鲜，不建议押宝全部设备。</p>
<h3>7. 备选：微软远程桌面（局域网神器）</h3>
<p>局域网内它延迟最低、体验最原生、完全免费；跨公网需 VPN / 端口映射。只在同一局域网连电脑的话，先用它，别装别的。</p>
<h2>三、RustDesk 自建服务器简易指南</h2>
<p>这是 RustDesk 的正确打开方式：用 Docker 一键部署 <code>hbbs</code> + <code>hbbr</code>。</p>
<p><strong>准备工作</strong>：一台有公网 IP 的 VPS（1 核 1G 就够），Docker 环境。服务端需放行端口：<strong>TCP 21115~21119</strong>、<strong>UDP 21116</strong>（务必在云厂商安全组放行，否则客户端一直&#8221;无法连接&#8221;）。</p>
<pre><code class="language-yaml line-numbers"># docker-compose.yml
services:
  hbbs:
    container_name: hbbs
    image: rustdesk/rustdesk-server:latest
    command: hbbs -k _
    volumes:
      - ./data:/root
    network_mode: "host"
    restart: unless-stopped
  hbbr:
    container_name: hbbr
    image: rustdesk/rustdesk-server:latest
    command: hbbr -k _
    volumes:
      - ./data:/root
    network_mode: "host"
    restart: unless-stopped
</code></pre>
<p>部署成功后看 hbbs 的日志，里面有一行 <code>Key: xxxx</code>——这就是客户端要填的公钥：</p>
<pre><code class="language-bash line-numbers">docker compose up -d
docker logs hbbs | grep "Key:"
</code></pre>
<p><strong>客户端配置</strong>（被控端和控制端都要做）：打开 RustDesk → 设置 → 网络 → <strong>解锁网络设置</strong> → 填写：</p>
<table>
<thead>
<tr>
<th>项目</th>
<th>填写内容</th>
</tr>
</thead>
<tbody>
<tr>
<td>ID 服务器</td>
<td>你的 VPS 公网 IP 或域名（默认端口 21116，可省略）</td>
</tr>
<tr>
<td>中继服务器</td>
<td>同上（可留空，默认自动）</td>
</tr>
<tr>
<td>Key</td>
<td>刚才日志里的公钥内容</td>
</tr>
</tbody>
</table>
<p>填好点确定，界面下方出现绿色 <strong>&#8220;就绪&#8221;</strong> 就说明连上了自建服务器。之后两台设备互相输入对方 ID 即可连接，流量走你自己的中继，无额度、无上限。</p>
<p>几个避坑点：<br />
1. <strong>防火墙</strong>：90% 的自建失败都是安全组没放行 UDP 21116，检查两遍。<br />
2. <strong>密钥备份</strong>：<code>./data</code> 目录下的 <code>id_ed25519</code> 是私钥，丢了所有客户端都要重配，备份好。<br />
3. <strong>网络模式</strong>：官方建议 Linux 用 <code>host</code> 模式，否则 P2P 直连失效、所有流量被迫走中继。</p>
<p>更多 Docker 自托管玩法的朋友，可以参考本站的<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/756/"> Docker 自托管项目盘点</a>；而如果想绕开公网 IP 用别的思路，<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/547/">Cloudflare Tunnel / Tailscale / ZeroTier 无公网 IP 远程访问方案</a>也值得一看。</p>
<h2>四、按场景推荐</h2>
<h3>个人临时使用：偶尔连一次</h3>
<p>ToDesk 或 AnyDesk 都行，免注册开箱即用；只是要记住 ToDesk 免费版每月有 80 小时额度，偶尔用根本用不完。</p>
<h3>日常远程办公：每天都要用</h3>
<p><strong>向日葵</strong>是省心之选：免费不限时长，挂机办公一整天无压力，还能多设备管理。如果想零成本且不担心技术维护，RustDesk 自建也可以。</p>
<h3>无人值守 / 长期挂机：下载机、看店、值班</h3>
<p>看三个指标：免费额度、远程开机、断线率。向日葵免费不限时长 + 开机硬件方案（开机插座约 20~60 元）+ 长时挂机不断线，是这个场景的最优解；ToDesk 的每月 80 小时额度在这里直接出局。</p>
<h3>技术玩家 / 隐私敏感：数据不想过第三方</h3>
<p><strong>RustDesk 自建</strong>，无需多言。一台免费 VPS + 十分钟配置，换来自主可控的永久远控能力。</p>
<h3>远程游戏 / 高画质串流</h3>
<p>优先看延迟和帧率：ToDesk（付费版 4K 高刷）、UU远程（免费 4K/144Hz）、RustDesk 自建（配置得当可媲美 Parsec）。这个场景对网络要求极高，先确保你的上下行带宽达标。</p>
<h2>五、安全提醒（必读）</h2>
<p>远程桌面软件直接暴露的是你整台电脑，安全问题比&#8221;哪个免费额度大&#8221;重要得多：</p>
<ul>
<li><strong>只从官网下载</strong>：远控软件是诈骗团伙的重灾区，搜索引擎里的&#8221;高速下载站&#8221;多半是捆绑木马。永远从官方渠道获取安装包。</li>
<li><strong>强密码 + 双重验证</strong>：无人值守访问务必设置高强度独立密码（12 位以上，字母数字符号混合），能开双重验证就开。别用 123456 这种&#8221;图方便&#8221;的密码。</li>
<li><strong>陌生的连接请求一律拒绝</strong>：任何自称&#8221;客服&#8221;&#8221;技术支持&#8221;让你下载远控软件并报出 ID 的都是诈骗。</li>
<li><strong>不用时收好被控端</strong>：长期开机的电脑建议设置连接白名单或定时关机，减少暴露面。</li>
<li><strong>RustDesk 自建注意加固</strong>：务必开启 <code>-k _</code> 密钥验证，否则公网 ID 服务器会被陌生客户端注册；定期更新服务端版本。</li>
</ul>
<h2>六、FAQ</h2>
<p><strong>Q1：哪个免费远程桌面软件最好用？</strong><br />
A：没有唯一答案。日常办公主力选向日葵（免费不限时长）；轻度偶尔用选 ToDesk（额度内画质最好）；技术玩家选 RustDesk 自建（永久免费、数据自主）。按本文对比表对号入座即可。</p>
<p><strong>Q2：ToDesk 免费版到底能用多久？</strong><br />
A：按 2026 年 2 月起的政策，每月 80 小时远控时长 + 200 次连接。平均每天约 2.6 小时。超限后当月无法发起新连接，需等待次月重置或开通会员。</p>
<p><strong>Q3：RustDesk 自建难吗？要花钱吗？</strong><br />
A：不难，会装 Docker 的话十分钟搞定（教程见第四节）。服务器是唯一成本——<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/542/">永久免费的云服务器</a>（如 Oracle Cloud 免费层）足够跑，基本零成本。</p>
<p><strong>Q4：RustDesk 和 ToDesk 哪个好？</strong><br />
A：出发点不同。ToDesk 是开箱即用的商业软件，画质和易用性占优，但免费有额度天花板；RustDesk 开源免费无限制，但需要自建服务器才稳定。简单说：不想折腾选 ToDesk（轻度），愿意折腾选 RustDesk（长期）。</p>
<p><strong>Q5：向日葵免费版文件传输慢怎么办？</strong><br />
A：免费版限速约 300KB/s，传小文件没问题，大文件确实慢。可以改用局域网共享、NAS 或网盘中转；或者在高频传输的场景叠一个 ToDesk/RustDesk 分担。</p>
<p><strong>Q6：TeamViewer 为什么不推荐了？</strong><br />
A：国内个人用户体验打折明显：免费版最多绑定 3 台设备、商业用途检测极敏感（远控自家电脑都可能被误判），同一时间只能传输一个文件。跨国办公它依然是好选择，国内个人场景不建议。</p>
<p><strong>Q7：远程控制安全吗？会被黑客看吗？</strong><br />
A：正规远控软件都用端到端加密（AES-256 等），传输过程相对安全。风险主要在人这一侧：弱密码、诈骗诱导安装、从不明渠道下载。按第五节的安全清单做一遍，基本无忧。</p>
<p><strong>Q8：手机远程控制电脑，用哪个 App 体验最好？</strong><br />
A：向日葵和 ToDesk 的手机 App 都很成熟，支持手势操作；RustDesk 移动端也能用。看店/看监控这类&#8221;只看画面&#8221;的场景，用手机看完全没问题。</p>

<p>Microsoft Store（微软商店）是 <a href="https://waynetalk.com/925/">Windows 11</a> 系统中不可或缺的核心组件，它为我们提供了海量、安全、可靠的应用程序、游戏、电影和主题。然而，在某些情况下，例如系统精简、更新错误或意外卸载后，你可能会发现微软商店从你的电脑上“消失”了。</p>
<p>这篇教程将为你提供一个清晰、可靠的解决方案。作为一名长期和 Windows 系统打交道的博主，我将分享一个经过亲身验证行之有效的方法——通过 PowerShell 手动安装，帮助你快速找回并恢复功能完备的微软商店。</p>
<h3 id="wei-shi-me-wo-de-wei-ruan-shang-dian-hui-bu-jian-liao" tabindex="-1">为什么我的微软商店会不见了？</h3>
<p>在开始修复之前，了解问题根源有助于我们更好地理解。常见原因包括：</p>
<ul>
<li><strong>系统精简或定制：</strong> 使用了一些第三方精简工具或安装了“Debloated”版本的 Windows 11，这些版本为了追求性能可能会移除包括商店在内的内置应用。</li>
<li><strong>系统文件损坏：</strong> <a href="https://waynetalk.com/922/">系统更新失败</a>或核心组件损坏可能导致微软商店无法正常工作或直接消失。</li>
<li><strong>用户误操作：</strong> 通过某些高级命令意外地卸载了应用商店。</li>
<li><strong>企业策略限制：</strong> 在受组织管理的设备上，系统管理员可能通过策略禁用了微软商店。</li>
</ul>
<p>无论原因如何，下面的方法都能帮你解决问题。</p>
<h2 id="tong-guo-powershell-shou-dong-an-zhuang-microsoft-store" tabindex="-1">通过 PowerShell 手动安装 Microsoft Store</h2>
<p>这个方法的核心是获取官方的安装包，然后利用 Windows 自带的强大工具 PowerShell 来执行安装。请严格按照以下步骤操作。</p>
<h3 id="di-yi-bu-huo-qu-microsoft-store-an-zhuang-bao" tabindex="-1">第一步：获取 Microsoft Store 安装包</h3>
<p>首先，我们需要从微软的服务器上获取最新的商店安装包。虽然我们可以直接访问商店的网页链接，但要下载安装文件，我们需要借助一个广受好评的第三方工具。</p>
<ol>
<li><strong>微软商店官方链接：</strong> 这是商店应用的官方地址，我们主要用它来获取产品ID。<br />
<blockquote><p><code>https://www.microsoft.com/store/productId/9WZDNCRFJBMP</code></p></blockquote>
</li>
<li><strong>访问下载工具网站：</strong> 打开 <strong><a href="https://store.rg-adguard.net/" target="_blank" rel="noopener">store.rg-adguard.net</a></strong>。这个网站是一个在线链接生成器，它可以直接从微软官方服务器解析出应用安装包的下载地址，非常安全可靠。</li>
<li><strong>生成下载链接：</strong> 将上面的商店链接粘贴到网站的搜索框中，确保右侧的下拉菜单选择 <strong>“Retail”</strong>，然后点击对勾（✔️）按钮进行搜索。
<p class="fancybox-wrapper lazyload-container-unload" align="center" data-fancybox="post-images"><img decoding="async" src="https://img.waynetalk.com/file/1761112395495_5958654469bd48109fd68e31be8abf69.png" alt="在 rg-adguard 网站上输入微软商店链接以下载安装包" /></p>
</li>
<li><strong>下载正确的安装文件：</strong> 页面会列出所有相关的文件。向下滑动页面，找到一个文件名类似 <code>Microsoft.WindowsStore_..._..._~_8wekyb3d8bbwe.Msixbundle</code> 的文件。
<ul>
<li><strong>关键点：</strong> 请务必选择后缀名为 <strong><code>.msixbundle</code></strong> 的文件。这是 Windows 现代应用程序的捆绑包格式。选择一个最新的版本号（数字越大通常越新）进行下载。</li>
</ul>
<p class="fancybox-wrapper lazyload-container-unload" align="center" data-fancybox="post-images"><img decoding="async" src="https://img.waynetalk.com/file/1761112392701_76b33be1f635446297a27e2a906137c2.png" alt="从搜索结果列表中找到并准备下载 Microsoft.WindowsStore 的 .msixbundle 文件" /></p>
<p>将文件下载到你容易找到的位置，例如，本教程中我将它保存在了 <code>E:</code> 盘的根目录。</p>
<p class="fancybox-wrapper lazyload-container-unload" align="center" data-fancybox="post-images"><img decoding="async" src="https://img.waynetalk.com/file/1761112402210_b6811ad2509a4719b10575f1ef68b3e5.png" alt="Windows 11 文件资源管理器中显示已下载的微软商店 Msixbundle 安装包" /></p>
</li>
</ol>
<h3 id="di-er-bu-yi-guan-li-yuan-shen-fen-yun-xing-powershell" tabindex="-1">第二步：以管理员身份运行 PowerShell</h3>
<p>安装应用需要管理员权限，因此我们需要打开一个提升了权限的 PowerShell 窗口。</p>
<ol>
<li>按下键盘上的 <code>Win + X</code> 快捷键，或者右键点击“开始”按钮。</li>
<li>在弹出的菜单中，选择 <strong>“Windows PowerShell (管理员)”</strong> 或 <strong>“终端 (管理员)”</strong>。
<p class="fancybox-wrapper lazyload-container-unload" align="center" data-fancybox="post-images"><img decoding="async" src="https://img.waynetalk.com/file/1761112408151_37d5979db69a4acd803b9fa07c3db29b.png" alt="通过 Win+X 快捷菜单打开 Windows PowerShell (管理员) 选项" /></p>
</li>
<li>在用户账户控制 (UAC) 弹窗中点击“是”。
<p class="fancybox-wrapper lazyload-container-unload" align="center" data-fancybox="post-images"><img decoding="async" src="https://img.waynetalk.com/file/1761112408580_dba189e2e58c4414a90cde50ec86a069.png" alt="以管理员身份运行的 Windows PowerShell 窗口界面" /></p>
</li>
</ol>
<h3 id="di-san-bu-zhi-xing-an-zhuang-ming-ling" tabindex="-1">第三步：执行安装命令</h3>
<p>现在，我们要在 PowerShell 中执行命令来安装刚刚下载的文件。</p>
<ol>
<li><strong>切换到文件目录：</strong> 首先，需要将 PowerShell 的当前路径切换到你保存 <code>.msixbundle</code> 文件的位置。例如，我将文件保存在 <code>E:</code> 盘，命令如下：
<pre><code class="language-powershell hljs"><span class="hljs-built_in">cd</span> E:
</code></pre>
<p>输入后按回车。如果你的文件在其他路径，例如 <code>D:\Downloads</code>，则输入 <code>cd D:\Downloads</code>。</p>
<p class="fancybox-wrapper lazyload-container-unload" align="center" data-fancybox="post-images"><img decoding="async" src="https://img.waynetalk.com/file/1761112413884_0d5d4b9ad22748c1a2a46d28ac36f3d3.png" alt="在 PowerShell 中使用 cd 命令切换到 E 盘根目录" /></p>
</li>
<li><strong>执行安装命令：</strong> 输入 <code>add-appxpackage</code> 命令，后面跟上你下载的完整文件名。
<ul>
<li><strong>专业提示：</strong> 你可以输入 <code>add-appxpackage Microsoft.W</code> 然后按下 <code>Tab</code> 键，系统会自动补全文件名，这样可以避免手动输入错误。</li>
</ul>
<p>命令格式如下：</p>
<pre><code class="language-powershell hljs"><span class="hljs-built_in">add-appxpackage</span> <你的文件名.Msixbundle>
</code></pre>
<p>根据我下载的文件，完整的命令是：</p>
<pre><code class="language-powershell hljs"><span class="hljs-built_in">add-appxpackage</span> Microsoft.WindowsStore_22406.<span class="hljs-number">1401.6</span>.<span class="hljs-number">0</span>_neutral_~_8wekyb3d8bbwe.Msixbundle
</code></pre>
<p class="fancybox-wrapper lazyload-container-unload" align="center" data-fancybox="post-images"><img decoding="async" src="https://img.waynetalk.com/file/1761112413871_dd28b10e9dfd43f4b21b370f53fddb60.png" alt="在 PowerShell 中输入 add-appxpackage 命令准备安装微软商店" /></p>
</li>
<li><strong>完成安装：</strong> 按下回车键执行命令。如果一切顺利，光标会移动到下一行，不会有任何成功或失败的提示。<strong>没有消息就是最好的消息！</strong> 这代表微软商店已经成功安装到你的系统中了。
<ul>
<li><strong>权威参考：</strong> <code>Add-AppxPackage</code> 是一个强大的 cmdlet，用于在 Windows 中添加已签名的应用包。你可以查阅 <a href="https://learn.microsoft.com/en-us/powershell/module/appx/add-appxpackage" target="_blank" rel="noopener">Microsoft Docs 上的 Add-AppxPackage 官方文档</a> 以了解更多技术细节。</li>
</ul>
</li>
</ol>
<h3 id="di-si-bu-yan-zheng-an-zhuang-bing-shi-yong" tabindex="-1">第四步：验证安装并使用</h3>
<p>现在，你可以点击“开始”按钮或按 <code>Win</code> 键，在应用列表中你应该能重新看到 “Microsoft Store” 的图标了。</p>
<p class="fancybox-wrapper lazyload-container-unload" align="center" data-fancybox="post-images">
<p>打开它，熟悉的界面又回来了！你可以登录你的微软账户，开始下载和更新应用。</p>
<p class="fancybox-wrapper lazyload-container-unload" align="center" data-fancybox="post-images"><img decoding="async" src="https://img.waynetalk.com/file/1761112418730_9d075f343332484ea13a67d40ea95cd7.png" alt="成功打开并正常运行的 Windows 11 微软商店主界面" /></p>
<p><strong>个人经验分享：</strong> 我在测试时发现，如果开启了 <a href="https://waynetalk.com/702/">VPN 或网络代理</a>，可能会导致商店加载缓慢或出现网络错误。建议在访问微软商店时使用本地的正常网络环境，以获得最佳体验。</p>
<h2 id="chang-jian-wen-ti-yu-jie-jue-fang-an-faq" tabindex="-1">常见问题与解决方案 (FAQ)</h2>
<p><strong>Q1: <code>add-appxpackage</code> 命令执行后出现红色错误提示怎么办？</strong><br />
A: 红色错误通常表示安装失败。请检查：</p>
<ul>
<li><strong>权限问题：</strong> 确保 PowerShell 是以“管理员身份”运行的。</li>
<li><strong>文件名错误：</strong> 仔细核对你的文件名是否与下载的完全一致，包括版本号和扩展名。建议使用 <code>Tab</code> 键自动补全。</li>
<li><strong>依赖项缺失：</strong> 某些情况下可能缺少必要的依赖框架（如 VCLibs）。你可以按照同样的方法在 <code>rg-adguard.net</code> 网站上搜索并安装 <code>Microsoft.VCLibs</code> 相关的 .appx 文件。</li>
</ul>
<p><strong>Q2: 除了这个方法，还有其他恢复商店的方式吗？</strong><br />
A: 是的。对于一些非严重损坏的情况，你可以尝试：</p>
<ul>
<li><strong>运行 <code>wsreset.exe</code>：</strong> 在运行框 (<code>Win + R</code>) 中输入 <code>wsreset.exe</code> 并回车，这个命令可以清空商店缓存并重置它。</li>
<li><strong>Windows 设置：</strong> 进入 <code>设置</code> > <code>应用</code> > <code>安装的应用</code>，找到 Microsoft Store，点击“高级选项”，尝试“修复”或“重置”功能。</li>
<li><strong>Winget 命令：</strong> 在 PowerShell (管理员) 中尝试运行 <code>winget install "Microsoft Store"</code>，这是 Windows 包管理器，有时也能直接修复。</li>
</ul>
<h2 id="zong-jie" tabindex="-1">总结</h2>
<p>丢失 Microsoft Store 无疑会影响 Windows 11 的完整体验。幸运的是，通过 PowerShell 手动重装是一个强大且可靠的解决方案。本教程详细介绍了从下载官方安装包到执行命令的每一个步骤，希望能帮助你轻松解决这个令人头疼的问题。</p>

<h2 class="wp-block-heading">二、最小可用：先让启动器接管日常</h2>

<p class="wp-block-paragraph">不管 Raycast 还是 Alfred，第一步都是绑定一个全局快捷键（如 <code>Option+Space</code>），然后：</p>

<pre><code class="language-text">基础命令（无需写代码即可用）:
  - 打开应用（输入前几个字母回车）
  - 文件搜索（find 文件名）
  - 剪贴板历史（粘贴刚才复制的任意一条）
  - 窗口管理（half/center 分屏）
  - 计算器、单位换算、查汇率
  - 快捷片段（snippet）一键输入常用话术
</code></pre>

<p class="wp-block-paragraph">光这几项，就能砍掉大量鼠标操作。</p>

<h2 class="wp-block-heading">三、进阶：用脚本扩展定制专属命令</h2>

<p class="wp-block-paragraph">当现成功能不够，就用脚本扩展。Raycast 支持 <strong>Script Commands</strong>（单文件脚本）和 <strong>Extensions</strong>（完整扩展）。</p>

<h3 class="wp-block-heading">3.1 一个 Bash 脚本命令：一键查公网 IP</h3>

<p class="wp-block-paragraph">在 Raycast 里新建 Script Command，选 Bash：</p>

<pre><code class="language-bash">#!/bin/bash
# @raycast.title 我的公网 IP
# @raycast.mode inline
# @raycast.packageName 网络工具

curl -s https://api.ipify.org
</code></pre>

<p class="wp-block-paragraph">保存后，唤起 Raycast 输入&#8221;我的公网 IP&#8221;即可看到结果，回车复制到剪贴板。</p>

<h3 class="wp-block-heading">3.2 TypeScript 扩展：调用本地 API</h3>

<p class="wp-block-paragraph">Raycast 官方偏好 TypeScript。一个简单的&#8221;翻译并复制&#8221;扩展核心：</p>

<pre><code class="language-typescript">import { getSelectedText, Clipboard } from "@raycast/api";
import { execSync } from "child_process";

export default async function () {
  const text = await getSelectedText();
  // 调用本地翻译脚本或 API
  const result = execSync(`trans :zh "${text}"`).toString();
  await Clipboard.copy(result);
  return result;
}
</code></pre>

<pre><code class="language-text">热键(⌥T) → 获取选中文本 → 运行 /usr/bin/trans → 粘贴结果

<h2 class="wp-block-heading">九、Alfred Workflow 进阶：用 Script Filter 做搜索</h2>

<p class="wp-block-paragraph">Alfred 的 Script Filter 能把脚本输出渲染成可选项列表，比如搜索本地文件并回车打开：</p>

<pre><code class="language-bash"># 伪代码：输入关键词 → 返回匹配文件列表（XML/JSON 给 Alfred）
mdfind "<span class="katex math inline">1" | head -10 | while read f; do
  echo "{\"title\":\"</span>f\",\"arg\":\"$f\"}"
done
</code></pre>

<p class="wp-block-paragraph">这比系统搜索快且可定制，是高手常用的&#8221;文件秒开&#8221;方案。</p>

<h2 class="wp-block-heading">十、把键盘流做成&#8221;个人操作系统&#8221;</h2>

<p class="wp-block-paragraph">真正的高手，把启动器当成中枢，所有动作从它出发：</p>

<pre><code class="language-text">全局快捷键唤起
  ├→ 打开/切换应用（1 秒）
  ├→ 执行脚本（翻译/记账/新建笔记）
  ├→ 调用 AI（总结/改写）
  └→ 跳转项目（打开文件夹+笔记+标签组）
</code></pre>

<p class="wp-block-paragraph">建议做法：每周回顾一次&#8221;我今天重复点了哪些鼠标操作&#8221;，把它变成一条 Raycast/Alfred 命令。半年后，你的命令库就是独一无二的&#8221;效率外挂&#8221;。</p>

<h2 class="wp-block-heading">十一、隐私与权限注意</h2>

<ul class="wp-block-list">
<li>macOS 对自动化管控严格，首次运行脚本命令需授予&#8221;辅助功能&#8221;&#8221;完全磁盘访问&#8221;权限。</li>
<li>涉及账号密码的脚本，凭证用环境变量或系统钥匙串，别硬编码进脚本文件。</li>
<li>不要把含敏感逻辑的脚本提交到公开 Git 仓库。</li>
</ul>

<h2 class="wp-block-heading">十二、键盘流背后的心智模型</h2>

<p class="wp-block-paragraph">很多人装了 Raycast 却用回鼠标，根源在于没建立&#8221;命令面板心智&#8221;。真正的高手不是记得更多快捷键，而是养成一个肌肉记忆：任何想做的操作，第一反应是按全局快捷键而不是去点。这个反射需要刻意练习大约两周——前三天你会忘记唤起，一周后开始自然，两周后便回不去。</p>

<p class="wp-block-paragraph">另一个心智转变是&#8221;把操作当成可组合的命令&#8221;。鼠标操作是离散的、不可记录的；键盘流里的每一步都是一条可被脚本化、可重复的命令。当你发现自己在重复某个多步操作，就把它写成一个 Script Command，下次一键完成。你的启动器因此越用越聪明，像一双越练越强的&#8221;外部双手&#8221;。</p>

<p class="wp-block-paragraph">最后，警惕&#8221;为自动化而自动化&#8221;的陷阱。不是所有操作都值得脚本化，判断标准是：这个动作每周出现超过三次、且步骤固定，就值得做成命令；偶发且多变的，保留手动反而更灵活。</p>

<h2 class="wp-block-heading">十三、新手两周上手路线图</h2>

<ul class="wp-block-list">
<li><strong>第 1–3 天</strong>：只做一件事——把全局快捷键按成肌肉记忆，用它完成打开应用、搜索文件、查剪贴板历史三件事。</li>
<li><strong>第 4–7 天</strong>：加三个常用命令（截图 OCR、单位换算、快速笔记），体会&#8221;一想就到&#8221;的爽感。</li>
<li><strong>第 2 周</strong>：写第一个自己的脚本命令（哪怕只是打开某个文件夹），理解参数与模式的写法。</li>
<li><strong>第 3 周起</strong>：每周复盘一个重复鼠标动作，把它变成命令。三个月后你的命令库就是专属效率外挂。</li>
</ul>

<h2 class="wp-block-heading">总结</h2>

<p class="wp-block-paragraph">Raycast / Alfred 的价值，不在于&#8221;少点几下鼠标&#8221;，而在于<strong>把你脑子里的意图直接翻译成动作</strong>。从今天起，装好启动器、绑全局快捷键、写第一个脚本命令，让键盘流成为你生产力的底层操作系统。</p>

<h2 class="wp-block-heading">常见问题 FAQ</h2>

<p class="wp-block-paragraph"><strong>Q1：Windows 用户能用 Raycast 吗？</strong><br />
Raycast 目前仅支持 macOS。Windows 用户可用 <strong>PowerToys Run</strong>（免费、微软官方）做启动器，或用 <strong>Wox</strong>、<strong>Listary</strong> 等实现类似键盘流；若想要 AI 命令面板，可关注 Raycast 官方动态或借助跨平台方案如 <strong>uTools</strong>。</p>

<p class="wp-block-paragraph"><strong>Q2：Raycast 和 Alfred 该选哪个？</strong><br />
追求开箱即用、扩展商店丰富、内置 AI，选 Raycast；已有 Alfred 工作流积累、或不想订阅，选 Alfred + Powerpack。两者核心体验接近，迁移成本低。</p>

<p class="wp-block-paragraph"><strong>Q3：脚本命令报错怎么办？</strong><br />
先确认脚本在终端能独立运行（依赖、权限、PATH 都正常），再检查 Raycast/Alfred 的环境变量是否隔离（它们不一定继承你的 shell 环境，必要时在脚本里写全路径）。</p>

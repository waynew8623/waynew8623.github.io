<p style="margin: 20px 0 !important; line-height: 1.75 !important; color: #242424 !important; font-size: 17px; letter-spacing: -0.003em;">由于Hugging Face会休眠48小时没人访问的space，因此建议使用提供计划任务的平台执行cron计划，周期性访问Hugging Face Space的主页。比如：https://www.cron-job.org/</p>

<p style="margin: 20px 0 !important; line-height: 1.75 !important; color: #242424 !important; font-size: 17px; letter-spacing: -0.003em;">Hugging Face Spaces 使用的是容器快照技术，每次重启都会回到“出厂设置”。</p>

</li>
<li style="margin: 10px 0; line-height: 1.7 !important; color: #242424 !important; font-size: 17px;">

<p style="margin: 20px 0 !important; line-height: 1.75 !important; color: #242424 !important; font-size: 17px; letter-spacing: -0.003em;">我们没有采用传统的数据库或付费存储，而是选择了 Dataset 方案，主要为了解决以下问题：</p>

<li style="margin: 10px 0; line-height: 1.7 !important; color: #242424 !important; font-size: 17px;">

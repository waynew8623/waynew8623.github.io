<p class="wp-block-paragraph"><a href="https://waynetalk.com/519/">家里有台 NAS</a>、树莓派或闲置小主机，想在公司或手机上访问，却发现宽带没有公网 IP，端口映射做不了，DDNS 也没戏？这是绝大多数家庭用户的真实困境。好消息：2026 年有几套<strong>完全免费、无需公网 IP、不开放入站端口</strong>的<a href="https://waynetalk.com/intranet-penetration-guide/">内网穿透方案</a>，让你安全地<a href="https://waynetalk.com/frp-ssl-ddns-raspberry-guide/">远程访问</a>家里的一切。</p>

<p class="wp-block-paragraph">本文对比三套主流免费方案：Cloudflare Tunnel、Tailscale、Zerotier，帮你按场景选对工具。</p>

<h2 class="wp-block-heading">一、先理解&#8221;穿透&#8221;的两种姿势</h2>

<ul class="wp-block-list">
<li><strong>反向隧道（如 Cloudflare Tunnel）</strong>：本地主动向外建连，外部通过服务商域名访问。家里无需开放任何入站端口，最安全。</li>
<li><strong>虚拟组网（如 Tailscale / Zerotier）</strong>：把多台设备拉进一个虚拟局域网（VPN 化），设备间直接互访。适合&#8221;我想像在局域网一样访问多台设备&#8221;。</li>
</ul>

<p class="wp-block-paragraph">选型一句话：<strong>想对外暴露 Web 服务 → Cloudflare Tunnel；想像本地局域网一样访问多台设备 → Tailscale / Zerotier</strong>。</p>

<h2 class="wp-block-heading">三、Cloudflare Tunnel：把家里服务发布到公网</h2>

<p class="wp-block-paragraph">适合场景：你想用 <code>nas.你的域名.com</code> 从任何地方访问家里的 Web 面板、<a href="https://waynetalk.com/805/">博客后台</a>等。</p>

<ol class="wp-block-list">
<li>家里服务器安装 <code>cloudflared</code>：</li>
</ol>

<pre><code class="language-bash"># <a href="https://waynetalk.com/75/">Debian/Ubuntu</a> 示例
wget -q https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb
sudo dpkg -i cloudflared-linux-amd64.deb
</code></pre>

<ol class="wp-block-list" start="2">
<li>登录并创建隧道：</li>
</ol>

<pre><code class="language-bash">cloudflared tunnel login
cloudflared tunnel create home-tunnel
cloudflared tunnel route dns home-tunnel nas.你的域名.com
</code></pre>

<ol class="wp-block-list" start="3">
<li>配置 <code>config.yml</code> 指向本地服务：</li>
</ol>

<pre><code class="language-yaml">tunnel: home-tunnel
credentials-file: /root/.cloudflared/<id>.json
ingress:
  - hostname: nas.你的域名.com
    service: http://192.168.1.100:5000
  - service: http_status:404
</code></pre>

<ol class="wp-block-list" start="4">
<li>以服务方式常驻：</li>
</ol>

<pre><code class="language-bash">cloudflared tunnel run home-tunnel
</code></pre>

<p class="wp-block-paragraph">优势：全程不开放家庭入站端口，Cloudflare 还能叠 WAF、Access 登录保护，安全性高。</p>

<h2 class="wp-block-heading">四、Tailscale：把设备连成一张私网</h2>

<p class="wp-block-paragraph">适合场景：不止一个 Web 服务，你想从手机/笔记本直接 SSH 到家里机器、访问 NAS SMB、甚至打游戏串流。</p>

<ol class="wp-block-list">
<li>各设备登录 Tailscale 账号（支持多平台客户端）。</li>
<li>家里 Linux 机器安装并加入：</li>
</ol>

<pre><code class="language-bash">curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
</code></pre>

<ol class="wp-block-list" start="3">
<li>记下该机器的 Tailscale IP（如 <code>100.x.x.x</code>），即可从任意已加入的设备直接访问：</li>
</ol>

<pre><code class="language-bash">ssh user@100.x.x.x
</code></pre>

<ol class="wp-block-list" start="4">
<li>进阶：在自家路由器/NAS 上启用 <strong>Subnet Router（子网路由）</strong>，让 Tailscale 网内的设备直接访问整个家庭局域网（192.168.x.x）。</li>
</ol>

<p class="wp-block-paragraph">Tailscale 个人免费档覆盖多台设备，基于 WireGuard，延迟低、体验顺滑。</p>

<h2 class="wp-block-heading">五、Zerotier：自建虚拟局域网的经典选择</h2>

<p class="wp-block-paragraph">Zerotier 思路类似：创建虚拟网络（Network），把设备加进来，分配虚拟 IP，设备间直连通信。</p>

<pre><code class="language-bash"># Linux 加入网络
curl -s https://install.zerotier.com | sudo bash
sudo zerotier-cli join <网络ID>
# 然后在管理后台授权该节点
</code></pre>

<p class="wp-block-paragraph">适合喜欢&#8221;一个网络 ID 拉起所有设备&#8221;的玩家。免费层对小节点数足够，超量需付费或自建 Moon/控制器。</p>

<h2 class="wp-block-heading">六、组合用法</h2>

<p class="wp-block-paragraph">实战中三者常组合：</p>

<ul class="wp-block-list">
<li><strong>对外发布</strong>用 Cloudflare Tunnel（博客、面板、公开 API）。</li>
<li><strong>私有访问</strong>用 Tailscale（SSH、NAS、内网管理）。</li>
<li>把 Oracle 免费机（见本博客《Oracle 免费服务器》）作为跳板，Tunnel 出口或 Tailscale 中继都行。</li>
</ul>

<h2 class="wp-block-heading">七、安全与合规提醒</h2>

<ul class="wp-block-list">
<li><strong>最小暴露</strong>：能放私有网（Tailscale）的就不要公开（Tunnel）。</li>
<li><strong>加认证</strong>：公开服务务必启用登录/Access，避免裸奔。</li>
<li><strong>合规边界</strong>：上述工具仅用于合法的远程访问与自组网；不得用于绕过网络管控、非法代理、传播违规内容等违法用途。</li>
<li><strong>固件/系统更新</strong>：家里设备及时打补丁，避免被控。</li>
</ul>

<h2 class="wp-block-heading">八、FAQ</h2>

<p class="wp-block-paragraph"><strong>Q1：哪种最简单？</strong><br />
A：只想远程访问一两台设备，Tailscale 上手最快；想把服务用域名公开，用 Cloudflare Tunnel。</p>

<p class="wp-block-paragraph"><strong>Q2：免费额度够家用吗？</strong><br />
A：个人家庭场景（几台设备、少量隧道）三款免费档都够。具体上限以官网最新为准。</p>

<p class="wp-block-paragraph"><strong>Q3：速度慢怎么办？</strong><br />
A：Tailscale/Zerotier 优先 P2P 直连，若被 NAT 阻断会走中继变慢，可尝试开启 UPnP/端口映射改善打洞；Cloudflare Tunnel 速度取决于 Cloudflare 边缘与你的上行。</p>

<h2 class="wp-block-heading">总结</h2>

<p class="wp-block-paragraph">没有公网 IP 不再是访问家里的障碍。对外发布选 Cloudflare Tunnel（最安全、零入站端口），私有互联选 Tailscale 或 Zerotier（类局域网体验）。三者免费、正规、可组合，足以覆盖从&#8221;远程看 NAS&#8221;到&#8221;出门管理树莓派&#8221;的所有个人场景。记住：只暴露必要的，给公开服务加认证，合规使用。</p>

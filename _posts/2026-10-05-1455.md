<h2>二、DeepSeek：免费 API Key 获取教程</h2>
<h3>第 1 步：注册账号</h3>
<p>打开 <strong>platform.deepseek.com</strong>，点击注册。用<strong>邮箱或手机号</strong>即可，<strong>不需要实名认证、不需要绑信用卡</strong>——这是 DeepSeek 相对火山、智谱最大的门槛优势。验证邮箱后直接登录。</p>
<h3>第 2 步：确认免费额度到账</h3>
<p>登录后进入控制台，在&#8221;用量/余额&#8221;页面可以看到新用户赠送的免费额度。根据公开资料整理，<strong>新用户约有 500 万 token 免费额度，有效期约 30 天</strong>（具体数字和有效期以你账号页显示为准，不同批次活动可能调整）。注意：额度耗尽后会转为按量计费，所以先去看清楚再开调用。</p>
<h3>第 3 步：创建 API Key</h3>
<p>进入左侧 <strong>API Keys</strong> → 点击&#8221;创建 API Key&#8221;，起个名字（比如 <code>my-project</code>），复制生成的那串以 <code>sk-</code> 开头的 Key。<strong>页面只显示一次</strong>，立刻保存到安全的地方。</p>
<h3>第 4 步：调用测试</h3>
<p>DeepSeek 是标准的 OpenAI 兼容接口：</p>
<pre><code class="language-bash line-numbers">curl https://api.deepseek.com/v1/chat/completions \
  -H "Authorization: Bearer <redacted>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-chat",
    "messages": [{"role": "user", "content": "你好"}]
  }'
</code></pre>
<p>把 <code>sk-xxx</code> 换成你的真实 Key。看到返回的 JSON 里有模型回复内容，就说明 Key 生效了。常用模型名：<code>deepseek-chat</code>（对话）、<code>deepseek-reasoner</code>（深度思考）。</p>
<p><strong>避坑提示</strong>：DeepSeek 的免费额度有有效期，别领了放着不用；另外它的免费额度只覆盖 API 调用，网页版对话和 API 是两套体系，不要混淆。</p>
<h2>三、火山方舟：免费 token 领取教程</h2>
<p>火山方舟是火山引擎（字节跳动）的模型服务平台，能调用豆包 Seed、DeepSeek、Kimi 等几十个模型，是国内模型选择最全的免费渠道之一。</p>
<h3>第 1 步：注册火山引擎账号</h3>
<p>打开 <strong>console.volcengine.com</strong>（或搜索&#8221;火山方舟&#8221;进入产品页），用<strong>手机号注册</strong>。注意：火山方舟<strong>必须完成实名认证</strong>（个人认证填姓名+身份证号即可），不实名开不了推理服务。</p>
<h3>第 2 步：在&#8221;开通管理&#8221;领取免费额度</h3>
<p>登录后进入火山方舟控制台，找到 <strong>&#8220;开通管理&#8221;</strong> 页面。勾选你想用的模型，点击&#8221;开通服务&#8221;——<strong>免费额度随开通自动到账</strong>。根据公开资料整理，<strong>每个模型约赠送 50 万 token 免费额度</strong>，额度有效期以该页面显示为准（常见为 30~90 天）。多开几个模型，额度就叠起来了。</p>
<p>部分时段还有&#8221;协作奖励计划&#8221;等活动，每天可额外领额度，具体以控制台活动页为准。</p>
<h3>第 3 步：创建推理接入点（关键步骤）</h3>
<p>这是新手最容易卡住的地方。火山方舟调用时 <strong>model 参数不填模型名，而要填&#8221;推理接入点 ID&#8221;</strong>：</p>
<ol>
<li>控制台左侧进入 <strong>在线推理 → 创建推理接入点</strong>；</li>
<li>选择刚才开通的模型，创建一个接入点；</li>
<li>记下生成的 <code>ep-xxxx</code> 形式的 Endpoint ID。</li>
</ol>
<h3>第 4 步：创建 API Key 并调用</h3>
<p>进入 <strong>API Key 管理 → 创建密钥</strong>，复制保存。调用地址是 <code>https://ark.cn-beijing.volces.com/api/v3</code>：</p>
<pre><code class="language-bash line-numbers">curl https://ark.cn-beijing.volces.com/api/v3/chat/completions \
  -H "Authorization: Bearer <redacted>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "<你的 ep-xxxx 接入点 ID>",
    "messages": [{"role": "user", "content": "你好"}]
  }'
</code></pre>
<p><strong>避坑提示</strong>：方舟是&#8221;开通即计费&#8221;模式，免费额度用完后如果账号有余额会自动按量扣费。建议去费用中心设置<strong>预算告警</strong>，防止半夜跑脚本把钱烧光。另外学生认证可领更高额度，在校的同学别错过。</p>
<h2>四、智谱 AI：免费 API 申请教程</h2>

<h3>第 1 步：注册并实名</h3>
<p>打开 <strong>open.bigmodel.cn</strong>，点击右上角&#8221;登录/注册&#8221;，用<strong>手机号+短信验证码</strong>注册（无需信用卡）。首次登录会提示完成<strong>实名认证</strong>：个人用户填写姓名+身份证号即可，企业可选营业执照。</p>
<h3>第 2 步：确认新人资源包到账</h3>
<p>实名通过后进入控制台，在 <strong>&#8220;资源包管理&#8221;/&#8221;用量中心&#8221;</strong> 页面确认新人 token 资源包已自动到账。根据公开资料整理，<strong>新用户约赠送 2000 万 token 资源包</strong>（有效期以控制台显示为准）。另外注意：<strong>GLM-4-Flash、GLM-4.5-Flash 等 Flash 系列模型是长期免费的，调用它们不消耗资源包额度</strong>——这是智谱最香的一点。</p>
<h3>第 3 步：创建 API Key</h3>
<p>左侧进入 <strong>&#8220;API Keys&#8221;</strong> → 新建密钥，复制形如 <code>xxxx.yyyy</code> 的 Key 并妥善保存。</p>
<h3>第 4 步：调用测试</h3>
<p>智谱同样是 OpenAI 兼容接口：</p>
<pre><code class="language-bash line-numbers">curl https://open.bigmodel.cn/api/paas/v4/chat/completions \
  -H "Authorization: Bearer <redacted>" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "glm-4-flash",
    "messages": [{"role": "user", "content": "你好"}]
  }'
</code></pre>
<p>想完全不耗额度就把 <code>model</code> 指定为 <code>glm-4-flash</code> / <code>glm-4.5-flash</code> 等 Flash 系列；想用更强模型再换 GLM-4.5 等付费模型（会消耗资源包）。</p>
<p><strong>避坑提示</strong>：同一身份证/手机号只能领一次新人包，不要尝试多开小号，会被风控封号。免费档有并发限制，批量任务注意控制 QPS。</p>

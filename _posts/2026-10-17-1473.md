<p>核心摘要（Key Takeaways）：<br />
&#8211; <strong>sing-box</strong> 是用 Go 编写的新一代开源通用代理内核，支持 SOCKS、Shadowsocks、VMess、Trojan、VLESS、TUIC、Hysteria2、Naive 等十余种协议；截至 2026 年 9 月，稳定版已进入 1.14.x。<br />
&#8211; <strong>和 Clash 的关系</strong>：Clash 原版已停止维护，Mihomo 是其社区分支；sing-box 是从零重写的独立内核，主打协议覆盖更全、配置格式统一为 JSON、分流规则更精准。<br />
&#8211; <strong>客户端选型</strong>：iOS 用官方 SFI、Android 用官方 SFA、macOS 用官方 SFM；Windows 选开源社区的 GUI.for.SingBox 或 sing-box-windows；Linux/软路由可用命令行 + WebUI。<br />
&#8211; <strong>两种上手路径</strong>：订阅导入适合新手（几分钟开箱），手动配置适合想精细掌控的人；进阶重点在分流规则（rule-set）和 TUN 模式（虚拟网卡）。</p>
<p>Clash 原版停更之后，很多人发现自己的客户端越用越旧：新协议不支持、规则库不再更新、遇到问题无人修复。社区出现了两条路线：一条是 Mihomo，继续沿着 Clash 的 YAML 配置生态走；另一条就是 sing-box——一套全新的内核，全平台统一，协议支持最激进，配置统一用 JSON。如果你正打算换客户端，或者想一套配置走遍手机、电脑和路由，这篇 sing-box 教程就是为你准备的。</p>

<h2>三、分步骤教程①：订阅导入（新手推荐，5 分钟开箱）</h2>
<p>订阅导入是把&#8221;节点列表 + 基础配置&#8221;打包成一个 URL，客户端拉取后自动生成可用配置。步骤在各客户端大同小异：</p>
<h3>1. 拿到订阅链接</h3>
<p>订阅链接通常来自你自建的服务端（本站有 <a class="wp-editor-md-post-content-link" href="https://waynetalk.com/493/">VPS 零基础部署 sing-box / Xray 服务端指南</a>）或订阅转换服务。拿到形如 <code>https://xxx/sub/xxx</code> 的链接即可，<strong>本文不提供也不推荐任何购买渠道</strong>。</p>
<h3>2. 导入（以官方客户端为例）</h3>
<p><strong>SFI（iOS）/ SFA（Android）/ SFM（macOS）：</strong><br />
1. 打开客户端 → <code>Profiles</code> → <code>New Profile</code>；<br />
2. <code>Name</code> 随便填，<code>Type</code> 选 <code>Remote</code>，<code>URL</code> 粘贴订阅链接；<br />
3. 点击创建，回到 <code>Dashboard</code>，选中刚建的配置，打开 <code>Enabled</code> 开关。</p>
<p><strong>GUI.for.SingBox（Windows）：</strong><br />
1. 首次打开先去 <code>Settings → Kernel</code>，确认 sing-box 内核已安装（显示 Local 版本号），没有就点右侧更新按钮；<br />
2. 进入 <code>Overview → QuickStart</code>，<code>Remote URL</code> 粘贴订阅链接 → <code>Save</code>；<br />
3. 点击生成的配置文件 <code>Click to Start</code> 启动；<br />
4. 建议在设置中勾选&#8221;以管理员身份运行&#8221;，避免 TUN 模式启动失败。</p>
<h3>3. 选择上网模式</h3>
<p>启动后一般有三种模式（各客户端叫法略有差异）：</p>
<ul>
<li><strong>Rule（规则模式）</strong>：按分流规则自动决定直连或走代理，日常推荐；</li>
<li><strong>Global（全局模式）</strong>：所有流量都走代理，适合排查问题；</li>
<li><strong>Direct（直连模式）</strong>：全部直连，等于暂停代理。</li>
</ul>
<p>首次使用建议选 <strong>Rule</strong>，然后去节点/分组页手动选一个延迟低的节点（部分客户端会自动测速排序）。</p>
<h3>4. 验证是否生效</h3>
<p>打开浏览器访问一个境外网站，能正常打开即成功。若打不开：先切到 Global 模式排除规则问题，再换节点重试，最后检查订阅链接是否过期。</p>
<p>订阅不是一劳永逸的：节点会增减、规则集会更新，记得定期在客户端里点&#8221;更新订阅&#8221;。想把多个订阅的节点统一管理、自动重命名和过滤，可以看看本站的 <a class="wp-editor-md-post-content-link" href="https://waynetalk.com/706/">Sub-Store 订阅管理神器高阶指南</a>。</p>
<h2>四、分步骤教程②：手动配置（想精细掌控的人）</h2>
<p>如果你只有单个节点信息（比如自建的 VLESS），或者想自己写规则，可以手动配置。sing-box 的配置是 JSON，大致长这样（示例，请替换为你自己的参数）：</p>
<pre><code class="language-json line-numbers">{
  "log": { "level": "info" },
  "inbounds": [
    { "type": "mixed", "tag": "mixed-in", "listen": "127.0.0.1", "listen_port": 10808 }
  ],
  "outbounds": [
    {
      "type": "vless",
      "tag": "proxy",
      "server": "example.com",
      "server_port": 443,
      "uuid": "your-uuid-here",
      "tls": { "enabled": true, "server_name": "example.com" }
    },
    { "type": "direct", "tag": "direct" }
  ],
  "route": {
    "rules": [
      { "protocol": "dns", "action": "hijack-dns" }
    ],
    "final": "proxy"
  }
}
</code></pre>
<p>关键字段解释：</p>
<ul>
<li><code>inbounds</code>：本地监听入口，<code>mixed</code> 表示同时提供 SOCKS5 + HTTP 代理，浏览器/软件把代理指向 <code>127.0.0.1:10808</code> 即可；</li>
<li><code>outbounds</code>：出口，<code>proxy</code> 是你的代理节点，<code>direct</code> 是直连；</li>
<li><code>route.rules</code>：分流规则，按需把特定流量送往不同出口；</li>
<li><code>final</code>：没命中任何规则时的默认出口。</li>
</ul>
<p>写完配置后，用官方命令先校验再运行，避免 JSON 手误导致启动失败：</p>
<pre><code class="language-bash line-numbers">sing-box check -c config.json   # 校验配置合法性
sing-box run -c config.json      # 运行
</code></pre>
<p>想系统学习 JSON 配置的完整写法（inbound/outbound/route/DNS 全套），可以读本站的进阶长文：<a class="wp-editor-md-post-content-link" href="https://waynetalk.com/701/">Sing-box 新一代通用代理核心从入门到精通</a>。</p>
<h2>五、进阶①：分流规则（rule-set）</h2>
<p>sing-box 分流的核心是 <strong>route + rule-set</strong>：规则集可以是本地文件，也可以是远程订阅的二进制规则集（<code>.srs</code>），客户端启动时自动下载更新。</p>
<p>常见做法：</p>
<ol>
<li><strong>按域名分流</strong>：把常用境外服务域名走代理，国内域名直连；</li>
<li><strong>按 IP 地理位置分流</strong>：配合 GeoIP 数据，非 CN IP 走代理；</li>
<li><strong>按进程分流</strong>：指定某个应用（如游戏、下载器）直连或走代理。</li>
</ol>
<p>1.14 版本起，rule-set 支持本地缓存预热，离线冷启动不再被首次下载阻塞；同时官方开始用 gRPC API 替代旧的 Clash API 做状态查询，第三方客户端也在跟进适配——<strong>升级内核后如果客户端显示异常，先确认客户端版本是否兼容新内核</strong>。</p>
<h2>六、进阶②：TUN 模式（虚拟网卡）</h2>
<p>默认的&#8221;系统代理&#8221;模式只能接管走系统代理设置的软件；<strong>TUN 模式会创建一张虚拟网卡，接管整个系统的 TCP/UDP 流量</strong>，游戏、终端、各类不走系统代理的应用都能被代理。</p>
<p>开启要点：</p>
<ul>
<li><strong>需要管理员/root 权限</strong>：Windows 勾选&#8221;以管理员身份运行&#8221;，macOS/Android 首次开启会弹系统授权；</li>
<li><strong>DNS 接管</strong>：TUN 模式通常会接管系统 DNS（1.14 默认 hijack 模式），防止 DNS 泄漏；若与本地 DNS 方案冲突，可在设置里切换为 native/disabled；</li>
<li><strong>与 VPN 冲突</strong>：TUN 本质是虚拟网卡，和系统 VPN 不能同时开；</li>
<li><strong>性能</strong>：TUN 模式资源占用略高于纯代理模式，低配设备按需开启。</li>
</ul>
<p>TUN + 分流规则是 sing-box 的完全体形态：系统级接管 + 精准分流，既省心又省流量。</p>
<h2>七、常见问题排查</h2>
<ol>
<li><strong>订阅导入后节点列表为空</strong>：检查订阅链接是否过期、网络能否访问订阅地址；换用订阅转换格式（如 sing-box 专用格式）重试。</li>
<li><strong>GUI.for.SingBox 提示无内核</strong>：去 <code>Settings → Kernel</code> 点更新按钮安装内核，确认 Local 显示版本号后再启动。</li>
<li><strong>TUN 模式启动失败</strong>：Windows 确认以管理员身份运行；检查是否有其他 VPN/代理软件占用了虚拟网卡。</li>
<li><strong>部分网站打不开、部分正常</strong>：通常是分流规则或 DNS 问题，先切 Global 模式定位，再检查规则集是否更新成功。</li>
<li><strong>升级内核后客户端异常</strong>：1.14 起部分旧字段被标记弃用（计划在 1.16 移除），检查客户端是否有&#8221;弃用字段&#8221;提示并更新配置。</li>
</ol>
<h2>八、FAQ</h2>
<p><strong>Q1：sing-box 和 Clash（Mihomo）到底选哪个？</strong><br />
A：新人、想一套配置走全平台、对新协议（TUIC/Hysteria2/AnyTLS 等）有需求的，选 sing-box；已有成熟 YAML 规则体系、不想折腾的，Mihomo 也完全够用。两者不是替代关系，是两条并行的生态路线。</p>
<p><strong>Q2：sing-box 配置里的订阅链接从哪里来？</strong><br />
A：来自你自建的服务端或你信任的订阅转换服务。本文只讲客户端用法，不提供购买渠道。自建可参考本站 <a class="wp-editor-md-post-content-link" href="https://waynetalk.com/493/">VPS 部署 sing-box 服务端指南</a>；选协议前建议先看 <a class="wp-editor-md-post-content-link" href="https://waynetalk.com/490/">2026 协议选型指南：VLESS-Reality、Hysteria2 与 TUIC 实测</a>。</p>
<p><strong>Q3：iOS 上 sing-box 客户端叫什么？和 Shadowrocket 有什么区别？</strong><br />
A：官方叫 SFI（sing-box for iOS）。它和 Shadowrocket 是不同的 App：SFI 开源免费、紧跟 sing-box 内核更新；Shadowrocket 是付费闭源老牌客户端，协议支持也很全。按需选择即可。</p>
<p><strong>Q4：TUN 模式和系统代理模式有什么区别？</strong><br />
A：系统代理只接管&#8221;遵守系统代理设置&#8221;的软件；TUN 在网卡层接管全部流量，包括游戏、终端等。TUN 更彻底，但需要管理员权限，且不能与系统 VPN 共存。</p>
<p><strong>Q5：配置文件写错了怎么排查？</strong><br />
A：三步：① <code>sing-box check -c config.json</code> 校验 JSON 与字段合法性；② 看日志输出定位到具体字段；③ 升级内核后注意弃用字段提示（1.14 起会在日志/客户端里告警）。</p>
<p><strong>Q6：sing-box 能在软路由/旁路由上用吗？</strong><br />
A：可以，sing-box 原生支持 Linux，OpenWrt 也有相关方案。家庭网关级的透明代理玩法可参考本站 <a class="wp-editor-md-post-content-link" href="https://waynetalk.com/704/">OpenWrt 旁网关透明代理实操方案</a>。</p>
<p><strong>Q7：规则集（rule-set）更新失败怎么办？</strong><br />
A：先确认网络能访问规则集地址；部分客户端支持&#8221;本地缓存预热&#8221;，离线也能用上次的规则；临时方案是切 Global 模式保证连通，再排查规则源。</p>
<p><strong>Q8：sing-box 适合完全不懂技术的新手吗？</strong><br />
A：订阅导入路径对新手是友好的，跟着第三节走几分钟就能用上。手写 JSON 配置则需要一点学习成本，建议先用起来、再慢慢看第四节和进阶部分。</p>
<h2>总结</h2>
<p>sing-box 的崛起，本质上是代理客户端从&#8221;Clash 一家独大&#8221;走向&#8221;多内核并存&#8221;的标志：官方客户端覆盖 iOS/Android/macOS、社区补齐 Windows/Linux，一套 JSON 配置全平台通用，协议支持永远走在最前面。对普通用户来说，记住三件事就够了——<strong>选对客户端、订阅导入开箱、Rule 模式日常用</strong>；想折腾再去碰分流规则和 TUN 模式。</p>
